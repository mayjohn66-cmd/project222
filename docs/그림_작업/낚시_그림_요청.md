## 물가 소품

실제 연결된 가게 외부 바닥을 유지한다. 물가3곳은 개울/갈대 못/숲 연못으로 구별하며 기존 아이소메트릭 월드와 방향·발 디딜 가장자리를 맞춘다. 물에 걸어 들어가지 않는 충돌을 유지한다. 낚싯대와 찌는 입질 때 보이는 작은 소품이며 실제 이미지가 준비되면 현재 코드 도형을 교체한다. 전용 강·신규 원정 지형 이미지를 자동 생성하지 않는다.

현재 구현: 코드로 만든 작은 수면·가장자리 돌·낚싯대·찌와 3D 이름표. 최종 그림이나 애니메이션으로 완료했다고 표시하지 않는다.
