# 물 타일과 판자 부두 후보 (2026-10-11)

사용자 승인 방향: 물 타일을 깔고 나무판자를 이어 플레이어가 위에서 낚시한다. Codex 내장 `image_gen`으로 물 기본 재질과 물가 흙 재질2개를 개별 생성했다. 기존에 허용한 Python 픽셀 보정/합성으로 게임용 타일을 만들고 기존 판자·잔디·갈대·나무 그림을 재사용했다. 현재 후보 저장이며 게임 실행에는 아직 연결하지 않았다.

## 저장된 그림

| 묶음 | 장수 | 방식 |
| --- | --- | --- |
| 물 기본/작은 변형 | 3 | 같은 기본 그림, 내부 RGB ±2만 변경 |
| 물가 경계 | 18 | 직선4·두 방향6·세 방향4·안쪽 모서리4; 공통 물/흙/기존 잔디 픽셀 조합 |
| 나무판자 | 3 | 기존 wood_1/2/3 바이트 그대로 재사용 |

- [픽셀 정리본24장](픽셀_정리/) · [타일 비교](타일_24장_비교.png) · [물 반복 확인](물_반복_확인.png).
- AI [생성 원본2장](생성_원본/) · [재질 정리2장](재질_정리/) · [전체 프롬프트와 참조](프롬프트.json). 내장 도구 모드이며 별도 API/CLI는 사용하지 않았다. 원본 파일은 보존한다.
- 모든 타일64×32/공통 불투명1024픽셀/이진 알파/투명 RGB0/64색 이하. 게임 칸96×48에 대응하며 중심 기준점 제안(32,16). 물과 흙은12색 재질로 정리, 재질 외곽 색을 통일하고 기존 바닥의 다이아몬드 알파에 맞췄다. 물 변형의 외곽 픽셀은 기본과 같다. 서로 다른 경계 그림을 독립적으로 생성하지 않았다.
- 상판은 기존 그림을 그대로 사용한다. 두께/기둥/난간/부두 끝단 소품은 이번에 새로 만들지 않았으며 실제 배치 확인 뒤 필요량을 결정한다. 현재 상판 연결은 같은 바닥 높이의 판자 발판 제안이다.

## 배치 후보

[세 장소 비교](낚시터_배치_비교.png)와 [칸별 배치/서기·찌 위치](배치_후보.json)를 저장했다. 장소 전체 그림은 타일 연결을 확인하는 미리보기이며 게임에 넣을 단일 배경 에셋이 아니다.

- 가게 옆 개울(`fish_bank`): 흐르는 물 띠+짧은 발판. 양끝으로 물이 이어지는 구성.
- 갈대가 둘러싼 못(`fish_reeds`): 공통 물/경계+꺾인 부두+기존 갈대3묶음.
- 숲가의 작은 연못(`fish_pond`): 모서리를 잘라낸 물 모양+곧은 부두+기존 소나무3그루.

이들은 배치 제안이며 현재 월드 좌표를 강제로 이동하거나 해금 조건을 바꾸지 않았다. 실제 지도에서 주변 길·건물·나무와 겹치는지 확인해 배치해야 한다. 겨울에도 낚시용 열린 물을 유지하고 계절색은 주변 장식으로 구분하는 기존 설계를 따른다.

## 재현 및 검사

저장소 루트에서 `python -X utf8 docs/그림_작업/받은그림/낚시_타일/픽셀_정리.py`를 실행한다. 보관된 원본과 기존 바닥에서 재현한다. 원본이 처음 없을 때만 프롬프트에 기록된 생성 경로에서 복사한다. [후보 목록](후보_목록.json)·[픽셀/배치 검사](검사_결과.json)·[보존 검사](보존_검사.json)에 해시와 규격을 기록했다.

- 신규 타일24장 규격/알파/색 수/SHA256·재현 해시 동일. 물 변형의 공통 가장자리와 채널 차이 ±2, 판자3장 원본 바이트 동일.
- 후보 칸 지도3개에서 육지→부두 끝 경로, 서는 칸이 판자임, 인접한 찌 칸이 판자 없는 물임 확인. 이것은 후보 좌표의 도달 검사이며 Godot의 실제 충돌/플레이 조작 검사가 아니다.
- 기존 원정 후보45PNG와 게임용147+332PNG 해시 유지·실행 manifest 불변. 기존 낚시 ID3개와 배치 후보 대응.
- 문서 링크/목록 검사0문제, 에셋 검사 FAIL0/WARN28(기존 경고 유지), diff 공백 검사 통과. docs 후보는 실행 에셋 검사의 대상이 아니므로 위 픽셀/해시 검사로 별도 확인했다.
- 실제 코드/아이템/어종 확률/보관/저장/시간대 조명 변경 없음. 애니메이션과 전용 노멀맵은 이번에 생성하지 않았다. 실제 GPU/Godot 실행 검사는 새로 하지 않았다.

## 후속 연결

현재 FishingSpots의 임시 물 평면/돌/직사각형 충돌을 타일 배치와 판자 보행 영역에 맞춰 교체한다. 물 위 이동은 막고 판자는 육지에서 연결되게 한다. 물가 타일은 부분 육지/물 경계이므로 전체를 보행 가능으로 처리하지 않는다. 픽셀 조합의 UV 경계는 육지0.17/흙0.30/얕은 물0.37이며 후보 그림 규격이다. 실제 충돌은 보행 면적에 맞춰 결정한다.

기존 location ID/해금/낚싯대/기본 어종/계절·날씨 어종/취소·중단·지급 규칙을 유지한다. 부두 끝 서는 위치와 물의 찌 위치를 분리하고 기존 실제 빛/노멀맵 연결을 보존한다. 물가 주변 장애물·캐스팅 표시·돌아오는 길·세 장소 해금·저장 재개는 적용 후 검사한다. 플레이어가 부두를 건설해야 낚시하는 새 조건은 추가하지 않는다.
