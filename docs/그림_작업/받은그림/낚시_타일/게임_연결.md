# 낚시 타일 게임 연결 (2026-10-11)

- 실행 물3·경계18 PNG: art/received/fishing. 판자3은 기존 floors/wood 원본을 재사용한다.
- fishing_tile_layouts.json: 후보에서 물/판자 칸만 추출한 세 배치, 기존 위치 ID 유지. 주변 갈대/소나무 후보 장식은 이번 연결에서 추가하지 않았다.
- 물 충돌은 경계의 육지 띠를 제외하고 판자 칸에는 만들지 않는다. 부두 끝 26px 안에서 낚시하며 찌 방향으로 선다.
- 도로/보도/마당/미래 매장 확장 영역과 기존 충돌을 피한다. 공간이 아직 황무지 초반이면 첫 실제 재료 판매 뒤 다시 배치한다. 부분 배치도 남은 위치를 재시도한다.
- 자연물 생성에서 낚시 물/부두 칸을 제외하여 이후 나무 성장/덤불 재생에도 유지한다. 방문 NPC는 주변 육지 위치와 실제 경로를 사용한다.
- 기존 바닥 spatial 셰이더 + SpriteNormalMaps 생성 노멀 사용. 세계 조명/시간 변화에 반응. 새 PNG 가져오기는 무손실, 밉맵/자동3D손실압축 끔.
- 기존 낚시 해금·어종·보상·제작·시간·중단·저장 형식 유지. 정지 그림 연결이며 새 물결/낚시 애니메이션은 넣지 않았다.
