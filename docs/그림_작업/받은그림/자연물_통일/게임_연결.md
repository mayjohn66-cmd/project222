# 자연물 그림체 통일과 게임 연결

2026-10-12 · 사용자 요청: 자연물의 품질 차이를 줄이고 최대한 동일한 표현으로 조정.

## 적용

- 기준 둥근 나무를 만든 뒤 그 이미지를 공통 참조로 자연물 15종을 각각 재제작했다. 내장 `image_gen` 사용, 실제 투명 원본 15장과 최종 프롬프트는 [생성 요청](생성_요청.json)·`생성원본/`에 보존했다. 사용자가 앞서 허용한 Python 픽셀 정리 방식으로 전체를 균일 축소했다. 몸이나 잎만 축별 압축하지 않았다.
- 자연물15·단풍24·열매 상태2·마을 꽃덤불1 = 실행용 알베도42장. 공통47색, 최근접 축소, 디더링 없음, 이진 알파. 수종별 모양·자작나무 흰 줄기·벚꽃·사과는 구분된다.
- 잎의 구형 덩어리, 소나무 단색 면, 밑면의 잔디 패치/회색 받침을 정리했다. 맨가지 나무 실제 높이는48→104px로 보강해 겨울에도 성목 크기를 유지한다.
- 계절 선택에 원래 수종을 남겨 둥근/자작/참나무/벚꽃/포플러/버드나무의 단풍 실루엣을 유지한다. 기존 둥근 나무의 단풍4장 외 수종별20장을 추가했다. 버드나무의 가을 색도 상태 그림을 선택한다.
- 자연물15종·마을 꽃덤불의 형상 보조 노멀16장을 연결했다. 알파 실루엣의 완만한 가장자리 높이로 생성한 **근사 법선**이며 정확한3D 형상을 복원한 것은 아니다. 색·열매·단풍 명암을 높이로 읽지 않는다. 계절/열매 상태는 동일 형상의 기본 노멀을 공유한다. 실제 환경광·태양·점등과 시간 시스템은 유지한다.
- 기존 `art/received/nature/`, `nature_states/`, 마을 꽃덤불 경로를 유지해 마을·원정·채집 장소에 함께 적용했다. 선택 SHA·원정 기준점·메뉴가 아닌 월드 꽃덤불 밑면 좌표를 갱신했다. 밑면은 기존 앵커 기준 상대 좌표를 유지해 충돌 범위를 바꾸지 않는다.
- 변경 전22장 모두 Git의 변경 전 바이트와 동일한 복사본을 `변경전/`에 보존했다. 최초 받은 원본도 그대로 있다. 주인공/NPC/가구/바닥·보상·가격·해금·성장 시간/배율·물리 위치·애니메이션은 변경하지 않았다.

## 확인 자료

- [보정 전15종](보정전_비교.png), [보정 후15종](보정후_비교.png): 모두 동일3배 최근접 확대. 성목 수종별 실제 비율을 유지한다.
- [실제 지도 낮](실행화면/environment_village_12.png), [실제 지도 밤](실행화면/environment_village_22.png): 현재 살아 있는 지도 배치와 실제 조명.
- [종별 비교 낮](실행화면/nature_spring_12.png), [저녁](실행화면/nature_spring_18.png), [밤](실행화면/nature_spring_22.png), [아침](실행화면/nature_spring_6.png).
- [수종별 단풍](실행화면/nature_autumn_12.png), [겨울 성목](실행화면/nature_winter_12.png): 실제 렌더를 사용하는 저장하지 않는 비교 배치다. 새로운 자연물 배치를 사용자 지도에 추가한 것이 아니다. 비교 배치의 계절 나무를 검사하기 위한 그림이며 바닥 계절 전체를 바꾸는 검사는 아니다.
- [선택 및 재현 기록](선택_기록.json): 전체 원본/선택 SHA, 공통 팔레트, 균일 배율·캔버스·기준점·계절 선택.

새 자연물 검사 첫 실행의 실패1은 열매 덤불이 기본 덤불 노멀을 공유하는 정상 동작을 잘못 검사한 조건이었다. 공유 규칙에 맞춰 수정한 최종 실행은 실패0이다. 기존 가져오기/로드의 Unicode NUL 경고 및 비어 있는 `shutter` 번역 경고는 남아 있다. 리소스 로드 실패나 SCRIPT ERROR는 발생하지 않았다.

Godot는 분리된 프로젝트·APPDATA에서 검사했고 사용자 저장을 사용하지 않았다. 가져오기로 생기는 CSV 번역 부산물은 작업 저장소에 반영하지 않았다. 애니메이션은 기존 방침대로 보류한다.
