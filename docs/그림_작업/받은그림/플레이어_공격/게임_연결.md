# 원정 플레이어 기본 검 공격 — 2026-10-13

## 범위

사용자 요청에 따라 원정에서 몬스터를 공격하는 기본 근접 동작을 제작·연결했다.
남녀 주인공 각각 8방향×4자세, 게임 PNG 총 64장이다. 원거리 무기·무기마다 다른 외형·새 공격 방식은 추가하지 않았다. 원거리 장비는 기존 투사체를 유지하며 검 그림을 표시하지 않는다.

현재 근접 무기의 공용 검 표현이다. 검·단검·도끼·창별로 별도 동작을 제작했다는 의미가 아니다.

## 그림

- 기존 `art/actors/player_male`, `player_female`의 방향별 정지 그림을 참조했다. 기존 걷기/정지 PNG는 수정하지 않았다.
- 내장 `imagegen`을 남녀 원화에 각 1회 사용했다. 원화 각 887×1774 RGBA, 4열×8행이다. 별도의 이미지 모델명은 확인하지 않았다.

`tools/art/prepare_player_attack.py`가 연결된 인물/검 실루엣을 분리하고 최근접으로 균일 축소한다. 셀 경계를 넘어간 칼끝도 같은 인물의 연결된 그림으로 분리해 다른 프레임에 조각이 남지 않게 했다.

머리와 하체는 기존 원본에 합성하고 팔·몸통 중간·검 부분을 바꾼다. 검과 손이 머리 앞을 지나갈 때는 원본 머리 위에 겹쳐 그린다. 원본이 보이는 머리 픽셀과 발 영역은 보존 검사하며, 무기에 가려진 머리 좌표는 목록에 따로 기록했다. 전체 머리 영역의 최종 RGBA가 모든 프레임에서 동일하다고 주장하지 않는다.

남성 북서의 베기 자세는 원화가 반대 방향으로 뻗어, 북동의 팔·검 부분만 반전했다. 북서 머리/발은 기존 북서 원본이다. 다른 방향과 여성은 해당 방향 원화를 사용한다.

게임 캔버스는 96×96이다. 기존 64×64 인물을 (16,16)에 놓고 검을 위한 투명 여백을 추가했다. 인물의 실제 표시 크기·발 앵커는 그대로이며, 칼의 크기에 맞춰 몸을 축소하지 않는다. 알파 0/255, 원본 팔레트와 검 색 4개를 사용한다. 법선·조명은 기존 `SpriteNormalMaps` 경로를 사용한다.

```text
python -X utf8 tools/art/prepare_player_attack.py
```

기본 실행은 저장된 PNG·SHA·발·머리/무기 가림·알파를 확인한다. 재추출은 `--write --male <원본> --female <원본>`을 명시한다.

## 연결과 판정

`ExpeditionPlayerAttackArt`가 프레임을 읽고 `ExpeditionPixelPlayer`가 기본 검 공격을 재생한다. 현행 피해 판정은 입력 즉시 발생하므로, 원화의 준비 자세부터 기다리지 않고 **베기 → 후속 동작 → 회수 → 준비** 순서로 표시한다. 기존 공격 쿨다운에 맞춘 표시 시간을 사용한다.

성공한 `basic_attack()`마다 `attack_serial`을 증가시켜 화면에 전달한다. 공격 대기시간·원정 종료로 거부된 입력은 증가하지 않는다. 짧은 `attack_flash`를 화면이 놓치거나 다음 공격까지 양수로 유지해도 다음 정상 공격의 그림이 재시작된다. 이는 공격 표시용 번호이며 피해 횟수나 피해량을 늘리지 않는다.

공격 방향은 시작 시 고정한다. 이동 입력은 유지하고, 동작이 끝나면 기존 이동/정지 그림으로 돌아간다. 방 교체·쓰러짐·원거리 방식으로 변경하면 남은 검 동작을 해제한다. 공격 범위·피해량·적 밀림·가격·장비 보너스·저장·원정 보상은 변경하지 않았다.

## 검증

- PNG 64장: SHA/알파/96×96/보존 픽셀/상하 안전 여백 통과.
- 실제 남녀 8방향 GPU 공격 **445개 실패0**: 입력→기존 즉시 피해→공격 PNG·컬러/정렬 마스크, 거부된 입력·다음 공격·일시정지·이동·완료 복귀·무기 방식 변경·방 교체·쓰러짐 확인.

- 기존 원정 완주 **16판/104노드, 모두 완료, 막힘0**. 보스 이전 첫 두루마리 지급0 유지.
- 가져오기2 ERROR0, 전체 스크립트/장면934 로드실패0, 에셋 FAIL0/WARN23(기존), 문서 링크/목록 검사는 기록 시 실행한다.
- 정적 원화·실행 프레임을 확인했다. 사람이 실시간 재생을 보며 판단하는 동작 품질 검토와 다른 PC 플레이는 미확인이다. Windows RC1 실행 파일은 재빌드하지 않았다.
