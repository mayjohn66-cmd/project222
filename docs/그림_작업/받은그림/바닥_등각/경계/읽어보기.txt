등각 경계 타일(생성 0회, tools/art/iso_transition_tiles.py 로 다시 만들 수 있음)
- 폴더: grass_dirt / grass_road / grass_paving. 각 16장, 64x32 마름모(빈틈 없는 모양).
- 파일명 = 마름모 네 꼭짓점의 지형, 순서 N(위) E(오른쪽) S(아래) W(왼쪽). 1 = 잔디, 0 = 길.
  예) 1111 = 전부 잔디, 0000 = 전부 길, 1100 = 위·오른쪽 꼭짓점만 잔디.
- 게임에서 고르는 법: 지형을 칸이 아니라 꼭짓점 격자에 칠하고, 칸 (i,j)는 꼭짓점 (i,j)(i+1,j)(i+1,j+1)(i,j+1)을 N,E,S,W로 읽어 파일을 고른다.
- 1111/0000 자리에는 정리 폴더의 변형(_1~_3)을 섞어 써도 된다.
- 경계 물결은 타일마다 같은 무늬라(주기 1) 이웃끼리 항상 맞물린다.
