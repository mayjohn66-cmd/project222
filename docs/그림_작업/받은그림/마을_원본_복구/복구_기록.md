# 마을 2D 원본 복구 및 누락 분류 정정

2026-10-11 Codex. 사용자가 기존 출력이 있었는지 지적하여 현재 파일뿐 아니라 삭제 이력을 재조사했다.

## 원인

10월 4일 커밋 `2835365b`는 마을 Sprite2D를 VillageArt 자리표로 바꾸면서 더 이상 사용하지 않던 마을 원본 PNG29장과 가져오기 파일을 삭제했다. 그림 경로와 크기는 village_art.csv, 제작 규격·원본 경로는 그림_작업/assets.json 및 요청서.md에 남아 있었다. 10월 11일 점검에서 현재 경로가 없다는 사실을 미제작으로 잘못 분류했다. 기록이 없었던 것이 아니라 삭제 이력 확인을 누락한 것이다.

## 복구

삭제 직전 Git 객체에서 PNG29장을 이 폴더에 바이트 그대로 복구했다. 원본 파일명을 보존하고 원래 경로를 목록에 기록했으며 Git 원본과 SHA256 및 바이트 일치29개를 확인했다. 복구_목록.json/CSV에 원래 경로, 복구 경로, 원본 커밋, 크기, 색상 수, 상태를 남겼다. 기존 게임 연결9장과 실제 지도 배치는 그대로다. 복구 파일은 후보 보관이며 게임에 자동 연결하지 않았다.

- 비자리표 원본26장: 게시판·벤치·가로등, 도구점·대장간, 생선/빵/천 노점 앞뒤, 빵집·곡물창고·마구간, 주택 앞뒤/회전, 길 안내판·울타리·광장상자·꽃덤불 및 이미 연결한 노점/손수레/주택의 과거 선택 원본. 새 제작 대상으로 일괄 분류하지 않는다.
- 벤치·게시판·가로등은 전체 오브젝트 그림임을 직접 시각 확인했다. 그 밖의 복구본26장 전체에 대한 게임용 배율·바닥·회전 품질 검사는 아직 하지 않았다. 일부는 반투명 광택과 큰 해상도가 있어 픽셀 보정 후 연결해야 한다.
- 자리표3장: village_well(96×96), low_wall(1536×768), apple_tree(128×160). 원본 RGBA색2개로 된 임시 사각형이며 우물 원본은 직접 시각 확인했다. 우물·담장은 별도 그림 제작 또는 기존 부품 조합이 필요하다. 사과나무는 art/received/nature/tree_apple.png가 이미 있어 재사용을 우선 검토한다.

## 다음 순서 정정

1. 복구한 게시판·벤치·가로등을 보정·연결한다.
2. 도구점·대장간과 전용 노점/다른 주택·건물의 원본 품질을 확인하고 연결한다.
3. 우물·낮은 담장처럼 원본 자체가 자리표인 대상만 제작 여부를 판단한다.

이번은 복구·기록 정정이며 게임 기능과 렌더러를 변경하지 않았다. 새 AI 이미지를 생성하지 않았고, 원본을 픽셀 편집하지 않았다. 애니메이션 보류는 유지한다.
