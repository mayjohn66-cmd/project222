# 주인공 표정 픽셀 보정 (2026-10-08)

사용자가 「원본 유지하는 픽셀 합성으로 보정」을 승인하여 기존 후보에서 합성했습니다. 기존 원본·게임용 초상화 파일을 덮어쓰지 않았습니다. 이 폴더는 `.gdignore` 아래의 검토용 후보이며 게임 실행 화면에는 아직 연결되지 않습니다.

## 기준과 방법

- 남성: `../male_B_1x.png`, 여성: `../female_C_1x.png`를 공통 기본 레이어로 사용합니다.
- 표정 재료: `../표정_inpaint/{male,female}_{표정}_1x.png`의 작은 눈·눈썹·입 패치만 사용합니다.
- 기본 표정은 RGBA 픽셀 전체가 원본과 동일합니다. 다른 표정은 눈·눈썹·입·홍조의 고정 영역에서만 변경됩니다. 얼굴 윤곽·코·목·몸·의상·배경과 알파는 기본 원본을 유지합니다.
- 서로 다른 생성본의 얼굴 전체를 옮기지 않고, 눈 패치를 같은 기준 위치에 맞추고 입을 고정된 중심에 붙입니다. 얼굴 부위 패치는 최근접 리샘플링을 사용하므로 기존 표정의 모든 세부 픽셀까지 그대로 유지하는 방식은 아닙니다.
- 원본의 색상 팔레트 안에서만 합성합니다. 홍조는 기본 원본에 있는 분홍색 계열을 사용합니다. 앞머리와 코가 겹치는 부분은 보호합니다.

## 파일

- `player_{male,female}_{neutral,smile,flustered,surprised,worried,tired,determined}_1x.png`: 80×96, 남녀 각각 7표정.
- 같은 이름에서 `_1x`를 뺀 PNG: 160×192, 정확히 최근접 2배 확대한 적용용 후보.
- `_표정_픽셀보정.png`: 기본→웃음→당황→놀람→걱정→피곤→결의 비교 시트.
- `mask_{성별}_{표정}.png`: 합성 허용 픽셀을 흰색으로 표시한 마스크. 기본 표정에는 변경이 없어 마스크를 만들지 않습니다.
- `pixel_integrity.json`: 고정 영역·원본 14파일 SHA256·14표정의 검사 결과.

## 검증과 재현

저장소 루트에서 `python dev/art/compose_player_expressions.py`로 재현합니다(Pillow와 Windows 맑은 고딕 필요). 이 명령은 이 폴더의 보정 결과만 다시 씁니다.

14표정 모두 원본 알파 유지, 코 변경 0, 합성 마스크 밖 변경 0, 지정 얼굴 영역 밖 변경 0, 팔레트 추가 0, 확대의 2×2 블록 일치 검사를 통과했습니다. 기본 2장은 변경 0픽셀, 나머지 표정은 80×96 기준 95~166픽셀만 바뀝니다. 입력 원본 14파일은 실행 전후 SHA256 일치입니다. 비교 시트를 육안으로 확인했습니다.

`tools/art/validate_assets.py .`의 기존 게임 에셋 검사도 FAIL 0입니다. 이 검증기는 docs의 후보 그림은 검사하지 않으므로 위 픽셀 검사를 별도로 수행했습니다. Godot 코드·런타임 초상화·데이터 변경이 없어 게임 전체 재실행 검사는 이번 작업 범위에 포함하지 않았습니다.

## 적용 시 전달사항

사용자가 보정 후보를 고른 뒤 Claude가 기존 `art/portraits/player/`의 제작 규격·초상화 선택 경로를 확인하여 적용합니다. 이 폴더의 파일을 곧바로 게임에서 읽지 않습니다. 원본 후보와 기존 게임용 그림을 유지합니다.
