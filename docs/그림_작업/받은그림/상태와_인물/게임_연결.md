## 선택 및 상태 처리

- `NatureStateArt`가 기존 `SeasonStyle` 규칙을 읽는다. 가을에는 단풍 그림을 쓰고 다른 계절의 기존 나무 선택/겨울 숨김은 유지한다. 나무 캔버스96×128/불투명 영역/줄기와 바닥 픽셀은 원본과 같다. 상태마다 노멀맵은 기존 나무를 공유한다.
- 열매 덤불64×64는 잎·바닥·알파가 두 상태에서 같고 열매131픽셀만 달라진다. 마을 `StaticBody2D`의 `berry_state` 메타를 `ready`/`empty`로 전달하면 표시가 바뀌며, 상태가 표시 서명에 포함된다. 현재 마을 덤불의 기본값은 `ready`다. **이번 작업은 마을 직접 수확·재생·아이템 지급을 추가하지 않았다.** 빈 상태 그림과 표시 경로가 준비됐으며 실제 수확 기능 연결은 별도 후속이다.
- `ActorPoseArt`는 실제 제작한 의상/자세만 등록한다. 기존 일반 손님8·직원3·주인공의 8방향 걷기 묶음과 개인 NPC10명의 서 있는 원본은 보존한다. 대장장이/직장인은 남서 정지 그림이다. 현대 의상은 명시된 프롤로그 `look_key`에만 적용하고, 일반 손님의 `commuter` 소분류는 기존 판타지 공용 외형을 유지한다. 가짜 걷기/8방향 세트로 복제하지 않는다.
- 좌식의 크기를 좌식 자체 높이로 다시 늘리지 않는다. 기준 높이84와 기존 성인 표시 높이를 공유하며 종횡비를 균일하게 유지한다. 인물은96×96, 모든 새 실행 그림은 알파0/255·최대89색·8배수 크기다. 무손실 가져오기·알파 경계 RGB 보정OFF·밉맵OFF.
- 생성된 머리가 원본과 달라지는 것을 막기 위해 좌식 기본9그림에 기존 머리/얼굴을 합성했다. 주민3명은 원래96px 도트, 주인공은 기존64px 도트를 기준 크기로 최근접 보정한 뒤 합성한다. 머리 합성 영역의 RGB/알파 일치와 참조 원본SHA는 검사 기록에 있다. 기존 원본 파일은 덮어쓰지 않는다. 생성 원본13개도 보존한다.

## 벤치와 프롤로그

- 기존 길목 쉼터 첫 모임에서는 벤치에 한 주민(기존 참가자 목록의 첫 인물 타블렌)이 앉고 다른 주민은 주변에 머문다. 한 벤치에 참가자 전원을 겹쳐 앉히지 않는다. 코르빈/이세르의 좌식도 같은 표시 선택 경로로 사용할 수 있다.
- 첫 모임 이후 기존 벤치 `[E]` 재방문 대화 동안에는 플레이어가 앉는다. `VillageRestPose`가 기존 그림 발자국과 좌우 반전 방향으로 자리를 맞춘다. 대화 종료/중단/장면 제거 때 원래 위치·물리 처리·이동값·이전 자세 메타를 복원한다.
- 프롤로그의 취식 의자는 `sit_kind=seat`, 바닥에 주저앉기는 `sit_kind=floor`로 구분한다. 일어서면 해당 표시 메타를 정리한다. 주인공 성별과 취식 의자의 바라보는 방향을 따른다.
- 쉼터의 해금·참가 시각·평판·재방문 보상·회복 수치·저장 구조를 바꾸지 않았다. 사용자 지도 배치와 원본/복제 제거 기록도 유지한다. 검사 화면의 시설 표시/배치/줌 변경은 격리된 검사 장면에만 적용했다.

## 대장장이·직장인 비율 보정 (2026-10-11)

사용자 지적으로 다시 비교했다. 이전 검사는 표시 경로·전체 높이·조명을 확인했지만 다른 NPC와 머리/몸 비율을 나란히 검토하지 못했다. 두 인물은 전체 키가 비슷해도 머리가 작고 다리가 길어 기존 개인 NPC와 외형 크기가 다르게 보였다.

- 기존 코르빈(`doyun`)을 엄격한 체형/도트 밀도 기준으로 삼아 두 인물의 큰 머리·짧은 다리·작은 몸 비율을 보정했다. 망치/가죽 앞치마, 현대 재킷/서류 가방은 유지한다. 내장 `imagegen` 편집2회 후 허용된 Python 최근접 픽셀 정리로 기존 실행 경로의 PNG2장을 교체했다. 종횡비를 균일하게 유지하며 렌더러 높이를 늘이거나 줄이는 방식으로 체형을 고치지 않았다.
- [이전/보정 비교](비율_비교.png)는 기존 NPC3명과 두 인물을 같은 발 기준선에 배치한다. 아래 행이 선택본이다. 96×96 캔버스, 실제 불투명 높이84px, 발(48,90), 기존 성인 렌더 높이를 공유한다. 몸폭은 직장인40px, 대장장이45px이며 앞치마·팔·가방 등 소품 차이를 포함한다.
- 이전 생성 원본13장은 보존하고 `생성_원본/actor_blacksmith_proportions.png`, `actor_commuter_proportions.png`를 추가했다. 정확한 프롬프트·참조 경로/생성 시점 SHA·출처는 [생성 기록의 proportion_correction](생성_기록.json)에 있다. [픽셀 정리](픽셀_정리.py)를 재실행하면 같은 선택본·비교표가 재현된다.
- 다른 실행 그림24장 및 좌식 원본 얼굴 합성9영역 SHA는 보정 전과 같다. 기존 개인 NPC10명, 공용 손님/직원/주인공 걷기 그림도 유지한다.
- [실제 게임 비교](실행_확인/costumes.png)는 왼쪽부터 코르빈·타블렌·(기존 주인공)·이세르·대장장이·직장인이다. 기존 성인3명과 신규2명의 실제 Quad 높이 차이0.01 미만, 발 기준선 오차0.0001 미만을 검사하고 체형은 이미지로 확인했다. 조명12시/HUD6시 고정의 격리 검사 화면이다.
- 최종 Godot4.7.1 가져오기2회 ERROR0, 전체875개 로드 실패0(기존 NUL 경고4), GPU13385 검사 실패0/SCRIPT ERROR0. 에셋 FAIL0/WARN28(기존), 경제 기준 하루27.0명·평균객단가228 유지. 이번 수정은 PNG2장·그림 메타/재현/비교 검사이며 게임 진행과 저장 구조는 변경하지 않았다.
