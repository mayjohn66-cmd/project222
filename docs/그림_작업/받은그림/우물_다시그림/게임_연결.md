# 우물 다시 그리기

2026-10-12, main. 사용자가 기존 모델을 정지 이미지로 변환하는 대신 우물을 새로 그려 달라고 요청했다.

## 새 그림

내장 image_gen 도구로 기와지붕·나무 기둥·도르래·물통·돌 우물·청록 물을 갖춘 새 투명 도트 디자인을 만들었다. CLI/API 대체 경로는 사용하지 않았다. 벤치와 게시판은 스타일 참조, 이전 우물은 교체 대상 참조, 바닥은 등각 방향 참조로 전달했다. [전체 프롬프트](프롬프트.txt)와 [생성·참조 해시](생성_기록.json)를 보존한다.

- [생성 원본](원본.png): 1139×1381 RGBA, 생성 도구 출력 그대로 보존.
- [게임용 그림](../../../../art/received/village/village_well_drawn.png): 128×192 캔버스, 몸체85×112,64색, 알파0/255.
- [픽셀 확대](게임용_4배.png)는 정수4배 최근접 미리보기다.
- [선택 해시·배율·알파 기준](선택_기록.json), [재현 도구](../../../../tools/prepare_drawn_well.py). 기본은 읽기 검사, `--install`로 선택본/검사 기록을 복원한다.

처음에는 몸체109×144로 연결했으나 주인공 대비 너무 크게 보여 전체를 균일하게 줄였다. 원본의 가로세로 비율은 유지하며 몸통/지붕 등 일부만 압축하지 않았다. 몸체85×112(이전 모델 렌더99px 높이와 비슷한 범위)에서 물통·도르래·지붕·돌 외형을 실제 화면으로 확인했다. 원본 생성의 반투명 가장자리는 기존 사용자 승인 방식으로 이진 알파 정리했고 팔레트64색으로 맞췄다.

## 실행 연결

`VillageSpriteArt`의 `village_well` 별칭이 새 `village_well_drawn.png`를 선택한다. ID·기준점(64,128)·1.5×1.5 canonical 충돌·지도 배치·해금·일과·저장 형식은 그대로다. 원래 지면 접점(앞쪽152px)을 맞춘다. 무손실 가져오기·최근접·밉맵OFF·자동3D 손실압축OFF 및 기존 보조 법선/실제 시간 조명을 사용한다.

기존 `art/received/village/village_well.png`와 모델·미리보기·렌더 원본은 보존했다. 이전32장 모델 렌더 정리 도구는 이전 파일을 재현하며 새로 그린 선택본을 덮어쓰지 않는다. 다른 실행 그림은 바꾸지 않았다.

## 확인

- Godot4.7.1 가져오기2회 및 크기 조정 후 재가져오기 SCRIPT ERROR/ERROR0. 기존 Unicode/NUL 경고3회는 별도 기록한다.
- 전체884 스크립트·씬 로드 실패0. 기존 Unicode/NUL 경고4회는 발생원 미확정.
- [GPU 실제 연결 검사](../../../../dev/scenes/check_environment_sprite_art.tscn)599/실패0: 편집 지도에서 살아 있는 우물, 새 그림 경로·비율, 마스크/충돌 및 낮밤 조명. 나머지 환경/담장 검사도 통과.
- 픽셀 재현 및 원본 SHA/선택본 SHA·64색·알파·무손실 import 확인. 기존 그림/지도/경제CSV 불변.
- 에셋 FAIL0/WARN28(기존 경고), 문서 링크/목록 오류0.
