# 원정 정지 그림과 낚시 아이콘 연결

2026-10-11 사용자 «이제 다 연결해보자» 반영. 이미 연결된 보정 NPC18장을 유지하고, 준비된 원정 PNG45장과 낚시 아이콘20종을 실행 경로로 연결했다.

## 연결 범위

| 종류 | 실행 그림 수 | 선택 기준 |
|---|---:|---|
| 일반 몬스터 | 18 | 적 데이터 ID |
| 보스 | 6 | 적 데이터 ID |
| 채집물 | 15 | 실제 채집 table/이벤트 target_id |
| 상자·회복샘 | 2 | object_kind |
| 유적 기둥·횃불·출구 | 4 | 지역 장애물/횃불 배치/exit_open |
| 물고기·요리·낚싯대 아이콘 | 20 | 기존 items.csv의 icon_path |

원정 주인공은 기존 남녀 선택형 8방향 그림을 재사용한다. 원정에서 만나는 사람도 기존 손님 역할 도트를 사용한다. 새 인물 애니메이션은 추가하지 않았다. 주인공의 기존 걷기, 공격 표시·투사체·피격 색/깜빡임은 유지한다. 별도 무기를 든 도트와 공격 자세는 후속이다.

## 원본과 표시

- [원정 매핑](../../../../data/art/expedition_sprite_assets.json), [낚시 아이콘 매핑](../../../../data/art/fishing_item_assets.json)에 원본 경로·SHA·선택본 SHA를 남겼다. 원정45장과 아이콘17장은 바이트 동일 복사다.
- `fish_ripple_carp`·`fish_grilled`·`fish_lunch`만 아이콘32색 규격에 맞췄다. 원본36/46/43색→32색, 각각16/100/112픽셀의 색만 변경. 캔버스·알파·실루엣·배치·받은 원본 파일은 동일하다. [전후 비교](아이콘_팔레트_비교.png).
- [재현 도구](../../../../tools/art/install_ready_sprite_art.py)는 기본 읽기 전용으로 원본/선택본65장 SHA와 팔레트 정리를 재현한다. `--install`로 선택본을 복원한다.
- 각 그림은 원본의 가로세로 비율과 발 기준점을 보존한다. 몬스터의 공격 준비/도약에서 축별 압축·회전을 하지 않고 위치/색만 바꾼다.
- 무손실 가져오기·최근접 필터·밉맵OFF·3D 자동 손실압축OFF. 기존 spatial 셰이더와 생성 노멀맵으로 지역 환경광·태양·횃불이 적용된다.
- 광산/유적의 정지 횃불에 실제 점광원을 연결했다. 출구 열림/닫힘은 그림2장으로 전환한다.
- `mine_gather`는 혼합 광맥이다. 수정 확정 보상이라는 뜻이 아니다. 실제 이벤트 target_id를 모델에 전달해 선택하며, 빈/미지정 table에 이 그림을 붙이지 않는다.
- 보상·몬스터 능력치·확률·계절/날씨 등장 조건·원정8×8·충돌·저장 형식은 변경하지 않았다. items.csv는20행의 icon_path만 바뀌었다.

## 남은 그림 범위

- 우물·낮은 담장은 기존 불투명 미리보기만 있어 투명 2D 전환이 남았다.
- 원정 바닥·배경 자연물·암벽/폐허 외벽과 일부 미준비 장애물은 기존 표시를 사용한다. 이번 작업으로 원정 전체가 2D로 전환됐다고 해석하지 않는다.
- 야생열매/돌조각 등 전용 후보가 없는 채집 table은 기존 임시 외형을 사용한다. 준비된15종과 별개이며 엉뚱한 재료 그림으로 대체하지 않는다.
- 개인 NPC의 미제작 방향/걷기·전투 자세·새 상태 애니메이션은 기존 보류 방침을 유지한다.
