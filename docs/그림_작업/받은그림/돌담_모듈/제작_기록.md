# 돌담 1×1 — 그림 하나로 통일

2026-10-12 처음에는 Codex 내장 image_gen을 3회 사용해 좌·중간·우를 만들었다. 사용자는 양끝에 기둥처럼 뚜렷한 차이가 있는 형태를 기대했으며, 기존 결과는 차이가 작으므로 **그림 하나로 통일**하도록 수정했다. 현재 선택은 기존 중간 그림과 같은 픽셀의 반복 돌담 1종이다. 추가 이미지 생성은 하지 않았다.

## 크기와 연결

- 배치 기준 1×1칸. 기존 바닥 한 칸은 64×32픽셀이다.
- 그림의 투명 캔버스는 64×96, 지면 기준점은 (32,64).
- 담장은 칸 중심을 지나가는 낮고 얇은 벽이다. 칸 전체를 두꺼운 돌 덩어리로 채우지 않는다.
- 같은 그림 하나를 반복한다. 길은 화면 왼쪽 위에서 오른쪽 아래로 이어진다.
- 다음 칸의 기준점은 이전 칸에서 (32,16) 이동한다. 같은 높이의 가로 나열이나 임의 간격으로 배치하면 연결되지 않는다.
- 미리보기는 동일한 그림 6개, 총 6칸이다. 끝 위치에 별도 그림을 선택하지 않는다.
- 담장 자체는 약 0.25칸 두께, 게임용 보이는 높이는 약 21픽셀이다.
- 기둥은 현재 선택에 포함되지 않는다. 반대 축과 모서리는 후속 범위다.

## 픽셀 정리

새 우물의 따뜻한 회색 돌색과 기존 2:1 바닥 기울기를 참고했다. 3개 생성 원본과 프롬프트는 아래에 보존했다.

- [중간 원본](중간_원본.png) · [최종 프롬프트](중간_프롬프트.txt)
- [좌측 끝 원본](좌_원본.png) · [최종 프롬프트](좌_프롬프트.txt)
- [우측 끝 원본](우_원본.png) · [최종 프롬프트](우_프롬프트.txt)
- [현재 통일한 그림의 크기·SHA·반복 규격](통일_기록.json)
- [이전 3종 선택 기록 — 사용 중단](선택_기록.json)

기존 중간 그림의 32픽셀 반복 구간을 그대로 선택했다. 종횡비를 유지한 전체 최근접 축소, 48색 이하 팔레트와 0/255 알파도 유지했다. 이번 통일 과정에서는 픽셀을 다시 그리거나 압축하지 않았다. 좌·우 후보와 처음 생성한 원본은 제작 이력으로 보존하며, 현재 선택에는 사용하지 않는다.

재생성: 저장소 루트에서 `python tools/art/prepare_stone_wall_modules.py --install`. 쓰기 없는 검증: `python tools/art/prepare_stone_wall_modules.py`.

## 연결 상태

**2026-10-12 후속: 게임 연결 완료.** 기존 4×0.5칸 돌담에 한 칸 그림을 4번 반복해 표시한다. 그림 전체를 길게 늘리지 않으며, 반대 축은 같은 그림의 수평 반전으로 맞춘다. 색·노멀맵·ID 마스크는 합성된 동일 그림을 사용한다. 기존 지도 배치·해금·충돌은 유지했다. [전체 연결 검사와 최종 남은 그림](../../마을_그림_연결/전체_연결_점검.md) 참고.

## 검증

- 활성 PNG 1개: 64×96, 이전 중간 그림과 픽셀 동일, 48색 이하, 알파 0/255.
- 연결 경계의 위·아래 높이는 2:1 이동량에서 1픽셀 이내로 이어짐.
- 원본과 결과 SHA 기록, 기본 검증으로 결과 재현 확인.
- 동일 그림 하나와 실제 바닥 위 6칸 연결을 눈으로 확인.
- 최초 제작 단계는 코드·데이터 미변경이었다. 후속 실행 연결에서 환경 GPU 593 검사 실패 0, 원정 GPU 1,008 검사 실패 0, 전체 로드 885 실패 0을 확인했다.
- 전체 에셋 검사 FAIL 0 / 기존 WARN 28, 문서의 깨진 링크·목록 누락 0. 후보 PNG는 별도 재현 검사로 픽셀 규격을 검증했다.
