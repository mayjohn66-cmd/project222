# 개인 NPC 전신 정지 후보 (2026-10-11)

## 대조 결과

실행 ActorSpriteFrames.KEYS의 공용 손님8종(normal/traveler/adventurer/miner/herbalist/child/collector/marsh_local), 직원3명, 남녀 주인공은 이미 전용 그림이 있다. 공용 소분류는 대분류로 선택되므로 공용 손님을 다시 생성하지 않았다.

초상화 명단10명은 초상화와 표정 그림이 있으나 이름별 전신 세계 표시 그림이 없다. StoreView3D._actor_look_key와 StoreActorVisuals.sprite_key 기준으로 이야기/행상인 NPC는 기존 모델 또는 역할별 공용 그림을 쓰며, 이번 후보를 아직 읽지 않는다.

## 제작

내장 image_gen으로 각 인물1회, 서로 독립된 원본10장. 초상화 `_서브컬처_전체.png`는 인물 정체성, `art/actors/traveler/rotations/south_west.png`는 게임 도트/등각/크기 기준이다. 프롬프트·참조·생성 파일 위치는 프롬프트.json에 기록했다.

- 타블렌(naru), 코르빈(doyun), 이세르(sora), 오렐(neighbor_bread), 피니아(child_berries)
- 라슈(traveler_water), 엘미(gatherer_herbs), 바르크(miner_ore), 세이나(healer_moss), 델빈(delvin)

최초 출력(현재 사용 보류): 허용된 Python 정리: 불투명 내용 경계 자르기 → 비율 유지 최근접 축소 →48색 이하 →64×64 투명 캔버스. 하단60px/중앙32px 기준으로 발을 정렬했다. 생성 원본과 기존 초상화는 수정하지 않았다. 전신_비교.png는3배 최근접 확대 미리보기다.

- **남서 방향 정지 후보1장씩이며 게임 미연결.** 애니메이션은 사용자 지시대로 보류했다. 방향별 정지 그림도 아직 없다.
- 연결_대기.csv는 다음 연결을 위한 목록이다. 후보를 art/actors에 복사하거나 KEYS에 추가하지 않았다. 현재 로더는8방향과 걷기64프레임 완전성을 요구하므로 이 한 방향을 무리하게 기존 걷기 세트로 등록하면 안 된다.

- 초상화 없는 별도 대장장이/추가 정착 주민 전용 외형은 이10명 명단에 포함하지 않았다. 추가 인물은 설정과 실제 노드ID부터 대조한다.

## 출력 품질 보정 (2026-10-11)

사용자가 최종 축소본의 얼굴/옷이 찌그러져 보인다고 지적했다. 최초 크기·알파 검사는 그래픽 가독성을 보증하지 못했으며, 최초 비교표의 품질 확인 판단을 정정한다.

- 최초64×64 캔버스의 내용 높이52px가 생성 원본의 논리 도트 간격보다 작아 눈·수염·손·의상 선이 끊겼다. 최근접 축소 자체도 이 크기에서는 원본 선을 건너뛰었고 48색 제한까지 겹쳤다.
- 새 선택 후보는 **96×96 캔버스, 내용 높이84px, 발 기준(48,90), 불투명 최대96색**이다. 가로세로 비율을 유지한 최근접 축소이며 흐림/디더링 없이 원본색을 더 보존한다. 투명RGB는0으로 정리한다.
- 기존 걷기 파일의84/88/92px 캔버스처럼 이미지 캔버스 크기는 별도 값이다. 기존 세계 칸/인물 키/충돌 수치를 이번 보정으로 바꾸지 않는다. 게임에서 실제 표시할 크기·밀도는 연결 시 화면 검증이 필요하다.
- `픽셀_정리/*_south_west_96.png`10장을 연결 대기 목록과 후보 목록에 선택했다. 원본10장과 이전64 출력은 보존했다. 이전64 출력은 후보 manifest의 rejected_outputs에 기록, `전신_비교_축소문제.png`는 최초 출력 비교 기록이다.
- `전신_비교.png`는 보정본의2배 최근접 비교표다. `보정_전후.png`에서 세 인물의 이전/보정 출력을 같은2배로 비교한다.
- 10장 크기/알파/색수/발 하단/원본 해시 보존 확인. 전체 비교표에서 눈·손·수염·옷 선을 재확인했다. **미연결 정지 후보1방향**, 실제 게임 표시 품질은 아직 검증하지 않았다.
