# 개인 NPC 도트 게임 연결 (2026-10-11)

## 연결 범위

- 타블렌·코르빈·이세르·오렐·피니아·라슈·엘미·바르크·세이나·델빈 10명.
- 보정된 96×96 PNG를 `art/actors/npc/<id>/south_west.png`에 바이트 그대로 복사했다. 사용 보류한 64×64 그림은 연결하지 않는다.
- 실행 목록은 `data/art/npc_sprite_assets.json`. 생성 후보 manifest는 생성 시점 기록으로 유지한다.
- `NpcSpriteArt`는 남서 정지 방향, 발 (48,90), 원본 알파/종횡비를 유지한다. 피니아는 기존 어린이 높이 0.72를 적용한다.
- 최초 결제 손님은 델빈, 튜토리얼 물물교환 상인은 타블렌. 부탁 NPC는 생성 시 대사 화자의 canonical NPC ID를 기록한다.
- 마을 정착 주민·낚시 방문도 인물 ID를 사용한다. `neighbor`는 기존 오렐 이야기 ID로 연결한다.
- 일반 행상인 손님을 이름 있는 타블렌으로 바꾸지 않는다. 공용 8종 손님/직원3/남녀 주인공의 기존 8방향 걷기는 유지한다.
- 프롤로그 `backpacker`는 외형 CSV가 일치하는 공용 `traveler` 그림에 연결한다.
- 이름 있는 그림이 없는 주민·비밀 상인은 공용 역할 도트를 사용한다. 대장장이는 공용 광부 그림으로 임시 표시한다(개별 바르크가 아님).
- 기존 노멀맵 생성/시간 조명, 색상·ID 마스크 정렬, 숨김·퇴장 처리를 그대로 이용한다.

## 검증

- `check_npc_sprite_art`: 최종 GPU 165 검사 실패 0(앞선 headless 기본 검사 163 실패 0). 실제 매장 생성/움직이는 정지 인물/소스 SHA256/비율/마스크/노멀맵/낮밤/퇴장 및 부탁 NPC 생성 검사.
- 프롤로그 `check_opening_prologue`: 37 검사 실패 0.
- 기존 `check_pixel_actors`: 1809 검사 실패 0. 시간 색조를 중복 곱하던 옛 검사만 현재 월드 빛/노멀맵 방식에 맞게 수정.
- 가져오기 2회 SCRIPT ERROR 0, 전체 865 스크립트·씬 로드 실패 0. 전체 로드 검사 중 NUL 문자 경고 4회가 발생했다(로드 실패 0). 원인은 아직 확인하지 않았다.
- 에셋 검증 FAIL 0 / WARN 28(기존 수 유지).
- 실제 렌더링: [낮](게임_연결/npc-day.png), [밤](게임_연결/npc-night.png). HUD는 검사 중 멈춘 게임 날짜/시간이며 렌더링 시각만 낮/밤으로 바꿨다.

## 후속

- NPC10은 한 방향 정지 그림이다. 이동 시에도 이 그림을 유지한다. 방향별/걷기 애니메이션은 사용자 지침대로 보류했다.
- 좌식 전용 그림은 아직 없다. 프롤로그 주인공이 앉는 동안은 기존 관절 모델이 남는다. 서면 2D로 복귀한다.
- `commuter` 현대 의상, 대장장이 등 신규 인물의 전용 그림은 준비되지 않았다. 현대 직장인에게 판타지 공용 의상을 강제로 대입하지 않는다.
- 준비된 원정 몬스터·채집물 후보의 실행 연결은 별도 후속이다. 이번 연결은 매장/마을 인물 범위다.
- 사용자 저장 파일을 쓰지 않는 별도 검사 프로젝트와 APPDATA로 실행했다.
