# 숲속 편의점 타이틀 배경 후보

2026-10-12 사용자 배경 이미지 출력 요청으로 직전 타이틀 화면을 기준으로 첫 후보를 제작했다. 이후 사용자 타이틀 연결 승인으로 아래 실행 연결을 완료했다. 다른 화면의 UI 수정은 후속이다.

## 출력

- [배경 PNG](forest_shop_title.png): 1672×941, RGB, 불투명 PNG. 약 16:9 원본 비율을 보존한다.
- SHA256: `942cbc56e85c6a265046f3a4f2dbdeb45d4a9ad0bdffa568c7f4f20fff2557f1`.
- Codex 내장 `image_gen` 사용, 생성 1회. 외부 API·Pixel Lab 호출 없음. 이미지 모델 식별자는 도구가 별도로 제공하지 않았다.
- 생성 원본 파일명: `exec-6618f13a-ef9c-444f-878b-212886ce58d4.png`. 출력 경로는 도구 반환으로 확인했고 프로젝트 복사본 해시·PNG 디코딩을 확인했다.
- 픽셀 축소·팔레트 제한·비율 변형·추가 합성 없음.

## 구도와 확인

- 판타지 숲에 도착한 현대 편의점, 크림색 벽·청록색 띠·유리 출입구. 참조는 [기존 숲 배경](../원정_배경/forest_received.png)과 [매장 실행 화면](../프롤로그_도시/실행_확인/튜토리얼_시야_1_15.png).
- 중앙 버튼 영역은 풀밭 여백, 편의점은 오른쪽 위. 완성된 마을이나 추가 인물을 넣지 않았다.
- 실제 생성 그림을 확인: 건물 지붕과 창문 연결·외곽 여백·숲의 색감·중앙 여백 양호, UI·글자·워터마크 없음.
- 이것은 타이틀의 평면 배경이며 매장 타일이나 플레이 공간을 대체하지 않는다.

## 타이틀 게임 연결 완료

후속 최신 상태: [로고·Silver 폰트 연결](../타이틀_로고/제작_기록.md). 아래 폰트 미변경/기존 TitleLabel 내용은 최초 배경 연결 당시 기록이며 현재 타이틀은 새 로고와 Silver를 쓴다.

- 실행 파일은 `res://art/ui/backgrounds/forest_shop_title.png`와 무손실 `.import`. 원본과 SHA256 동일, 이미지 비율·픽셀을 재가공하지 않았다.
- `scenes/core/title/title_screen.tscn`: 첫 자식 Background TextureRect를 전체 화면 앵커·최소크기 무시·KEEP_ASPECT_COVERED·mouse_filter IGNORE로 연결. 배경에만 Linear 필터, 타일·다른 그림 필터는 바꾸지 않는다.
- 비율을 유지하며 화면을 채우므로 4:3 등에서는 배경 양옆 일부가 잘릴 수 있다. 메뉴와 제목은 화면 안에 유지된다.
- 제목은 밝은 크림색·짙은 외곽선·30px. 중앙 버튼의 경로·기능·240×50 크기는 유지한다.
- [1152×648 실제 실행](실행_확인/타이틀_1152x648.png), [800×600 실제 실행](실행_확인/타이틀_800x600.png)에서 배경·제목·버튼 배치와 대비를 확인했다.
- 사용자 저장과 분리한 테스트 복사본/APPDATA에서 Godot 4.7.1 GPU 실행. 화면 크기·버튼 경계·배경 클릭 무시·실제 마우스 새 게임 클릭→이름창 표시→취소 22항목 실패0, 종료0, SCRIPT ERROR/ERROR0. 가져오기 두 번 모두 종료0, 두 번째 ERROR0.
- 임시 확인 코드는 작업 폴더에만 보관. 다른 게임 기능의 전체 회귀를 이번 작업에서 반복하지 않았다. 에셋 검증기 FAIL0/WARN29: 기존28개와 배경 높이941이 8의 배수가 아니라는 UI 규격 경고1개. 타일/아이콘이 아닌 화면 배경이므로 원본 비율을 유지하며, 별도 PNG 디코딩/해시·실제 GPU 화면으로 확인한다. 문서 검사 깨진 링크/미등록0.
- 폰트·공통 테마·저장·게임 규칙은 수정하지 않는다. 사용자 Silver 폰트 적용은 사용자 로컬 설정으로, 저장소 실행 캡처에는 기존 기본 폰트가 보인다. Windows RC1은 다시 빌드하지 않았으므로 이번 변경은 다음 배포 빌드에 포함해야 한다.

## 생성 프롬프트

```text
Use case: stylized-concept.
Asset type: a single production candidate for a cozy Korean fantasy convenience-store game's title-screen background, wide 16:9 landscape composition.
Primary request: draw the exterior of a modern convenience store that has mysteriously arrived in an isolated forest clearing, expressing a welcoming beginning and gentle discovery.
Input images: Image 1 is a STYLE AND PALETTE reference only for the established clustered pixel-art trees and grass. Image 2 is a GAME ENVIRONMENT AND BUILDING MATERIAL reference only: warm brown/beige walls, dark teal horizontal trim, wood-framed green glass entrance, pale stone tile flooring. Do not reproduce the screenshot, HUD, debris or cutaway interior.
Scene: a sunlit spring forest clearing, softly layered leafy trees at the sides and back, a narrow dirt footpath leading through the clearing toward the shop, a few unobtrusive small wildflowers. Just one modern flat-roof shop with cream walls, dark teal fascia, large glass windows and recognizable entrance. Warm light inside, modest shelves visible behind the glass. The building has an intact roof and clean, coherent exterior perspective, no lettering or logos on its fascia. No village yet, no extra houses, no characters.
Style: carefully composed 2D pixel-art game background with crisp deliberate pixel clusters and consistent pixel density, matching the established references; readable foliage masses and restrained texture. Not 3D-rendered, not photographic, not soft painterly concept art, not distorted coarse pixelization.
Composition: slightly elevated three-quarter/isometric viewpoint with approximately 2:1 ground diagonals. Shop focal point sits in the right third / upper-right quadrant, fully inside the frame with breathing room. Keep the central vertical 30 percent from y=25 to 80 percent calm and low-detail for the EXISTING centered title and three buttons to be drawn separately by the game. The clearing continues across the lower portion. Use natural trees and grass edge composition, no blank artificial panel.
Lighting: readable warm late-afternoon daylight, optimistic and cozy, luminous greens with brown and muted teal accents. Avoid underexposure, near-black vignette, overly harsh shadows, glowing magic portals or excessive particles.
Output: ONE seamless full-bleed 16:9 landscape PNG background, ideally 1536x864 or a native 16:9 resolution. Not a collage, not an asset sheet. No text, no numbers, no title, no watermarks, no frame, no UI, no buttons. Preserve clean shop proportions and do not bake gameplay interaction markers into the art.
```
