# 3D 마을 그림 작업 — 먼저 읽기

> 자동 생성 파일(`tools/build_art_request_doc.py`). 직접 고치지 말 것. 진행 현황은 이 파일을 다시 만들 때 갱신된다.

## 한 줄 사용법

1. PC 터미널에서 `tools\run_world3d.bat` (또는 `python tools/world3d_menu.py`) 실행.
2. **6번 「Pixel Lab 으로 만들기」** → 자산 선택 → PC 의 Claude Code 가 Pixel Lab MCP 로 한 면씩 만들어 보여 줌.
3. 마음에 들면 3번 「그림 넣기」(또는 Claude Code 가 `tools/ingest_world3d.py` 실행) → Godot 한 번 열기 → 4번 「가져오기 설정·검증」 → 게임에서 **F8**.

## 폴더 (이 폴더 `docs/그림_작업/` 하나만 보면 됨)

| 이름 | 용도 |
|---|---|
| `시트/<자산id>.png` | **자산별 한 장 요약**: 3D 미리보기 + 2D 원본 + 면 질감 틀과 크기. 어떤 그림이 필요한지 눈으로 볼 때 이것만 열면 됨 |
| `요청서.md` | 자산별 면 표(크기·반복·법선·영문 프롬프트), 공통 규칙 |
| `지시/<자산id>.md` | Pixel Lab 작업 지시(메뉴 6번이 만듦) |
| `받은그림/<자산id>/` | Pixel Lab 결과 임시 보관(확인 후 넣음) |
| `틀/` | 면 질감 틀 PNG(임시 그림, 정확한 크기). 평평하게 `<자산id>__<면>.png` |
| `faces.csv`, `assets.json` | 도구가 읽는 표 |

최종 그림이 들어가는 곳: `art/world3d/<자산id>/<면>.png` (게임이 자동으로 읽음).
