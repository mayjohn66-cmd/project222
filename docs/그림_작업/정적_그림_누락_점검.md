# 정적 그림 누락 점검 (2026-10-11)

사용자 결정: 애니메이션은 뒤로 두고 빠진 정적 그림부터 확인한다. 최초 점검은 파일·선택 코드 대조만 했으며, 이후 일반 몬스터 출력 요청으로14종을 추가 제작했다. 아래 현황은 그 후속을 반영한다. 게임 코드 변경/실제 게임 화면 검사는 이번에 하지 않았다.

## 이미 있고 연결 또는 보정이 필요한 그림

- 원정 후보 총38종39PNG: 채집15+상자1+회복샘1+환경 소품3종4장+일반 몬스터18종. 모두 후보 저장이며 실행 연결은 후속. [몬스터 제작 기록](받은그림/원정_몬스터/제작_기록.md)과 각 후보 목록을 참조한다.
- 물고기12·생선 요리6·낚싯대2 = 아이템20종: items.csv의 icon_path가 비어 있지만 받은그림/아이템에 해당 ID의 *_64.png 후보가20종 모두 있다. 새로 생성할 누락이 아니라 후보 확인/선택/실행용 복사와 아이콘 연결 대상이다.
- 냉장함/냉동함: 월드 네 방향 두 상태 그림은 연결 완료. furniture_items.csv의 메뉴 icon_path는2종 비어 있다. 월드 그림은 다시 만들지 않고 메뉴 미리보기의 기존 대체 표시를 확인한 뒤 전용 아이콘 필요 여부를 판단한다.
- 상자 열림은 별도 후보가 없지만 현재 원정은 소비 후 숨김으로 처리한다. 새로운 정적 열림 상태를 필수 누락으로 세지 않는다.
- 반대 방향 그림·별도 노멀맵은 기존 후보의 후속 사양이다. 지금은 애니메이션 프레임을 제작할 범위에 넣지 않는다.
