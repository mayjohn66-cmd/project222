원본 6장을 보존한 채 투명 배경·최근접 축소·팔레트를 정리한 PNG 9장이다. 새 AI 그림 생성은 하지 않았다. 선택 경로·원본 SHA·발 위치·바닥 다각형·지붕색은 `data/art/village_sprite_assets.json`, 재현 도구는 [픽셀_정리.py](픽셀_정리.py)에 있다. 기본 그림 80색 이하, 지붕 변형 96색 이하, 알파 0/255, 8배수 캔버스, 무손실 가져오기다. 지붕색 변형은 지붕 부분만 변경하고 몸체·실루엣·알파를 보존한다.

## 게임 연결

- `VillageSpriteArt`가 기존 `VillageArt.art_path`를 실행 PNG로 대응하고 `VillageMirror`에서 먼저 선택한다. 매칭하지 못한 오브젝트는 기존 표시를 유지한다.
- `ReceivedWorldArt.billboard`의 동일한 조명·마스크·정렬 경로를 쓴다. 그림의 종횡비는 균일 배율로 유지한다. 기본 PNG에서 생성하는 근사 노멀맵을 공유하며 기존 낮밤 조명을 받는다. 수작업으로 제작한 노멀맵은 아니다.
- 그림의 지면 네 꼭짓점을 충돌 및 깊이 정렬 기준으로 쓴다. 지붕 돌출부가 보행을 막지 않도록 지면 충돌을 분리한다. 좌우 반전 시 그림·발 위치·바닥 다각형·노멀을 함께 맞춘다.
- 기존 퀘스트/건설 해금, 저장된 지도 위치·회전·삭제 표시를 따른다. 그림 연결로 새 시설을 해금하거나 지도 위치를 변경하지 않는다.
- 검사용 해금·시간 변경은 격리된 실행 중 상태에서만 적용했다. 실제 저장 파일과 지도 JSON은 수정하지 않았다. 삭제된 원본 템플릿을 강제로 표시했던 초기 검사는 폐기하고 실제 남아 있는 배치를 대상으로 재검사했다.

## 검증

Godot 4.7.1, 별도 APPDATA 및 가져오기용 프로젝트에서 실행.

- 가져오기 2회: SCRIPT ERROR / ERROR 0.
- `check_village_sprite_art.tscn`: 실제 GPU 실행 92개 검사, 실패 0. 새 게임 시설 숨김·원본 해시·알파·정렬·바닥 충돌/바깥 보행·원래 지도 지면·반전·저장된 지붕색·낮밤 변화·삭제 정리·해금 복원 포함.
- 모든 `.gd` / `.tscn` 868개 로드 실패 0. 기존 Unicode NUL 경고 4개는 유지되어 별도 정리가 필요하다.
- 기존 마을 시장 검사 58개 / 낚시 타일 검사 70개 실패 0, 마을 일과 검사 실패 0.
- 에셋 검사 FAIL 0, WARN 28(기존). 밸런스 기준 도구 실행 완료; 가격·보상·진행 수치 변경 없음.
- 원본 6장 SHA 보존, 지붕 변형 3장 크기·알파·비지붕 픽셀 보존 확인.

실행 화면: [낮](village-day.png), [밤](village-night.png), [주택](village-houses.png). 시간대는 검사용 forced_hour라 HUD의 표시 시각과 다를 수 있다. 미해금 시설을 보이게 한 검사용 화면이며 새 게임에서 전부 등장하는 뜻은 아니다.

## 남은 그림

목록의 이전 PNG 경로 29개가 현재 파일로는 모두 누락되어 있다. 일부는 이번처럼 남아 있는 다른 원본을 재사용할 수 있으므로 경로 누락 수를 미제작 수로 취급하지 않는다. [연결_대조.csv](연결_대조.csv)는 목록 경로별 실행 대체 연결을 기록한다.

- 우물, 마을 게시판, 나무 벤치, 가로등, 낮은 담장: 실행 가능한 전체 오브젝트 PNG 필요. 그림_작업/시트의 3D 질감/미리보기 시트는 완성 2D 오브젝트로 사용하지 않는다.
- 이끼 주택 뒤쪽·회전 방향, 생선/빵/천 전용 노점, 도구 상점·대장간 등: 해당 그림이 준비되지 않은 방향/유형은 기존 표시 유지.
- 이번 연결은 일부 기존 마을 오브젝트 대상이다. 모든 마을 3D 표시를 제거한 작업은 아니다. 걷기·좌식·물결 등의 애니메이션은 별도 후속 작업이다.
