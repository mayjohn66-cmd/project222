## 기존 외형이 있고 2D 전환이 남은 항목

2026-10-11 추가 정정: 우물·담장이 없다고 분류한 것은 전체 외형이 담긴 기존 미리보기를 누락한 판단이었다. 두 종류 모두 기존 모델과 288×288 렌더 미리보기가 있다.

- 우물: `docs/그림_작업/틀/village_well__preview.png`. 지붕·기둥·돌 우물·물이 표현돼 있다.
- 낮은 담장: `docs/그림_작업/틀/low_wall__preview.png`. 돌 벽과 상부 마감이 표현돼 있다.
- 두 미리보기 모두 잔디와 지면 그림자가 포함된 불투명 이미지(알파 전부255)다. 받은그림 복구 폴더의 같은 이름 PNG는 별도의 임시 사각형(각2색)이며, 미리보기와 동일한 그림이 아니다.
- 분류는 **기존 외형 있음 / 게임용 투명 2D 그림 연결 미완료**로 바꾼다. 신규 디자인 제작으로 단정하지 않는다. 기존 모델을 배경 없는 정지 그림으로 재사용할 수 있는지 먼저 검토한다. 현재 실행 연결 수27/29는 변하지 않는다.
