# 그림 연결 후 남은 항목

2026-10-11, 복구본26종 전체 연결 이후 기준. 현재 게임 데이터/선택 코드 및 복구 Git 이력으로 판단한다.

## 실제 그림이 부족한 항목

1. 마을 우물: 복구본 village_well.png는96×96 임시 사각형. 전체 오브젝트 그림 필요.
2. 마을 낮은 담장: 복구본 low_wall.png도 임시 사각형. 전용 그림 제작 또는 기존 벽 부품 재사용 검토.
3. 계절 자연물: 단풍 나무·열매 덤불의 수확 전/후 상태. 기존 기본 나무/덤불은 있으나 이 상태들은 모델 표현이 남아 있다.
4. 인물: 대장장이 전용 월드 외형(현재 공용 광부), 프롤로그 현대 직장인 전용 의상, 앉은 자세 그림. 개인 NPC10명은 남서 정지 그림 연결됨. 주인공/일반 손님/직원 기존 걷기는 있음. 새 개인 NPC 방향별/걷기는 애니메이션 보류 범위.

게시판·벤치·가로등·도구점·대장간·생선/빵/천 노점·빵집·곡물창고·마구간·복구된 주택 방향·길 안내판·울타리·상자·꽃덤불은 실행 연결 완료. 옛 사과나무 자리표는 기존 tree_apple로 대체 연결했다.

## 그림은 있고 실행 연결이 남은 항목

- 원정 일반18/보스6 = 몬스터24종.
- 원정 채집15·상자1·회복샘1·환경소품4장 =21장, 몬스터 포함45PNG 후보.
- 낚시 물고기12·요리6·낚싯대2 = 아이콘20종.
- 원정 바닥·벽·장애물은 현재 모델 표시가 남아 있어 기존 타일/자연물 그림 재사용을 먼저 대조한다. 지역별로 새 바닥을 모두 만들어야 한다고 분류하지 않는다.

## 현재 지도에 배치되지 않은 확장 규칙

village_3d.csv에는 풍차·돔 회관·탑 주택, 치즈/향신료/고기/책/도기/꽃/물약 노점 등의 모델 규칙이 남아 있다. 현재 저장 지도에는 해당 새 종류의 배치가 없다. 추후 실제 콘텐츠로 사용하기로 할 때 개별 그림 제작 여부를 정한다. 복구한26종과 별개의 확장 후보이다.

추가 조사에서는 현재 파일 경로 누락만으로 미제작을 판단하지 않고, 받은그림·실행 선택 경로·Git 삭제 이력까지 대조한다.
