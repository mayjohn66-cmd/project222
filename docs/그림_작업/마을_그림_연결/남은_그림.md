# 그림 연결 후 남은 항목

2026-10-11, 복구본26종 전체 연결 이후 기준. 현재 게임 데이터/선택 코드 및 복구 Git 이력으로 판단한다.

## 기존 외형이 있고 2D 전환이 남은 항목

2026-10-11 추가 정정: 우물·담장이 없다고 분류한 것은 전체 외형이 담긴 기존 미리보기를 누락한 판단이었다. 두 종류 모두 기존 모델과 288×288 렌더 미리보기가 있다.

- 우물: `docs/그림_작업/틀/village_well__preview.png`. 지붕·기둥·돌 우물·물이 표현돼 있다.
- 낮은 담장: `docs/그림_작업/틀/low_wall__preview.png`. 돌 벽과 상부 마감이 표현돼 있다.
- 두 미리보기 모두 잔디와 지면 그림자가 포함된 불투명 이미지(알파 전부255)다. 받은그림 복구 폴더의 같은 이름 PNG는 별도의 임시 사각형(각2색)이며, 미리보기와 동일한 그림이 아니다.
- 분류는 **기존 외형 있음 / 게임용 투명 2D 그림 연결 미완료**로 바꾼다. 신규 디자인 제작으로 단정하지 않는다. 기존 모델을 배경 없는 정지 그림으로 재사용할 수 있는지 먼저 검토한다. 현재 실행 연결 수27/29는 변하지 않는다.

## 추가 그림이 부족한 항목

1. 계절 자연물: 단풍 나무·열매 덤불의 수확 전/후 상태. 기존 기본 나무/덤불은 있으나 이 상태들은 모델 표현이 남아 있다.
2. 인물: 대장장이 전용 월드 외형(현재 공용 광부), 프롤로그 현대 직장인 전용 의상, 앉은 자세 그림. 개인 NPC10명은 남서 정지 그림 연결됨. 주인공/일반 손님/직원 기존 걷기는 있음. 새 개인 NPC 방향별/걷기는 애니메이션 보류 범위.

게시판·벤치·가로등·도구점·대장간·생선/빵/천 노점·빵집·곡물창고·마구간·복구된 주택 방향·길 안내판·울타리·상자·꽃덤불은 실행 연결 완료. 옛 사과나무 자리표는 기존 tree_apple로 대체 연결했다.

## 현재 지도에 배치되지 않은 확장 규칙

village_3d.csv에는 풍차·돔 회관·탑 주택, 치즈/향신료/고기/책/도기/꽃/물약 노점 등의 모델 규칙이 남아 있다. 현재 저장 지도에는 해당 새 종류의 배치가 없다. 추후 실제 콘텐츠로 사용하기로 할 때 개별 그림 제작 여부를 정한다. 복구한26종과 별개의 확장 후보이다.

추가 조사에서는 현재 파일 경로 누락만으로 미제작을 판단하지 않고, 받은그림·실행 선택 경로·Git 삭제 이력·틀/시트 미리보기·기존 모델까지 대조한다.
