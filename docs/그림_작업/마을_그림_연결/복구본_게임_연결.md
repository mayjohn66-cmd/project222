# 복구된 마을 그림 전체 연결

2026-10-11 Codex, 사용자 요청: 복구 가능한 그림 전부 연결하고 남은 그림 재정리.

## 완료 범위

10월 4일 삭제되어 복구한 PNG29장 중 비자리표26장의 모든 원래 경로를 실행용 그림에 연결했다. 기존 선택 그림이 있던 노점/손수레/앞쪽 주택 등5개 경로는 앞선 선택본을 유지하고, 나머지21개 기본 그림은 복구 원본에서 정리했다. 임시 자리표3장 중 사과나무는 기존 자연물 tree_apple로 재사용 연결했다. 목록29개 중 연결27 / 미완성2(우물·낮은 담장)이다.

| 대상 | 방향/상태 |
|---|---|
| 대장간·도구점 | 기존 건물 방향 |
| 빵집·곡물창고·마구간 | 기존 건물 방향 |
| 생선·빵·천 노점 | 각 앞·뒤 2종 |
| 빨간 지붕 주택 | 기본·회전 2종 |
| 이끼 주택 | 앞·뒤, 각각 기존 지붕색3 추가 |
| 황토 타운하우스 | 기존 앞·뒤 연결 유지 |
| 공용/약초 노점·손수레 | 기존 선택 그림 유지 |
| 게시판·벤치·가로등·광장 상자·길 안내판·나무 울타리·꽃덤불 | 복구본 보정 연결 |
| 사과나무 | 현재 자연물 그림 재사용, 임의 다른 나무 선택 중단 |

전체 실행 목록은 기본27종 + 이끼 주택 지붕색6장 + 가로등 유리 발광마스크1장 = PNG34장. 이 작업에서는 PNG25장을 추가했다. 원본29장과 기존 실행9장은 바이트/SHA 보존. 새 AI 생성은 하지 않았다.

## 연결 방식

- VillageSpriteArt manifest에 원본 별칭·바닥네점·발 기준·균일 배율·충돌 축소율을 기록한다. 종횡비를 임의로 찌그러뜨리지 않는다. 큰 반투명 배경 광택을 제거하고 최근접 축소·80색 기본/96색 이하 지붕 변형·0/255 알파·8배수 캔버스·무손실 가져오기를 사용한다.
- 현재 지도에 저장된 앞뒤 방향, 좌우 반전, 앞/뒤 주택 지붕색을 따른다. 지붕색/반전 변화는 재표시 서명에 포함되어 편집 중 바뀐 상태도 즉시 반영한다.
- 바닥 면으로 깊이 정렬·충돌을 맞춘다. 건물 앞의 포장 일부를 보행 가능하게 남기며 서비스 NPC가 설 접근 지점을 실제 물리 쿼리로 확인했다.
- 기존 근사 노멀맵/월드 낮밤 조명 유지. 가로등의 유리 부분만 별도 발광 마스크로 밝혀 밤의 표시를 유지한다. 공유 셰이더의 발광 기본값은 OFF로 손님/다른 그림에 적용하지 않는다. 새 가로등 주변 광원 확산을 추가한 작업은 아니다.
- 신규시설 강제 해금·지도 위치 변경·삭제된 원본 배치 복원은 하지 않았다. 현재 retained 배치90개/20종에 적용된 것을 검사했다. 지도에서 사용하지 않는 나머지 방향도 동일 렌더러의 격리 복제 검사로 확인했다.
- 실제 새 게임에서는 기존 이야기/정착 해금대로 시설이 등장한다. 검사용 전부 표시 상태는 메모리에만 존재하고 사용자 저장 파일/지도 JSON에는 쓰지 않았다.

## 검증

Godot4.7.1, 격리된 APPDATA 및 가져오기 프로젝트.

- 가져오기2회 SCRIPT ERROR/ERROR0, 전체 스크립트/씬870개 로드 실패0(기존 NUL 경고4 유지).
- check_recovered_village_art GPU618 검사 실패0: 원본29 SHA, 비자리표26경로 연결, 기존 사과나무, 모든 기본27방향 렌더·마스크·노멀·보행/바닥충돌, 실제90배치 및 저장된 앞뒤 지붕색, 편집 색 변경 즉시 반영, 대장간/도구점/게시판/노점 접근가능, 밤 가로등 표시, 새게임 해금 유지.
- 공용 인물1809 검사 실패0, 마을 일과 failures0, 마을 시장58 검사 실패0.
- 실행PNG34 규격/알파/96색 이하, 복구원본29 및 기존 실행9 SHA 보존 확인.
- 에셋 FAIL0 WARN28(기존), balance_baseline 실행(하루손님27.0·경제수치 변경 없음).

검사 장면의 최초 실행은 튜토리얼 종료 지형 전환이 검사용 시설 표시를 다시 숨겨 실패했다. 전환을 먼저 적용하도록 검사 순서를 바로잡아 재검사했다. 생산 게임의 해금 규칙은 수정하지 않았다.

## 남은 항목

[남은 그림](남은_그림.md), [목록29경로 대조](연결_대조.csv) 참조. 복구 원본26종은 더 이상 신규 미제작 목록으로 세지 않는다. 우물·담장은 기존 모델/미리보기가 있어 투명 2D 전환 검토, 계절 상태/일부 인물은 추가 그림 검토, 원정 몬스터/채집물 및 낚시 아이콘은 이미 있는 후보의 연결 후속이다. 모든 3D 표현을 제거한 완료 보고는 아니다.
