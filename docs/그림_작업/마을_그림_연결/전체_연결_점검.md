# 준비된 그림 전체 연결 후 점검

2026-10-12 · main · 사용자 요청: 연결할 그림을 모두 연결한 다음 미제작 범위를 추린다.

| 대상 | 현재 결과 |
|---|---|

| 냉장고·냉동고 메뉴 | 이미 준비된 빈 상태 가구 그림을 메뉴 아이콘으로 연결 |

원정 그림 선택 목록은 45개에서 기존 자연물 재사용 2개를 포함한 47개가 됐다. 현재 실제 원정 채집 테이블 23개 모두 2D 그림을 선택한다. 혼합 테이블 그림은 대표 채집 장소를 보여 준다. 그림에 보이는 재료가 확정 지급된다는 의미는 없으며 드롭 테이블·가격·채집 조건·시간·소진/저장 규칙은 바꾸지 않았다.

돌담은 단일 64×96 그림을 (32,16) 간격으로 반복한 하나의 텍스처로 표시한다. 개별 돌을 길게 늘리지 않는다. 반대 축은 수평 반전하며 지도에 저장된 반전 때문에 축이 다시 뒤집히지 않는다. 같은 텍스처로 색·법선·ID 마스크를 맞췄다. 기존 canonical 4×0.5칸 충돌 및 삭제된 배치·정착 해금은 유지한다.

가구 카탈로그 28종은 모두 메뉴 그림 경로가 있다. 냉장고·냉동고는 별도 아이콘을 새로 그릴 필수 항목에서 제외한다.

## 이제 남은 그림

### 정적 그림 보강

1. **개인 NPC10명 + 대장장이·현대 직장인의 추가 방향 완료(2026-10-12).** 기존 남서 PNG를 유지하고 나머지 7방향을 연결했다. 일부 방향은 좌우 반전이며 독립 원화 여부·출처는 매니페스트와 [연결 기록](../받은그림/NPC_추가_방향/게임_연결.md)에 명시했다. 걷기는 여전히 후속이다. 주인공·공용 손님8종·직원3종의 기존8방향/걷기는 유지한다.
2. **일부 주민의 앉기 자세.** 개인 NPC 중 타블렌·코르빈·이세르는 남서/남동 좌식이 있다. 오렐·피니아·라슈·엘미·바르크·세이나·델빈7명과 대장장이·현대 직장인은 전용 좌식이 없다. 실제 앉기 콘텐츠에 투입할 때 필요한 그림을 준비한다. 주인공 남녀의 의자4방향·바닥2방향 자세는 이미 연결돼 있다.

### 사용자 지침대로 보류

- 개인 NPC·몬스터의 걷기/공격/피격, 플레이어 전투·채집·낚시 동작, 물결 등의 새 애니메이션.
- 현재 배치가 없는 풍차·돔 회관·탑 주택·추가 노점의 새 디자인. 실제 콘텐츠에 사용할 때 기존 원본·모델·그림을 먼저 대조한다.
- 돌담 기둥·모서리는 현재 단일 그림을 반복하는 사용자 결정에 필수인 그림으로 세지 않는다.

현재 연결 가능한 정적 그림에서 발견했던 채집8개 선택 경로·새 돌담·냉장고/냉동고 메뉴의 미연결은 해소했다. 이 목록은 현재 사용 중인 데이터와 연결 코드를 기준으로 한다. 사용하지 않는 초안 그림이나 모든 장면의 모든 UI 배치를 완성했다고 판정하는 목록은 아니다.
