## 2. 공통 외형 제작안

- 20대 중후반으로 보이는 성인. 정확한 생년·나이는 미확정이다.
- 갈색의 중간 크기 눈과 하이라이트 1~2점, 차분하고 부드러운 인상, 눈 밑의 옅은 피로감.
- 흰 티셔츠 위에 남색 편의점 조끼와 작은 민트색 배색. 명찰·가슴 주머니의 펜. 실제 브랜드 로고 없음.
- 남성: 짙은 갈색의 짧고 살짝 헝클어진 머리.
- 여성: 짙은 갈색의 목선 길이 머리, 한쪽을 귀 뒤로 넘긴 형태.
- 가슴 위 구도, 살짝 비스듬한 자세. 첨부 시트의 따뜻한 색감·짙은 외곽선·선명한 도트·얼굴 비율을 참고한다. [캐릭터 화풍 결정](../그림_3D/캐릭터_애니메이션_준비.md) 6-2절(2026-10-08 정정)에 맞춰 시트 수준의 중간 크기 눈을 유지한다. 6-1의 대형 눈 안은 철회됐다.
- 성격 제안: 낯선 상황에서 주변을 살피고 자신이 아는 일부터 시작한다. 주민과 교류하며 편안한 미소가 늘어난다.

필드별 정식 제작값은 설정 CSV를 사용한다. 새로운 혈연·연애·전이 원인이나 이름을 추가하지 않는다. 조끼 수선·장식 변화는 후속 연출 후보이며 이번 제작 목록에 별도 의상을 추가하지 않았다.

예정 파일명은 `player_male_neutral.png`, `player_female_neutral.png` 형식이다. `planned_file`은 제작 결과를 받을 예정 위치이며 **존재하는 이미지 경로가 아니다**. 14종 모두 현재 `asset_status`는 `미제작`이다. 생성·제작은 사용자 이미지 도구에서 진행한다.

같은 외형의 표정은 캔버스·얼굴 위치·몸 자세·옷·광원을 유지하고 얼굴 표정을 바꾼다. 개별 초상화의 해상도는 아직 정하지 않았으므로 임의 수치를 데이터에 넣지 않았다. 첨부 시트의 896×448은 주민 전체 모음 크기이며 주인공 한 장의 제작 규격이 아니다.
