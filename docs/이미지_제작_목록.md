# 이미지 제작 목록과 Pixel Lab 프롬프트 (초안 v0.1)

작성일: 2026-09-30 · 관련 문서: `에셋_규격서_초안.md`(규격), `AI_협업_규칙.md`

이 문서는 **아직 이미지가 없는 항목**과 Pixel Lab에 넣을 프롬프트 초안입니다. 이미지는 사용자가 만들고 Claude/ChatGPT는 만들지 않습니다.
태그: 🟡 제안 / ❓ 미정. 목록은 `data/core/items.csv`의 `icon_path`와 실제 파일을 비교해 만들었습니다(2026-09-30 기준).

## 0. 작업 순서 제안 🟡

1. **기준 그림 정하기**: 기존 `art/items/pixel_v1/`의 진짜 픽셀 아이콘(예: `forest_herb.png`, `bread.png`)을 스타일 기준으로 삼습니다. 처음 1~2장을 만들어 기준과 비교하고 스타일을 굳힌 뒤 나머지를 만듭니다.
2. **우선순위**: (1) 첫 원정 흐름에 필요한 것 → (2) 숲 재료·상품 → (3) 광산·늪 → (4) 유적 → (5) 손님·NPC·타일.
3. 만든 파일을 `upscale_icon.py`로 64×64로 바꾼 뒤 위 표의 경로에 **그 이름 그대로** 넣고 `python tools/validate_assets.py .`로 FAIL이 없는지 확인합니다.
4. 크레딧이 소모되므로 한 번에 다 만들지 말고 5~6개씩 확인하면서 진행합니다.

## 1. 공통 스타일과 제작 방식 🟡

**목표 스타일(사용자가 고른 참고): 스타듀밸리풍.** 짙은 외곽선, 따뜻하고 채도 있는 색, 왼쪽 위 하이라이트 1~2점, 칸을 채우는 단순한 실루엣.

**제작 방식: 작은 격자로 만들어 정수 배로 확대**
1. Pixel Lab에서 **32×32**(더 굵은 도트를 원하면 16×16)로 만듭니다. 64×64로 직접 그리면 도트가 너무 잘아서 화면에서 얇고 깨져 보였습니다(2026-09-30 확인).
2. 저장 전에 `python tools/upscale_icon.py 파일.png`로 **64×64로 정확히 2배(16px이면 4배) 최근접 확대**합니다. 반투명은 자동으로 정리됩니다.
3. 결과는 `art/items/pixel_v1/`에 들어가며 파일 규격(64×64, 색 32 이하, 반투명 없음)은 그대로입니다.

공통 프롬프트(영어, 32×32 기준):

```
32x32 pixel art item icon, single object filling almost the entire canvas with minimal empty margin (tight crop), centered and bottom-aligned, transparent background,
farming-sim game style like Stardew Valley, thick dark brown outline (darker shade of the object's own color, not pure black),
warm saturated colors, chunky compact shape, 3-4 tone shading per color with a dark shadow side on the bottom-right,
one or two small white highlight pixels on the top-left, light from top-left, no drop shadow, no anti-aliasing, no dithering, 16 to 24 colors
```

- 개별 항목은 `Subject: <대상>` 형식으로 뒤에 붙입니다. 표의 "프롬프트용 대상" 열을 그대로 쓰면 됩니다.
- 색 수는 32×32 격자에서는 16~24색이 적당합니다(64×64 기준의 32색 상한은 그대로 유지).
- 물체가 작게 나오면(2026-09-30 열매 시험작) `filling almost the entire canvas, tight crop`이 빠졌는지 확인합니다.
- 실패 사례: 반투명 가장자리, 배경 그림자, 색이 너무 많음, 물체가 너무 작거나 흩어져 있음 → 프롬프트에 `chunky compact shape, touching each other`를 유지하세요.

- 파일을 넣은 뒤 Claude에게 알려 주면 `validate_assets.py` 실행, Godot 가져오기, 가방 셀 표시를 확인합니다(이 클라우드 환경에서 확인 가능한 범위).
