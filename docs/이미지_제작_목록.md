# 이미지 제작 목록과 Pixel Lab 프롬프트 (초안 v0.1)

작성일: 2026-09-30 · 관련 문서: `에셋_규격서_초안.md`(규격), `AI_협업_규칙.md`

이 문서는 **아직 이미지가 없는 항목**과 Pixel Lab에 넣을 프롬프트 초안입니다. 이미지는 사용자가 만들고 Claude/ChatGPT는 만들지 않습니다.
태그: 🟡 제안 / ❓ 미정. 목록은 `data/core/items.csv`의 `icon_path`와 실제 파일을 비교해 만들었습니다(2026-09-30 기준).

## 0. 작업 순서 제안 🟡

1. **기준 그림 정하기**: 기존 `art/items/pixel_v1/`의 진짜 픽셀 아이콘(예: `forest_herb.png`, `bread.png`)을 스타일 기준으로 삼습니다. 처음 1~2장을 만들어 기준과 비교하고 스타일을 굳힌 뒤 나머지를 만듭니다.
2. **우선순위**: (1) 첫 원정 흐름에 필요한 것 → (2) 숲 재료·상품 → (3) 광산·늪 → (4) 유적 → (5) 손님·NPC·타일.
3. 만든 파일을 위 표의 경로에 **그 이름 그대로** 넣고 `python tools/validate_assets.py .`로 FAIL이 없는지 확인합니다.
4. 크레딧이 소모되므로 한 번에 다 만들지 말고 5~6개씩 확인하면서 진행합니다.

## 1. 공통 스타일 프롬프트 🟡

모든 프롬프트 앞에 붙일 공통 문장(영어 권장):

```
pixel art item icon, 64x64, single object centered, transparent background,
1px dark outline (not pure black), light from top-left, no shadow, no anti-aliasing,
limited palette (max 32 colors), cozy fantasy style
```

- 개별 항목은 `Subject: <대상>` 형식으로 뒤에 붙입니다. 표의 "프롬프트용 대상" 열을 그대로 쓰면 됩니다.
- 실패 사례에 자주 나오는 것: 반투명 가장자리, 배경 그림자, 색이 너무 많음 → 규격서 3장 기준으로 다시 생성하거나 팔레트를 줄입니다.

## 4. 결과 확인

- 파일을 넣은 뒤 Claude에게 알려 주면 `validate_assets.py` 실행, Godot 가져오기, 가방 셀 표시를 확인합니다(이 클라우드 환경에서 확인 가능한 범위).
- 규격에 안 맞는 파일은 실패 목록으로 정리해 돌려드립니다.
