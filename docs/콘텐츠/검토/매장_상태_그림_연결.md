## 연결한 범위

- 벽·창문·출입문: `art/received/shop_shell/`의 56장(48 후보 복사 + 반복 벽/창문 면 8장).
  벽의 중앙 32px 면을 한 칸씩 이어 붙여 매 칸 끝기둥이 반복되지 않게 했다. 반복 벽면의 기준점을 바닥 경계에 맞춰 모서리에서 만나게 한다. 별도 모서리 후보는 보존하지만 겹쳐 그리지 않는다.
- 진열대 9종의 회전·허용 층별 본체 84장, 창고 선반 3종의 회전별 본체 12장.
  2026-10-11 사용자 수정에 따라 재고가 있으면 고정된 물품 배치 그림, 없으면 빈 그림으로 표시한다.
  물품 ID·수량별 합성과 상자·체크 아이콘은 사용하지 않는다. 재고 숫자는 기존 가구 UI에서 확인한다.
  기존 받은 후보의 채워진 그림 96장을 원본 그대로 추가 복사했고 회전·층에 맞춰 선택한다.
  창고 중 기존/철제8장은 정렬본의 상자 배치, 나무4장은 같은 몸체의 기존 채워진 후보를 사용한다.
  빈 그림/설계도도 각 채워진 그림의 몸체와 맞췄다.
- 건축 미리보기·설계도도 새 빈 본체를 사용한다. 비교용 예시의 상품을 실제 재고로 사용하지 않는다.
- 출입문 `door`: 실제 `DayManager.shop_open`에 따라 열림/닫힘 표시.
  생산실·창고 문은 플레이어가 해당 방에 있는 동안 열림 표시. 출입 조건/텔레포트/시간 규칙 변경 없음.
- 매장/생산실/창고의 앞벽은 플레이어 접근 시 원래 비율을 유지하며 그림과 가림 실루엣에 같은 픽셀 투명 처리를 적용한다.

카메라를 보는 이미지 평면으로 연결했으며, 기존 렌더러 전체를 제거한 것은 아니다.
게임 좌표/충돌은 96×48, 화면 바닥 표시 64×32로 유지했다.
새 런타임 매핑은 `data/art/pixel_shop_frames.json`, 픽셀 해시는 `pixel_shop_assets.json`에 있다.

- 진열대 회전은 게임 0/1/2/3 → 그림 0/3/2/1, 벽 부착 문은 벽 방향에 대응한다.

- 채워진 그림은 재고가 있음을 나타내는 고정 배치다. 실제 판매 물품의 종류·수량·모든 저장 칸을 묘사하지 않는다.
  뒤판으로 물품이 가려지는 진열대 방향은 빈 그림과 모양이 같을 수 있다.
- 상품 글리프 68장은 보존하며 생산 설비의 결과 물품 표시에만 사용한다. 진열대는 글리프를 읽어 합성하지 않는다.
- 자동 검사는 슬롯·시간·위치를 시험값으로 설정한다. 별도 새 게임 연속 검사로 실제 진행 경로도 확인했다.

## 반복 타일의 경사·띠 보정 (2026-10-10 후속)

사용자 지적대로 앞의 세로 압축 수정만으로 PNG 자체의 반복 경사까지 해결되지는 않았다.
중앙 32px 면의 윗선/밑선이 불규칙했고, 띠의 높이·두께도 열마다 달라 반복 경계에서 꺾였다.
카메라 피치 30°·방향 45°와 바닥 64×32 기준은 그대로 사용한다.

- 실행 `wall_full_0..3_tile.png`·`window_0..3_tile.png` 8장만 교체했다.
  받은 후보와 실행용 전체 원본 48장, 문·진열대·상품을 포함한 나머지 212장은 이전 SHA256 그대로다.
- 기준점 (32,104), 반복 폭 32px, 다음 타일 높이 이동 ±16px 유지.
  모든 열에 `±floor((x-32)/2)` 경사를 적용한다. 벽 높이 61px/창문 높이 39px는 펼친 면 기준이며
  타일 한 칸의 반복 양끝에서 0/1px의 정상적인 도트 경사가 이어진다.
- 원본의 색상열을 최근접으로 재배치했다. 높은 벽의 위 테두리·청록 띠·밑단과 창문의 위/아래 틀은
  방향0 원본에서 얻은 공통 수직 색상열로 맞췄다. 중앙의 벽 질감·유리·세로 창틀은 해당 방향 원본을 사용한다.
  새 색상·반투명·블러 없이 64×128, RGB32색 이하, 알파0/255, 투명 RGB0 유지.
- [보정 도구](../../../tools/art/normalize_shop_wall_tiles.py): `--write`로 원본 후보에서 재현,
  `--check`로 8장 픽셀·실루엣·띠·반복 위상·팔레트·해시 검사. 원본은 쓰지 않는다.
  매핑/개수/치수는 그대로, `pixel_shop_assets.json`의 SHA256 8개만 갱신했다.
- Godot 검사도 실제 가져온 텍스처의 모든 알파 위치와 방향별 테두리·띠의 높이를 확인한다.

  원본 알파·실루엣·등각 기준점·정렬 깊이·가림 ID는 그대로 사용한다.
- `SpriteNormalMaps`는 동일 캔버스의 기존 `*_n.png`를 우선 재사용한다(기존 지붕 맵 검사 포함).

  이는 원본에 그려진 명암을 높이로 가정한 근사이며, 작가가 만든 정확한 면/형상 노멀맵은 아니다.
  전용 맵이 추가되면 캐시 생성 대신 그 맵을 사용한다. 원본 PNG를 재그리거나 수정하지 않는다.

  인물 프레임마다 대응 맵을 연결하고, 생산 표지 여백에는 평평한 법선을 추가한다.

  저녁에는 일몰, 밤에는 약한 외부광과 가게 천장 조명을 사용한다. 기존 날씨·계절 색도 연결된다.
- 처음 시도한 공통 상자·체크 표지는 사용자가 원한 표현과 달라 삭제했다(커밋하지 않음).
