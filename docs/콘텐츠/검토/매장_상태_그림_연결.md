# 매장 상태 그림 연결
2026-10-10 · main · 사용자 요청: 1·2순위 그림을 게임에 연결하고 다음 단계로 진행.

## 연결한 범위

- 벽·창문·출입문: `art/received/shop_shell/`의 56장(48 후보 복사 + 반복 벽/창문 면 8장).
  벽의 중앙 32px 면을 한 칸씩 이어 붙여 매 칸 끝기둥이 반복되지 않게 했다. 반복 벽면의 기준점을 바닥 경계에 맞춰 모서리에서 만나게 한다. 별도 모서리 후보는 보존하지만 겹쳐 그리지 않는다.
- 진열대 9종의 회전·허용 층별 본체 84장, 창고 선반 3종의 회전별 본체 12장.
  실제 슬롯의 상품 ID·재고로 68개 상품 그림을 합성한다(현재 판매 가능 물품 81 ID).
  품절은 상품 그림 제거, 상품 변경은 해당 그림 교체, 뒤판이 있는 뒤쪽 시점은 상품 숨김.
  진열 한 칸에 최대 5개/창고 한 칸에 최대 6개를 그리며 실제 수량·용량은 기존 값이다.
- 건축 미리보기·설계도도 새 빈 본체를 사용한다. 비교용 예시의 상품을 실제 재고로 사용하지 않는다.
- 출입문 `door`: 실제 `DayManager.shop_open`에 따라 열림/닫힘 표시.
  생산실·창고 문은 플레이어가 해당 방에 있는 동안 열림 표시. 출입 조건/텔레포트/시간 규칙 변경 없음.
- 매장/생산실/창고의 앞벽은 플레이어 접근 시 원래 비율을 유지하며 그림과 가림 실루엣에 같은 픽셀 투명 처리를 적용한다.

## 다음 단계: 생산 설비의 실제 상태 표시

- 음료 제조기·화덕 원본과 회전은 유지한다.
- 대기: 원본 그림. 생산 중: 실제 결과 물품 그림과 남은 시간 기반 진행 띠.
- 완료: 결과 물품 그림·초록 띠·체크. 실제 수령 후 대기 그림으로 복귀한다.
- 표지는 투명 위 여백을 덧붙이고 몸체 바로 위에 놓는다. 원본 몸체 픽셀/기준점은 그대로다.
- 기존 생산 시간·재료·출력량·제조법 해금·직원 수령·저장 형식은 변경하지 않는다.

## 구조와 한계

`PixelShopArt` / `PixelProductionArt`가 표시만 담당한다. main의 `StoreView3D` 렌더러에
카메라를 보는 이미지 평면으로 연결했으며, 기존 렌더러 전체를 제거한 것은 아니다.
게임 좌표/충돌은 96×48, 화면 바닥 표시 64×32로 유지했다.
새 런타임 매핑은 `data/art/pixel_shop_frames.json`, 픽셀 해시는 `pixel_shop_assets.json`에 있다.
기존 147개 선택 원본과 받은 후보는 덮어쓰지 않았다.

- 진열대 회전은 게임 0/1/2/3 → 그림 0/3/2/1, 벽 부착 문은 벽 방향에 대응한다.
- 일부 생성된 뒤면과 문틀은 앞면 또는 다른 상태와 미세한 형상 차이가 남는다.
  현재 연결은 생성 도형을 재설계한 것이 아니며 문틀의 모든 픽셀이 동일하다고 보장하지 않는다.
- 상품은 보드 기준점과 본체 알파로 제한한다. 전면 기둥과 테두리의 세밀한 마스크는 후속 그림 보정 대상이다.
- 낚시 물품의 작은 진열 그림도 연결했지만 전체 인벤토리 `icon_path` 추가는 이번 범위에 포함하지 않았다.
- 자동 검사는 슬롯·시간·위치를 시험값으로 설정한다. 별도 새 게임 연속 검사로 실제 진행 경로도 확인했다.

## 사용자 화면의 찌그러짐 수정 (2026-10-10)

- 앞 창문을 낮출 때 `frame_scale.y`와 메시 세로 배율로 전체 그림을 압축하던 처리가 원인이었다.
  창틀 높이와 등각선도 함께 눌렸다. 원본 PNG 문제로 단정하지 않고 표시 코드를 수정했다.
- 원본 크기·기준점은 고정한다. 가까운 앞벽만 원본 픽셀에 맞춘 4×4 순서 디더 투명 처리로 시야를 연다.
  색상/가림 ID 셰이더가 같은 함수를 공유하며, 먼 벽과 인물·가구는 기본값 1로 원래 불투명 표시한다.
- 바닥 경계에서 벽면이 만나도록 이미지 기준점을 맞췄다. 별도 모서리를 덧씌우던 표시를 제거했다.
  방 벽의 남·북 반복 길이도 실제 바닥 칸 수에 맞춰, 벽 두께 때문에 여분 조각이 생기지 않게 했다.
- 기존 검사는 색상과 가림의 축소가 같다는 것만 확인해 잘못된 비율을 놓쳤다.
  이번에는 네 방향 벽의 실제 경계 기준점·한 칸 반복 간격·세로 압축 제거와 고정 배율을 추가 검사했다.
