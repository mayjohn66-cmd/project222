# 나눔 표시와 쉼터 모임 시간

2026-10-06 · 인수인계 24①·25 · ChatGPT

## 24①: 물품 대금과 답례 구분

다음 13건에 `payment_kind: gift`를 추가하고, 첫 장터 준비도 같은 표시를 사용한다(합계 14건).

| 흐름 | 대상 |
|---|---|
| 사계절 축제 | `festival_spring`, `festival_summer`, `festival_autumn`, `festival_winter` |
| 공동 부탁 | `well_gathering` |
| 첫 장터 후 먹거리 부탁 | `naru_market_juice`, `doyun_market_soup`, `sora_market_drink` |
| 매장 행사 뒤 부탁 | `naru_thanks_snack`, `naru_lunch_extra`, `doyun_waterside_flask`, `sora_autumn_tea`, `doyun_winter_breakfast` |
| 첫 장터 준비 | `first_market` |

게시판·축제 진행 안내·첫 장터 준비 화면에 **나눔 부탁 · 물품 대금은 별도로 받지 않습니다.**를 표시한다. 기존 완료 보상은 **답례**로 표시하며, 첫 장터의 마지막 안내도 **장터 답례**로 맞췄다. 일반 부탁은 기존 보상 표시를 유지한다.

물품 소비량·현금·재료 답례·평판·선행 조건·완료 기록·반복 규칙은 바꾸지 않았다. 저장 형식과 기존 저장의 완료 상태도 유지한다. 이번 표시는 설정과 UI에서 처리하며 대사 CSV는 수정하지 않았다. 24②·③의 Claude 완료 사항도 유지한다.

## 25: 첫 쉼터 모임 시간 확대

`VillageRestSettings`의 시작을 14시, 종료를 19시로 변경했다. **14시 이상, 19시 미만**에 첫 모임이 열린다. 주민 이동과 수첩 안내는 같은 설정을 사용한다.

준비 다음 날부터 참여할 수 있고, 놓치면 다음 오후에 다시 열린다. 준비 비용과 답례·첫 모임 평판·재방문 기록·반복 답례 없음 규칙은 그대로다. 우물 저녁 모임의 18~24시도 유지한다.

## 검증

- `check_request_payment`: 실제 게시판 13개 카드의 나눔/답례 표시, 일반 부탁 표시 유지, 첫 장터 설정, 화면 열기·갱신으로 재고·돈·진행 기록이 바뀌지 않는지 검사한다.
- `check_village_market`: 실제 E 상호작용으로 연 준비 화면의 표시와 기존 답례를 검사한다. 기존 정확한 소비·완료 지급·중복 차단 검사도 유지한다.
- `check_village_rest`: 13·14·18·19시 경계, 14~19시 안내, 14·18시 주민 목적지와 실제 이동, 기존 저장·지급·재방문을 검사한다.
- `check_village_gathering`: 기존 우물 모임과 중복 지급 방지를 회귀 검사한다.

최종 실행 결과는 `docs/AI_인수인계.md`의 24·25번 완료 근거에 기록한다.
