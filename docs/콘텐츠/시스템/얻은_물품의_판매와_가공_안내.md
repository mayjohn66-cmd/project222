# 얻은 물품의 판매와 가공 안내

2026-10-08 콘텐츠 보강. 원정·낚시·첫 장사에서 얻은 물품을 인벤토리에서 선택하면, 그 물품으로 지금 가능한 행동을 알려준다. 기존 가격·제조법·상품 수요·진열·보관 규칙을 읽어서 표시한다.

## 플레이 흐름

1. 물품을 얻고 관리 책의 인벤토리에서 선택한다.
2. 재료가 진열 가능한 상품이면 가공하지 않고도 진열해 팔 수 있음을 확인한다. 소지품은 실제 진열대에 다가가 E로 보충한다. 손님이 집고 계산하면 판매된다.
3. 창고 선반에 넣어 둔 재고는 선반에서 직접 꺼낸다. 냉장·냉동 재고와 상온 변형·유통기한 주의는 기존 보존 규칙에 따라 표시한다.
4. 생산실 소개를 듣고 제조법을 배운 뒤에는 해당 재료의 가공 결과와 완제품의 제작 상태를 확인한다. 실제 제작은 기존 설비에서 한다.
5. 지금 알고 있거나 수락한 부탁·매장 소문이 해당 물품과 연결되면 기존 맥락을 함께 보여준다.

## 공개·재고 기준

- 아직 생산실 안내를 듣지 않았다면 물품 상세에서 미래 제조법을 미리 공개하지 않는다. 초기 편의점 상품에도 일괄적으로 ‘제작’이라고 쓰던 문구를 현재 상태에 맞춰 바꿨다.
- 제조법은 `ProductRecipeData.get_learned_recipes()`의 현재 학습 결과만 사용한다. 배워야 할 조리법을 잠금 목록처럼 노출하지 않는다.
- ‘소지’는 가방의 물품 수, ‘진열’은 실제 가게 진열대 수, ‘창고 선반’은 물리적 보관량이다. 세 수량을 합쳐 한 재고처럼 보이지 않는다. 냉장·냉동은 기존 보존 데이터를 따른다.
- 생선은 실제 낚시 경로를 표시한다. 판매할 수 없는 장비는 가게 상품이 아니라고 안내한다.
- 상세창을 읽는 행위는 물품 이동·학습·부탁 완료·보상을 일으키지 않는다. 새 경제 값, CSV, 대사 ID, 저장 필드, 그림은 추가하지 않았다.

## 연결과 검증

- 화면: `script/ui/management/inventory_detail_pane.gd`의 기존 가격·설명 아래에 현재 행동을 표시한다. `InventoryItemGuide.ENABLED`로 새 안내를 되돌릴 수 있다.
- 코드: `script/ui/management/inventory_item_guide.gd`.
- 검사: `dev/scenes/check_inventory_item_guide.tscn`에서 첫 장사, 실제 진열·창고·보존, 제조법 학습 전후, 장비와 생선, 저장 왕복, 작은 화면을 확인했다. 53개 항목 실패 0, 실제 화면 실패 0. Godot import 2회와 전체 776개 파일 로드 실패 0. 기존 가구 47·상품 준비 56·메인 통합 88도 실패 0.
