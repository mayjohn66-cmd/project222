# 상품을 준비하는 관리 책

2026-10-08 · 사용자 「차례대로 콘텐츠 보강」 승인에 따라 직원 도입 다음 순서인 생산 화면을 구현했다. 바깥 탭 이름은 현재 **생산**을 유지한다.

## 공개와 사용 순서

| 단계 | 표시하는 내용 |
|---|---|
| 핵심 튜토리얼 | 생산 탭을 숨긴다. 직접 진열·계산·원정 재료 판매부터 경험한다 |
| 타블렌의 첫 제작 안내 | 배운 상품과 필요한 생산실을 안내한다 |
| 생산실 문 설치 | 첫 화덕 설치와 실제 재료 준비를 안내한다 |
| 화덕의 현지식 빵 수령 | 기존 순서대로 다른 생산 설비·창고 준비를 공개한다 |
| 제조법 습득과 주민 교류 | 배운 상품, 맡은 부탁과 이미 들은 행사 소문을 연결한다 |

새 기능은 기존 공간 진행 조건을 읽는다. 화면을 열거나 상품을 선택한 것으로 생산실·창고·부탁·튜토리얼을 완료하지 않는다.

## 세 페이지

- **오늘의 준비:** 맡은 부탁·시제품 이야기·들은 소문이 연결된 상품을 먼저 보여 준다. 그다음 지금 만들 수 있는 상품을 우선하며 준비 가능 필터를 제공한다.
- **배운 상품:** 사용할 수 있는 제조법만 이름순으로 확인한다. 1회 출력 수량·가공 시간·필요 설비·재료 수량·부족분을 실제 제조법 데이터에서 읽는다. 모르는 상품과 아직 열리지 않은 현대 상품은 숨긴다.
- **설비 현황:** 실제 설치한 설비의 위치와 대기·가공·수령 상태, 가공 중인 상품과 남은 시간을 확인한다. 미설치 설비는 공개 조건을 만족하며 배운 상품에 필요한 종류만 표시한다. 같은 설비가 여러 대면 각 대의 위치와 상태를 구분한다.

설비가 부족하면 설치, 다른 설비를 공개하기 전이면 첫 상품 수령, 사용 중이면 가공 완료, 완성품이 남아 있으면 수령을 안내한다. 조리와 무관한 상품에 「반죽 → 굽기」 같은 고정 설명을 사용하지 않는다. 물고기별 제조법은 실제로 선택할 재료가 다르므로 해당 물고기 이름을 유지한다.

## 재료와 보관

재료는 **소지 / 1회 필요량 / 부족분**으로 표시한다. 실제 창고 선반의 재고와 설치된 냉장·냉동 설비의 보관 재고는 따로 표시하고 「꺼낸 뒤 사용」을 안내한다. 보관 수량을 소지 수량에 합산하지 않는다.

제작 시작과 완성품 수령은 책을 닫고 실제 설비에서 **[E]**로 진행한다. 메뉴에서 원격 제작·수령하거나 임의로 재료를 지급하지 않는다. 가공하지 않고 원정 재료를 진열하는 기존 초반 판매도 유지한다.

화면은 열려 있는 동안 실제 재료·보관 재고·제조법·이야기·설비 상태를 갱신한다. 목록과 상세는 각각 스크롤하며 가운데 제본 공간을 비운다. 가공 시간 갱신 중에도 살펴보던 스크롤 위치를 보존한다.

## 알려진 이야기만 연결

주민·정착·마을·개인 부탁과 제품 시제품의 **수락 후 미완료** 항목을 실제 요구 아이템과 연결한다. 부탁/시제품 수량은 기존 설정값을 표시한다. 낚시 부탁·이벤트는 수락한 항목의 아이템 또는 선택 그룹과 연결한다. 그룹 후보를 모두 내야 한다고 안내하지 않는다.

매장 행사는 현재 회차의 소문을 실제로 들었고 준비 또는 행사 기간인 경우만 기존 이야기의 상품 힌트를 사용한다. 행사 중·마지막 날에도 처음 들은 힌트를 유지하고 종료 후에는 준비 추천을 없앤다. 지난 회차에서 들었다고 다음 회차 소문까지 공개하지 않는다. 일정·수요 배율·예상 이익을 새로 예고하지 않는다.

배운 곳은 실제 시제품 수락/완료 기록, 첫 제작 안내, 완료한 물가 배움에서 확인되는 경우에만 설명한다. 배운 두루마리가 연결돼 있지만 습득 경로가 기록되지 않은 제조법은 「관련 두루마리」라고 표시해 해당 두루마리를 사용했다고 단정하지 않는다. 기본 제조법은 기본 사용 가능한 것으로 표시한다.

## 저장과 전달

새 저장 필드나 콘텐츠 ID를 추가하지 않는다. 기존 배운 제조법·이야기·보관·설비 저장을 읽어 화면을 다시 만든다. 이미 공간을 사용한 이전 저장의 제조법과 공간 접근을 소급 잠그지 않는다. 비용·급여·제조법 재료와 시간·출력량·보상·수요 데이터는 변경하지 않는다.

새 런타임 대사나 Gemini 글 종류를 등록하지 않았다. 기존 부탁 제목·행사 글·제작 안내를 재사용한다. 앞으로 문장을 다듬을 때도 실제 소지 재료와 현장 제작·수령을 기준으로 하며 원격 자동 생산을 약속하지 않는다.

다음 보강 대상은 기존 집기의 설명과 활용이다. 새 설비·치장·가격·이미지 제안은 이 작업의 구현 완료 범위에 포함하지 않는다. 관련 설계: [관리 책의 단계별 설계 방향](관리_책의_단계별_설계_방향.md).
