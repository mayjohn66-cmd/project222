# 원정 전 가게 운영 확인

2026-10-09 · 구현 완료 · `main` @ 36274fd.

## 1. 다음 원정을 준비하는 경험

원정 장비를 준비한 플레이어가 가게를 비울 때의 운영도 확인할 수 있게 한다. 초반에는 직접 계산하므로 가게를 닫고 재료를 구하러 다녀오는 선택을 설명하고, 직원과 함께 일하기 시작하면 맡길 수 있는 시간대를 기존 근무표로 보여 준다.

원정 준비에서 목적지를 고르면 가방 아래 **가게 운영 확인** 버튼이 나타난다. 기존 **장비 사용 안내**와 별도로 선택해 읽고, 닫은 뒤 출발하거나 원정 준비 오른쪽 위의 닫기 버튼으로 가게에 돌아간다. 안내를 읽는 것은 출발 조건이 아니다.

## 2. 실제 기록을 읽는 기준

| 내용 | 데이터와 판정 |
|---|---|
| 출발 시각·영업 상태 | `shop_return_context.hour`·`minute`·`was_open`. 매장에서 원정 준비로 이동할 때 남긴 기록 |
| 직원 | 기존 `EmployeeData`의 직원 ID와 `GameState.employee_states`. 고용된 직원만 이름 표시 |
| 시간대별 담당 | 기존 `EmployeeData.get_period_at_hour`와 직원의 `work_periods`. 실제 `Worker.is_hour_in_shift`·복귀 정산의 직원 판정과 대조 |
| 조회 범위 | 출발 시각부터 `GameConfig.DAY_START_HOUR`의 다음 하루 정산까지. 시작한 시간대만 일부 표시하며 자정과 정산 경계를 넘어 그다음 날의 근무를 펼치지 않음 |
| 저장 호환 | 이전 저장의 비어 있는 직원 상태는 기존 초기 고용/근무표를 조회만 함. JSON 체크포인트의 정수 값 float 시간도 지원 |
| 기록 없음/오류 | 출발 기록이 없으면 영업 상태를 추측하지 않고 가게에서 확인하도록 안내. 잘못된 직원 기록은 담당이 있다고 확정하지 않음 |

시간대 시작 시각과 정산 시각은 기존 설정을 읽는다. 미래의 원정 길이·매출·판매 건수를 예측하지 않는다. 시간표는 실제 담당을 확인하는 자료이며, 원정 중 다음 시간대까지 머무르는지는 플레이어가 정한다.

## 3. 상태별 안내

| 상태 | 플레이어에게 알려 주는 내용 |
|---|---|
| 닫고 나옴 | 원정 중 손님을 받지 않는다. 직원이 없어도 재료를 구하러 갈 수 있으며 실제 원정 시간만큼 가게 시간이 흐른다 |
| 영업하며 나왔으나 담당 없음 | 플레이어가 원정 중에는 직접 계산하지 못해 그 시간의 손님을 놓친다. 가게로 돌아가 닫고 떠나거나 아침 정비 때 기존 직원 근무표를 준비할 수 있음 |
| 일부 시간만 담당 있음 | 담당과 비는 시간대를 구분. 빈 시간대까지 머무르면 손님을 놓침 |
| 다음 정산까지 담당 있음 | 근무표에 담당은 있지만 실제 진열 재고가 있어야 판매 가능. 모든 상품 판매나 고정 매출을 보장하지 않음 |
| 기록 확인 불가 | 가게로 돌아가 문 상태와 근무표를 직접 확인 |

근무표 변경은 현행 규칙대로 **아침 06:00, 문을 열기 전 정비 시간**에 한다. 이 안내에서 직원 고용·해고·근무표 적용·영업 여닫기를 실행하지 않는다. 보유 재료가 자동으로 진열되거나 판매된다고 설명하지 않는다. 실제 직원이 없는 초반에도 이후 지원자 전체 목록을 미리 보여 주지 않는다.

가게에서 나오며 매장 씬의 문이 닫히는 처리와, 원정 중 영업 정산에 쓰는 `was_open` 기록을 구분한다. 화면 문구는 “출발 전 가게 기록 / 영업하며 나옴 / 닫고 나옴”이다. 현재 매장 씬의 문을 원격으로 확인하는 기능으로 표현하지 않는다.

## 4. 화면·상태 보호

- 기존 장비 안내의 본문 스크롤·고정 닫기·화면 맞춤·Esc/Tab/Enter·배경 입력 차단을 재사용한다.
- 안내는 자동으로 띄우지 않는다. 목적지 선택 전과 원정 길을 걷는 동안에는 상세 버튼이 숨겨진다.
- 두 안내 버튼과 원정 출발 버튼이 겹치지 않도록 배치한다.
- 실제 출발 버튼 클릭과 R/E/F5 등 뒤 화면 단축키를 차단한다. 안내를 닫으면 해당 진입 버튼으로 포커스가 돌아간다.
- 가방/준비 화면이 숨겨지거나 씬이 종료되면 별도 레이어도 정리한다.
- 열린 동안 변경된 기록을 다시 조회하며 내용이 같으면 스크롤 위치와 목록을 유지한다.
- 조회로 판매 정산·소비·지급·시간 진행·진열 이동·고용·이야기 완료·저장 파일 쓰기를 수행하지 않는다.
- `ExpeditionShopReadinessGuide.SHOP_ENABLED = false`로 이 안내만 끌 수 있다. 필수 저장 필드·버전·CSV 수치·가격·보상·이미지·대사 ID 변경은 없다.
