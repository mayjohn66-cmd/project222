# 직원의 첫 만남과 출근

2026-10-08 · 사용자 「1번부터 콘텐츠 보강」 승인에 따른 직원 도입 구현. 기존 직원 3명과 18장면을 사용한다.

## 실제 진행

| 경험 | 다음에 공개하는 내용 |
|---|---|
| 핵심 튜토리얼 완료 | 첫 지원자가 가게 앞의 연결된 빈 길로 걸어온다 |
| 가까이에서 [E] 소개 완독 | 그 사람만 고용 후보에 표시, 계약 조건 확인 가능 |
| 아침 6시 문 열기 전 계약 확정 | 근무표·직원 정보, 직접 시간대 선택 안내 |
| 근무 시간대를 직접 적용 | 첫 출근을 기다리도록 안내, 교육은 아직 숨김 |
| 가게를 열어 실제 출근 완료 | 첫 근무 장면과 교육 탭, 다음 아침 교육 안내 |
| 교육·해고·재고용 | 기존 비용·급여·기억·교육 유지 규칙 사용 |

직원 1 소개를 마친 다음 날부터 직원 2, 다시 그 다음 날부터 직원 3이 방문한다. 고용은 다음 방문의 필수 조건이 아니다. 처음 인사를 미루거나 소개 중간에 「나중에 · Esc」로 닫아도 비용·관계 손실은 없으며, 지원자와 다시 [E]로 이야기할 수 있다. 가게 문에서 떨어진 장소를 골라 지원자가 플레이어에게 너무 붙어 나타나지 않도록 하고, 막힌 길은 방문을 소비하지 않고 재시도한다.

지원자는 별도 이야기 인물로 표시한다. 실제 직원 그룹이나 구매 손님 그룹에 넣지 않아 임금·결제·재고·판매 통계에 포함하지 않는다. 기존 직원 스프라이트와 3D 직원 외형을 재사용하며 이미지 파일을 추가하지 않는다.

## 계약과 관리 화면

- 고용하지 않아도 직접 계산하며 모든 핵심 이야기를 진행할 수 있다. 생산실·창고를 직원의 선행 조건으로 묶지 않는다.
- 고용 후보에는 소개를 마친 사람과 이전 고용 기록이 있는 사람만 표시한다. 직접 고용 함수도 만남 조건을 검사한다.
- 후보 카드와 함께 일하는 직원 카드에 구분 문구를 표시한다. 고용·해고에서 이야기·계약을 살피고, 정보에서 근무·능력·급여를 확인한다.
- 대상이 없는 근무표·정보·교육 탭은 숨긴다. 미지급 급여가 남아 있으면 정보의 전체 급여 확인은 유지한다.
- 실제 첫 출근 뒤에만 해당 직원의 교육을 허용한다. 메뉴 버튼, 정보 탭, 직접 교육 함수로 이 순서를 건너뛸 수 없다.
- 고용비 0/0/100 G, 28일 급여 1000/1200/1400 G, 교육 단계·비용, 이어진 최대 2타임, 빈 근무표에도 급여 누적, 해고 후 교육·누적 급여 유지, 계절 말 정산은 그대로다.

## 저장과 끄기

`PlayerProgress.story_beat_days`에 `employee_recruitment:v1`, `employee_recruitment:met:<직원 ID>`, 이전 저장 호환용 `employee_recruitment:legacy_access:<직원 ID>`를 기록한다. 새 게임은 이 기록을 초기화한다. 방문자의 화면 위치는 저장하지 않고 재시작 시 아직 만나지 않은 다음 지원자를 다시 방문시킨다.

처음 이 기능을 적용할 때 기존 고용·교육·소개·이전 계약·근속 기록을 확인한다. 해당 후보는 다시 인사를 강요하지 않는다. 기존 고용·교육·근속 기록의 교육 접근은 별도 호환 키로 보존하고 실제 첫 출근 장면을 소급 완료하지 않는다. 돈·교육 수준·근무표·급여 기록을 초기화하지 않는다. 이후 저장부터는 새로 계약했다고 교육을 바로 열지 않는다.

`EmployeeStorySettings.recruitment_enabled`를 false로 바꾸면 방문을 끄고 만남·첫 근무에 따른 제한을 해제한다. 방문 간격·재시도 시간·문에서의 거리·상호작용 거리는 같은 설정 리소스에 있다. 현재는 하루 간격, [E] 거리 70이다.

## 글 다듬기 전달

기존 `service_text`의 `worker_001/002/003_intro`, `hired`, `first_shift` 장면을 우선 다듬는다. 새 이름·능력·답례·무료 교육을 약속하지 않는다. 소개는 가게 앞에 찾아와 일할 의사를 전하는 장면, 계약은 비용과 급여를 확인한 선택, 첫 근무는 실제 출근 이후의 경험이다. 설정 리소스의 intro 조건을 이 진행에 맞춰 갱신했다. 새 대사 ID·글 종류·가격을 추가하지 않는다.

## 검증

Godot 4.7.1의 분리된 새 게임 데이터로 검사한다. `dev/scenes/check_employee_recruitment.tscn`은 실제 방문 이동·공통 [E]·미루기/재개·계약·직원별 공개·실제 출근·다음 날 방문·저장 복원·기존 저장 호환을, `check_employee_content.tscn`은 계약 재검사·교육 비용·해고/재고용·급여·18장면 등록을 확인한다. 실제 사용자 저장은 사용하거나 덮어쓰지 않는다.
