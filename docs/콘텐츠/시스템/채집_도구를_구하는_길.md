# 채집 도구를 구하는 길

2026-10-09 콘텐츠 동선 점검. 첫 주민 부탁 `traveler_water`는 채집한 물 2개를 요구한다. 물 채집 규칙 `gather_water`에는 효과 `collect_water`의 도구가 필수다. 기존 데이터에는 채집용 물병(`gathering_bottle`)이 원정 상점 80 G에 있으나, 상점 화면이 원정 준비에 연결되지 않아 게임에서 살 수 없었다.

## 실제 플레이 흐름

1. 첫 손님에게 시작 상품을 팔고, 타블렌과의 기존 검·갑옷 물물교환을 마친다. 처음 판매하는 생수 1개의 현재 판매가는 100 G로 물병 80 G를 살 수 있다.
2. 원정 출발 화면 왼쪽의 **원정 상점**을 연다. 기본으로 보이는 **도구** 탭에서 채집용 물병을 산다. 낫도 기존 120 G 가격으로 구매할 수 있다.
3. 산 물병은 보유 장비에 생긴다. 원정 준비의 가방 정리에서 물병을 가방에 넣고 출발한다. 보유만 하고 가방에 넣지 않았다면 물을 뜰 수 없다.
4. 숲 등 물 채집 지점에서 물을 모아 돌아온 뒤 라슈에게 채집한 물 2개를 전달한다. 일반 생수(`water`)와 채집한 물(`raw_water`)은 별개다.
5. 부탁 수첩의 물품 준비 안내에도 필수 물병과 구매 위치·가방 준비를 적는다. 기존에 진행 중인 저장도 같은 원정 상점에 접근할 수 있다.

## 연결과 검증

- `scenes/expedition/prep/prep_shop.tscn`의 기존 상점과 기존 구매 처리를 원정 준비 화면에 표시한다. 가격·상품·지급 방식은 기존 CSV/코드를 그대로 사용한다.
- `script/ui/expedition/prep/expedition_supply_access.gd`가 열기·닫기와 화면 겹침을 맡는다. `ENABLED`로 연결을 되돌릴 수 있다. 물병 필수 조건은 `expedition_gathering_tool_guide.gd`가 현행 채집 규칙과 상점 목록에서 읽는다.
- 새 게임 흐름에서 최초 0 G, 타블렌 물물교환, 기존 판매가, 구매 80 G, 개별 도구 생성, 중복 구매 차단, 가방 이동, 실제 물 채집, 주민 부탁 소비·중복 차단, 저장 왕복을 확인했다. 새 검사 35개 실패 0(실제 화면 포함), 기존 원정 자동 진행 16판 막힘 0, Godot import 2회 및 전체 780개 파일 로드 실패 0.

추후 Claude는 초기 판매 수익·물병 80 G·라슈의 채집한 물 2개 요구가 현재 경제와 대사에 맞는지 검토한다. 초기 검·갑옷 교환 구성과 주민 부탁 답례는 이번 연결에서 바꾸지 않았다.
