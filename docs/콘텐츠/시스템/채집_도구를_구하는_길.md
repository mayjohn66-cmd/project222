# 채집 도구를 구하는 길

2026-10-09 사용자 수정 방향 적용, `main` @ 4cf5c75. 채집한 물을 부탁하기 전에 도구를 파는 NPC와의 교류가 먼저 있어야 한다. 이전 `da830d7`의 익명 원정 준비 상점 연결은 비활성화하고, 기존 행상인 타블렌의 노점에 실제 도구 판매를 연결했다.

## 실제 플레이 흐름

1. 기존 도입·첫 판매·타블렌의 검과 갑옷 물물교환·첫 원정을 마친다. 도입 보상과 상품 제작 해금은 바꾸지 않는다.
2. 오렐에게 야생 열매 2개를 나눈다(`neighbor_bread`). 다음에는 엘미가 숲 약초 3개를 부탁한다(`gatherer_herbs`). 이 두 부탁은 필수 물 채집 도구 없이 진행할 수 있다.
3. 두 부탁을 완료하면 기존 손님 해금 조건으로 타블렌이 다시 방문한다. 가게를 열어 실제 손님으로 맞이하고 인사를 나눈다. 새 손님이 아직 방문하지 않았다면 안내판이 개점을 안내한다.
4. 타블렌에게 마른 가지 4개를 전달해 노점 자리를 마련한다(`settle_naru`). 노점에 나타난 타블렌에게 처음 안부를 나눈다. 기존 인연·선물·재료 교환 해금은 유지한다.
5. 타블렌의 노점 가까이에서 **[E]**를 누르면 **타블렌의 노점 · 도구와 재료**가 열린다. 채집용 물병(`gathering_bottle`)은 기존 80 G, 낫은 기존 120 G다. 재료 교환 항목은 같은 화면 아래에서 스크롤로 확인한다. 닫기 버튼은 화면에 고정된다.
6. 물병을 구하면 라슈의 채집한 물 2개 부탁이 열린다(`traveler_water`). 산 물병은 **보유 장비**에 들어가므로 원정 준비에서 **원정 가방**에 넣고 출발한다. 보유만 한 물병으로는 물을 뜰 수 없다.
7. 물 채집 지점에서 채집한 물(`raw_water`)을 모아 돌아온 뒤 창고 재고로 전달한다. 시작 생수(`water`)와는 별개다. 부탁 수첩에서도 타블렌 구매 위치와 가방 준비를 안내한다.

오렐·엘미·타블렌 정착 부탁의 기존 답례는 합계 110 G로, 다른 지출이 없다면 물병 80 G를 살 수 있다. 첫 판매 수익도 기존대로 쓸 수 있다. 소지금이 부족하면 모은 재료를 진열해 판매하도록 안내한다. 새 무료 도구나 추가 현금 보상은 없다.

## 이전 저장과 예외

- 기존 부탁 ID·수락·완료·평판 기록을 유지한다. 이미 완료한 물 부탁을 다시 요구하지 않는다.
- 이미 수락한 물 부탁에서 도구나 필요한 물을 준비했다면 바로 이어서 진행할 수 있다. 도구와 물이 모두 없다면 수락 기록을 남긴 채 엘미와 타블렌을 먼저 만나고 준비 뒤 라슈로 돌아간다.
- 새 순서에서 타블렌의 노점을 이미 마련했고 필요한 물을 다른 정상 경로로 구했다면 물병을 다시 사도록 강제하지 않는다.
- 보유 장비와 저장된 원정 가방의 같은 효과 도구를 함께 검사해 중복 결제를 막는다. 가방의 개별 장비 ID도 기존 저장 형식을 따른다.
- 타블렌과 다른 주민들의 기존 이야기·안부·교환 한도는 유지한다. NPC 이야기 대신 무조건 상점 창을 여는 변경은 하지 않았다.

## 구현과 검증

- `default_resident_requests.tres`: 오렐 → 엘미 → 라슈 순서. 기존 6개 부탁·아이템·수량·답례·손님 해금 2/4/6회는 유지한다.
- `resident_merchant_supply.gd`: 기존 도구 상품·가격 조회, 타블렌 노점·안부 조건, 도구 효과 중복 검사, 개별 장비 구매, 물 부탁 준비 조건과 다음 행동 안내. `ENABLED`로 이번 판매·준비 조건을 끌 수 있다.
- `resident_trade_panel.gd`·`resident_trade_director.gd`: 기존 노점 화면에 도구 구매 항목과 보유금·구매 결과를 연결한다. 기존 교환 처리는 그대로 사용한다.
- `resident_request_flow.gd`·`resident_request_director.gd`: 도구 없는 물 부탁의 연기, 이전 수락 보존, NPC 재방문·노점·안부·구매의 다음 행동 안내.
- `expedition_supply_access.gd`의 익명 상점 연결은 `ENABLED = false`. 기존 상점 씬·구매 코드는 삭제하지 않았다. 도구 안내는 타블렌의 노점을 가리킨다.
