# 냉장함·냉동함 가구 (2026-10-05)

관리 메뉴의 고정 설비였던 냉장함·냉동함을 **가게에 놓는 3D 가구**로 만들었다. 보존 규칙(`default_preservation.tres`, `PreservationService`)은 그대로다.

| 가구 | 크기 | 제작 재료 | 3D 모델 |
|---|---|---|---|
| 냉장함 `fridge_unit` | 1×1 | 철광석 8, 수정 원석 3 | 흰 세로형 냉장고, 유리문과 선반·풀잎 상자, 표시등 |
| 냉동함 `freezer_unit` | 2×1 | 철광석 12, 수정 원석 5 | 낮고 긴 상자형, 유리 뚜껑 아래 얼음, 온도창 |

- 제작: 보강 나무 집기를 한 번 만든 뒤(`furniture_progression.csv`, family `decoration`, stage `modern`) 제작 화면 "매장" 분류에서 만든다. 아이콘 이미지는 아직 없다(`icon_path` 빈 값, 3D 미리보기로 표시).
- 사용: 가구에 가까이 가서 상호작용(`player.try_interact_with_preservation_unit`) → `PreservationPanel.open_for_unit`. **가구를 처음 열면 설치 대금 없이 설치**된다(제작 비용이 곧 설치). 기존 관리 메뉴의 "냉장·냉동 보관" 버튼과 설치 대금 120/240 G 경로는 그대로 남아 있다.
- **보관함은 설비당 하나**다. 같은 종류를 여러 대 놓아도 총 12개를 같이 쓴다(저장 형식을 바꾸지 않기 위한 단순화). 대수에 따라 용량을 늘릴지는 ❓미정.
- 구현: `scenes/shop/objects/preservation_unit.tscn`, `script/objects/shop/preservation_unit.gd`(decoration 상속), 모델은 `FurnitureAssets._fridge/_freezer`. 변형 가구 공통 모델(`FurnitureVariantAssets`)보다 전용 모델이 먼저 쓰이도록 `FurnitureAssets.build`의 순서를 바꿨다.
- 검증: `dev/scenes/check_preservation_unit.tscn`(17건), `check_furniture_objects`(563건, 등록 가구 10→12), 통합 검사. 소프트웨어 렌더로 모델 확인. 실제 GPU/PC 확인은 아직.
