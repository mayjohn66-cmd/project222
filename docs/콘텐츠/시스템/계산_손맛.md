# 계산 손맛 — 스캔 타이밍·손님 인내심·팁 (2026-10-13)

> 사용자 결정(2026-10-13): **권장 조합(손님 인내심 + 스캔 타이밍), 직원은 지금처럼 평균 속도, 팁 5%, 간편 계산 옵션.** 직접 플레이로 확인하기 전이다.

## 하는 일

- 계산대에서 손님이 기다리고 있을 때 **E → 스캔 막대**가 나온다. 흰 커서가 막대를 오가며, **노란 칸(완벽)** 에서 E를 누르면 팁이 붙고 **초록 칸(보통)** 에서 누르면 팁 없이 계산된다.
- 빗나가면 목표 위치가 바뀌어 **다시** 눌러야 한다. **2번 빗나가면** 자동으로 계산되고 팁은 없다(막히지 않는다).
- 커서는 **실제 시간**으로 움직인다(배속을 올려도 같은 손놀림).
- **팁 = 결제 금액의 5%(올림, 최소 1G)**, 완벽일 때만. 영업 결산에 "받은 팁"이 나온다.

## 손님 인내심

- 계산대 앞에서 **40초(게임 속)** 기다리면 "됐어요, 그냥 갈게요." 하고 **물건을 두고 나간다**(매출 손실, 결산에 "기다리다 지쳐 나간 손님"). 절반(20초)쯤 지나면 한 번 재촉한다.
- **계산 중(플레이어·직원이 서 있는 동안)에는 줄지 않는다.** 줄어드는 건 아무도 계산대에 서지 않았을 때뿐이다.
- 예외(기다려 준다): 튜토리얼 손님, 이야기 손님(단골·원정 만남·날씨 인사), 매장 행사 손님.

## 기본값은 간편 계산 (2026-10-13 사용자 결정)

- 직접 플레이로 확인하지 못한 기능이라, **처음 하는 사람에게는 기존 방식(E로 진행 막대, 자동 결제)이 기본**이다. 스캔 타이밍과 팁은 설정에서 **간편 계산을 끄면** 쓴다. 설정 파일에 값이 없으면 간편 계산이 켜져 있다. 손님 인내심은 어느 쪽이든 적용된다.

## 직원·간편 계산

- 직원은 **지금처럼 1.2초 자동 계산**(스캔·팁 없음). 플레이어가 직접 하면 팁 때문에 이득이 있고, 직원이 맡으면 안정적이다.
- **설정 → 간편 계산**을 켜면(기본값) 스캔 없이 예전처럼 E로 진행 막대가 차서 자동 결제된다(팁 없음). 인내심은 그대로다. 설정 파일 `gameplay/simple_checkout`에 저장된다.
