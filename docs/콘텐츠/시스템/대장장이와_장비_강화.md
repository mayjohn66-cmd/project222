# 대장장이와 장비 강화

2026-10-09 · 사용자 승인 방향의 구체 설계 · 기준 `main` @ dd93be0.

**이번 파일은 설계이며 게임에는 아직 연결되지 않았다.** 단계별 조건·기존 수치·NPC 역할·구현 순서는 [설계 JSON](대장장이와_장비_강화.json)에 정리했다. JSON은 실행 설정이나 기존 대사 조건 파서의 입력이 아니다.

## 1. 플레이어가 경험할 흐름

편의점에 적응하고 원정 재료를 팔던 플레이어가, 이웃을 통해 장인을 소개받는다. 익숙한 장비를 손질하는 선택이 생기고, 작업장을 함께 마련하면서 가게 주변에 일하는 이웃이 늘어난다.

```mermaid
flowchart LR
    A[타블렌의 도구 판매] --> B[라슈의 물 부탁 완료]
    B --> C[원정에서 광석을 얻고 복귀]
    C --> D[타블렌의 소개]
    D --> E[대장장이와 첫 만남]
    E --> F[기존 대장간 마련 부탁]
    F --> G[NPC 제작·강화 서비스]
    G --> H[선택형 첫 강화와 복귀 뒤 안부]
```

광석을 물 부탁보다 먼저 얻었다면 복귀 기록을 보관하고 앞선 흐름이 끝난 뒤 소개한다. 광석을 이미 판매했어도 소개가 사라지지 않는다. 강화는 선택형 성장 요소이며, 첫 강화 체험을 미뤄도 영업·원정·주민 부탁을 계속할 수 있다. 소개 장면이 기존 부탁이나 계산대 수리 이야기를 가로채지 않는다.

## 2. NPC 역할

| 인물 | 담당 | 장면에서 맡을 일 |
|---|---|---|
| 타블렌 | 도구 판매·소개 | 물병과 낫을 판매하고 장인의 소식을 전한다. |
| 코르빈 | 광석 교류·작업장 준비 | 기존 대장간 부탁을 제안하고 광석·자리 마련을 돕는다. 광석 자동 공급 보상은 추가하지 않는다. |
| 대장장이 | 장비 제작·강화 | 장비를 살펴보고 플레이어가 맡긴 재료로 실제 작업을 한다. |
| 순회 기술자 | 마석 발전기·계산대 개조 | 기존 계산대 복구와 룬석 관련 이야기를 맡는다. |

신규 NPC 설계 ID는 `village_blacksmith`, 임시 역할 표기는 **대장장이**다. 이 ID는 아직 게임/대사/초상화에 등록되지 않았다. 실제 대화 인물의 고유 이름은 기존 이름 정책에 맞춰 후속으로 정한다. 코르빈의 기존 내부 ID `doyun`이나 인물 설정 파일을 새 대장장이로 바꾸지 않는다.

외형·성격 제작 참고 제안:

- 성인 장인의 단단한 체형, 걷어 올린 소매, 갈색 가죽 앞치마, 벽돌색 두건과 손때 묻은 망치. 성별·정확한 연령·고유 이름은 이번 설계에서 확정하지 않는다.
- 작은 수선을 소중히 여기고 쓸 수 있는 부분부터 살핀다. 능력을 자랑하기보다 물건의 상태를 구체적으로 짚는 차분한 이웃이다.
- 짧고 친근한 반말을 제안한다. NPC 관계·말투는 Gemini가 기존 이름·말투 정책과 맞춰 다듬는다.
- 타블렌은 거래를 통해 알던 사이, 코르빈은 광석과 작업장을 함께 준비하는 관계로 제안한다. 혈연·연애·전이 원인은 설정하지 않는다.
- 그림은 후속 제작 참고다. 이번 작업에서 기존 인물 그림을 덮어쓰거나 새 그림을 생성하지 않았다.

## 3. 장면과 완료 조건

새 장면 ID는 설계 예약이며 현재 글 도구에는 미등록이다. `blacksmith_progress:` 기록은 구현 때 기존 선택형 이야기 기록에 추가한다.

| 설계 장면 | 시작과 플레이 행동 | 실제 완료 | 소비·답례 |
|---|---|---|---|
| `smith_heard_naru` | 튜토리얼·타블렌 정착·물 부탁 완료 + 실제 철광석 복귀 경험. 타블렌에게 소식 듣기 | 소개 장면 완독 | 없음 |
| `smith_first_meeting` | 소개 후 외부의 접근 가능한 자리에서 NPC 인사·장비 보여주기 | 첫 만남 완독 | 장비를 가져가거나 강화하지 않음 |
| `smith_workshop_wait` | 코르빈의 기존 `open_smithy` 부탁을 맡고 준비 | 기존 공동 부탁의 정상 전달 | 기존 재료·답례만 |
| `smith_workshop_ready` | 기존 대장간에 담당 NPC가 들어옴. 서비스 설명 듣기 | 설명 완독, 제작·강화 공개 | 없음 |
| `smith_first_enhancement` | 소유 장비 선택 → 재료 확인 → 의뢰 확정 | 기존 강화 서비스가 실제로 성공 | 기존 강화 재료만, 추가 답례 없음 |
| `smith_after_first_return` | 첫 강화 이후 다시 원정에서 돌아와 짧은 안부 | 안부 완독 | 없음 |
| `smith_return_greeting` | 정착한 장인에게 다시 인사하거나 서비스 선택 | 반복 안부 또는 선택 서비스 | 안부만으로 추가 답례·할인 없음 |

첫 강화는 체험 안내다. 이를 완료해야 일반 강화 서비스나 다른 콘텐츠가 열리는 구조로 만들지 않는다. 이미 소유한 검·방어구·도구 중 강화 가능한 것을 고른다. NPC에게 보여 주기, 창 열기, 취소만으로 완료하거나 무료 강화를 지급하지 않는다.

복귀 뒤 안부에서 해당 강화 장비를 실제로 썼다고 말하려면 별도의 사용 증거가 필요하다. 증거가 없으면 돌아온 플레이어의 안부를 묻는 내용으로 쓴다.

## 4. 기존 대장간을 재사용

기존 `open_smithy`는 코르빈 정착, 안부 **7일**, `flower_corner` 완료가 필요하다. 꽃자리는 앞선 `path_light` 이후 진행한다. 요구 물품은 **철광석 5개 + 돌 조각 4개**, 기존 답례는 **평판 1 + 60 G**, 장소는 `VillageBlacksmith/Smithy`다.

이 조건·소비·답례를 그대로 사용한다. 새 대장장이를 위해 같은 시설을 다시 짓거나 별도의 건축 재료를 한 번 더 내게 하지 않는다. 코르빈은 작업장 마련 부탁의 제안자로 남고, 실제 제작·강화 담당은 새 대장장이가 된다. 기존 `open_smithy` 글의 “코르빈의 장비 작업장”과 대장간 화면의 주인 표시는 역할 분담에 맞춰 후속 교정한다.

소개는 먼저 해도 서비스는 기존 작업장 단계 뒤에 열린다. 안부 7일 조건 때문에 첫 강화까지 기다리는 시간이 생기므로 수첩은 현재 가능한 다음 행동 하나를 안내한다. 그동안 원정·영업은 계속한다. 강화가 첫 원정 필수가 되도록 난이도를 올리지 않는다. 해금이 실제 플레이에서 너무 늦다면 Claude가 경제·전투 검증 후 선행 조건 조정을 제안한다. 이번 설계는 선행 수치를 변경하지 않는다.

## 5. 강화 규칙과 첫 체험

현재 `EquipmentEnhancementService`는 **골드 비용 없이 기존 재료만 소비**한다. 조건을 충족하면 **확정 성공**하며 확률 실패·파괴·하락·새 내구도 시스템이 없다. 이 규칙을 유지한다. 서비스 처리 오류는 확률 실패가 아니며 재료와 상태를 복원해야 한다.

현재 +0 → +1 재료는 다음과 같다. 구현에서 숫자를 복사하지 않고 `equipment_enhancement_costs.csv`에서 읽는다.

| 종류 | 기존 첫 강화 재료 |
|---|---|
| 기본 무기 | 철광석 2개 |
| 기본 방어구 | 숲 약초 2개 |
| 기본 채집 도구 | 철광석 2개 |

예를 들어 대장간 마련과 낡은 검의 첫 강화를 모두 하려면, 각각의 기존 비용인 철광석 5개와 2개를 따로 준비한다. 건축 비용을 강화 비용으로 간주하거나 무료 시범으로 대체하지 않는다.

장비별 강화 상한·성능·공격 방식·도구 효과는 기존 데이터를 따른다. 선택 장비는 `instance_id`로 구분한다. 같은 종류 장비 여러 개 중 고른 하나만 바꾸고, 보유 장비와 저장된 원정 가방의 개별 장비를 모두 지원한다. 가방에 있는 장비는 같은 ID·배치·모양을 유지한 채 단계만 갱신한다.

## 6. 화면과 조작

- 새 게임에서는 NPC 도입 전 원정 준비의 강화 탭과 실제 강화 실행을 모두 잠근다. 숨긴 버튼 외의 입력으로도 실행되지 않아야 한다.
- 도입 후 원정 준비는 가방 정리·현재 강화 단계 조회·마을 대장간 위치 안내를 제공한다. 실제 강화는 NPC 서비스 창에서 의뢰한다.
- 대장장이에게 [E]로 말을 걸면 **안부 / 장비 제작 / 장비 강화**를 명확히 선택한다. 매번 안부 장면을 끝내야 서비스를 쓰게 만들지 않는다.
- 제작 목록에는 배운 장비 제조법을, 강화 목록에는 실제 소유 장비를 보여 준다. 미래의 모든 장비·재료·비용을 초기에 펼치지 않는다.
- 상세는 장비 이름·그림·출처(보유 장비/가방)·현재/다음 강화 단계·필요 재료/보유량·기존 공격 방식 또는 도구 용도를 보여 준다. 공격력·방어력 절대 수치는 숨긴다.
- 재료 부족은 부족분과 현행 준비 경로로 안내한다. 최대 단계는 조회만 가능하다. 선택 장비는 확정 직전에 재검사한다.
- 대화·서비스 동안 시간과 이동을 잠그고, 닫기·Esc·장면 이탈 때 이전 상태를 복원한다. 확인/닫기 버튼은 긴 목록과 분리해 작은 화면에서도 보이게 한다.
- 안내 위치는 최신 **관리 책 → 일정 → 마을 수첩/물품 준비/목적지 표시**다. 이전 왼쪽 상시 부탁 패널을 다시 켜지 않는다.

## 7. 저장과 이전 플레이

새 키는 기존 `PlayerProgress.story_beat_days`의 `blacksmith_progress:` 접두어에 선택형으로 기록한다. 별도 강제 저장 필드나 저장 버전 변경을 요구하지 않는다. 장면은 완독, 첫 강화는 실제 트랜잭션 성공, 원정 경험은 실제 복귀에서 기록한다.

- 새 광석 기록은 실제 신규 채집물을 성공적으로 정산한 뒤 남긴다. 출발 때 담아 간 광석·선물·보유 수량을 새 채집이라고 기록하지 않는다. 현재 철광석 출처 기록은 없으므로 신규 기록 연결이 필요하다.
- 이미 `open_smithy`를 완료한 저장은 시설·서비스 권한을 유지한다. 대장장이 소개 안부는 선택형이며 건축 재료를 다시 받지 않는다.
- 이미 강화한 개별 장비가 있는 저장은 강화 권한을 소급 잠그지 않는다. 작업장이 없던 경우 임시 작업 NPC가 기존 강화 서비스로 받는 호환 경로를 둔다. 영구 대장간은 기존 부탁으로 마련한다. 무료 강화나 추가 건물을 지급하지 않는다.
- 과거 광석 출처를 알 수 없는 저장은 새 원정 획득으로 추정하지 않는다. 기존 시설/강화 권한이 없다면 현재 철광석을 보여 주는 비소비 호환 행동으로 소개를 이어갈 수 있다.
- 취소·재접속·빠른 중복 클릭·장비 이동/변경·재료 소모 실패 때 소비와 진행을 중복시키지 않는다. 강화 어댑터는 실제 저장 원본을 갱신하며 로컬 복사본만 바꾸고 끝내지 않는다.

## 8. 구현과 글 전달

새 진행 설정/흐름/기록/NPC/서비스 패널/개별 장비 어댑터를 분리한다. 기존 큰 파일에는 복귀 기록과 UI 진입 제한 같은 최소 연결만 둔다. 구현 순서는 JSON의 `implementation_order`, 검사 항목은 `acceptance_checks`를 따른다.

Gemini에는 JSON의 장면별 `story_brief`를 전달한다. 새 설계 ID는 아직 등록되지 않았으므로 기존 `webprompt --ids`가 바로 처리한다고 안내하지 않는다. 구현 때 `service_text` 장면 컨텍스트 등록 후 기존 글 도구를 사용한다. 기존 교정 대상은 `open_smithy`와 `smithy_panel`이다. 대사에는 재료 수량·골드·강화 단계·확률을 쓰지 않고 숫자 정보는 데이터 UI가 표시한다.

Claude 검토: 대장간 선행의 대기 시간, 기존 작업장/첫 강화 재료 부담, 코르빈→대장장이 역할 표시, 이전 강화 저장의 임시 서비스 경로. 사용자 승인 방향인 별도 NPC·도입 뒤 공개·기존 강화 규칙 유지 안에서 검토한다.

**이번 변경:** 설계 문서·JSON·콘텐츠 목록·인수인계만. NPC 등장, 강화 버튼 잠금, 새 기록, 대장간 역할 표시는 후속 구현 항목이다. 현행 가격/CSV/대사/그림/게임 코드는 변경하지 않았다.
