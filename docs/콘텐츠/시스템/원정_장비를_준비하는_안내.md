# 원정 장비를 준비하는 안내

2026-10-09 · 구현 완료 · `main` @ d885d78.

## 1. 보강 목적

타블렌에게 도구를 사거나 대장장이에게 장비를 맡긴 다음, 실제로 원정에서 사용하는 준비를 알 수 있게 한다. 장비를 소유하는 것과 원정 가방에 넣는 것을 구분하고, 현재 가방으로 어떤 기본 공격·채집을 할 수 있는지 보여 준다.

## 2. 플레이어 흐름

원정 준비에서 목적지를 선택하면 가방 정리가 열린다. 가방 아래의 **장비 사용 안내**를 누르면 현재 상태를 읽는다. 자동으로 뜨는 추가 튜토리얼은 없으며, 안내를 닫은 뒤 플레이어가 직접 장비를 오른쪽 가방에 옮기고 출발한다.

| 확인할 내용 | 실제 기준 |
|---|---|
| 처음 드는 무기와 공격 방식 | 방 안에서도 쓰는 `ExpeditionWeaponLoadout`과 기존 공격 프로필. 가방 배치 배열의 첫 무기로 시작하며 없으면 맨손 |
| 두 무기 교체 | 가방 무기가 둘이면 방 안의 교체 버튼 또는 Q. 들고 있는 무기의 공격 보너스를 사용 |
| 기본 공격 | 방 안의 공격 버튼 또는 J / Space |
| 방어구 | 실제 가방에 넣은 장비 이름·현재 강화 단계·개별 장비 번호 |
| 채집 도구 | 기존 도구 효과와 `expedition_gathering_rules.csv`의 필수 여부. 물병은 물 채집에 필수, 낫은 도구 없이도 가능한 밀 채집에 도움 |
| 보유했지만 미준비한 장비 | 왼쪽 보유 격자의 실제 개별 장비. 소지 중인 도구는 다시 구매하라는 대신 가방에 넣으라고 안내 |
| 가방 배치 조건 오류 | 기존 출발 장착 검사에서 받은 이유. 유효하지 않은 가방의 공격 방식을 확정된 것으로 보여 주지 않음 |

공격력·방어력 절대 수치는 표시하지 않는다. 강화 단계와 장비 번호는 같은 종류의 다른 장비를 구분하기 위한 현재 정보다. 아직 얻지 않은 모든 장비·제조법·강화 비용 목록을 펼치지 않는다.

채집 도구가 하나도 없고 보유 격자에도 도구가 없을 때만 기존 타블렌 진행 안내를 덧붙인다. 새로운 상점·도구 지급·강화 의뢰·물품 제작 기능은 없다. 물 채집 도구는 원정 전체의 필수 출발 조건으로 만들지 않는다.

## 3. UI와 조회 규칙

- 가방 화면에서 선택해 여는 안내이며, 지도 선택 전이나 원정 길을 걷는 동안에는 버튼이 보이지 않는다.
- 긴 내용은 본문에서 스크롤한다. 가방으로 돌아가는 버튼은 본문 밖에 고정한다.
- 창 크기에 맞춰 중앙 패널을 배치하고, 배경 가방·출발 버튼의 클릭을 차단한다.
- Esc는 안내만 닫고 가방 화면으로 돌아간다. Tab은 안내 닫기 버튼에 머무르며 뒤 화면에 포커스를 넘기지 않는다. 안내 안에서는 R·E·F5 등 배경 단축키를 차단한다.
- 가방/원정 준비가 숨겨지거나 장면이 종료되면 안내 레이어도 정리한다. 기존 준비 단계의 시간·이동 정책을 따르며 별도 시간 정책을 만들지 않는다.
- 열린 동안 실제 장비 상태를 다시 조회한다. 내용이 같으면 목록을 재작성하지 않고 스크롤을 유지한다.
- 조회로 장비 이동·소비·지급·강화·이야기 완료·저장 파일 쓰기를 수행하지 않는다.

### 찾은 문제와 수정

- 물병이 없으면 물 채집 보상은 없는데, 도구 판정 전에 방의 채집 기회가 소비됐다. 이제 **필수 도구 부족은 시작 전에 확인**하고 진행 시간·채집 기회·난수·보상을 소비하지 않는다. 같은 방의 갈대 등 다른 지점을 선택하거나 출구로 나갈 수 있다.
- 필요한 도구는 **이번 원정의 실제 가방** 기준이다. 가게에 남겨 둔 물병은 사용할 수 없다. 물병을 전체 원정의 필수 출발 조건으로 만들거나 자동 지급하지 않는다.
- 선택 도구 없이 가능한 밀 채집은 기존 성공률을 유지한다. 실제로 시도한 뒤 실패하면 한 번의 기회가 소비된다. 실패를 무한 재시도할 수 있게 바꾸지 않았다.
- 채집 결과/실패 문구에 출구로 다가가 E를 누르는 다음 행동을 함께 표시한다. 진행 이름은 실제 채집 지점·상자 열기·휴식에 맞춘다. 이동·기본 공격으로 채집을 중단하는 기존 규칙을 안내한다.
- 전리품 포기 확인창의 `confirmed` 신호가 기존 정리 함수에 연결되지 않았던 부분을 복구했다. **취소는 보상을 남기고 창을 닫으며, 확인은 남은 보상을 포기하고 다음 방 또는 철수 결과로 진행**한다. 철수 전에 획득했지만 가방에 넣지 않은 물품은 먼저 정리한다.

### 구현 범위

[방 진행 안내 모듈](../../../script/expedition/rooms/expedition_room_progress_guide.gd)에 필수 도구 확인과 다음 행동 표시를 분리했다. 모델의 상호작용 시작 전 콜백, 방 입장/종료의 연결·정리, 기존 화면의 안내 조회만 추가했다. NPC 대화와 출구 행동은 도구 검사보다 먼저 처리한다. `ExpeditionRoomProgressGuide.ENABLED = false`로 새 안내와 도구 사전 확인을 끌 수 있다. 전리품 포기 신호 복구는 별도 버그 수정으로 유지한다.
