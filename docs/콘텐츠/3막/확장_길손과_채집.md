## 제미나이·Claude 인수인계

- 새 부탁 문장은 `data/shop/requests/requests_text.csv`의 `community_request:welcome_garden`. 기존 종류를 사용하므로 새 종류 등록이 필요하지 않다. `content_voices.csv`에 이세르의 상황 지침을 추가했다. 정식 인물 파일 두 개는 수정하지 않았다. 보상·수량·조건을 대사로 변경하지 않는다.
- 손님 이름·설명·원정 사건 문구·상점 소문은 각 CSV에 있다. `requests_text` 작성 도구의 대상은 새 공동 부탁 한 행이다. 다른 CSV의 이야기는 별도 초안에서 제안하고 해당 데이터 수정 절차를 따른다.
- 조정 위치: 손님/수요/이벤트는 `data/shop/catalogs/`, `data/shop/events/`; 몬스터/사건/드롭은 `data/expedition/`; 행동·채집 지점은 `scenes/expedition/rooms/default_content_settings.tres`; 방문 해금은 `scenes/shop/requests/default_village_visitors.tres`.
- 신규 수치·드롭·등장 가중치는 플레이 조정용 초깃값이다. `balance_baseline.py`는 대분류 기준 계산이며 소분류 변경·해금·새 이벤트 효과·선택 채집의 경제 효과를 계산하지 않는다.
- 이미지 생성은 하지 않았다. 새 손님은 기존 외형 선택 경로, 새 적·채집 지점은 색·이름이 있는 임시 도형을 사용한다. 후속 이미지 제작 대상은 손님 4종, 일반 적 4종, 선택 채집 오브젝트 8종이다.
