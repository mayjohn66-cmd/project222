# 작은 노점의 첫 장터 (2026-10-03)

**등불 아래의 길손 → 이세르의 마을 이야기 → 작은 노점의 첫 장터**의 세 번째 콘텐츠. 기존 노점에 주민들이 함께 모이는 일회성 행사다.

## 플레이 흐름

1. 튜토리얼과 주민 세 명의 정착, **이세르의 마을 이야기**를 완료한다.
2. 기존 타블렌에게 가까이 가서 E로 장터 제안을 끝까지 듣는다. 중단하면 부탁을 맡지 않는다.
3. 다시 타블렌에게 E로 준비 화면을 연다. 창고의 **빵 2개·야생 열매 3개**를 확인하고 전달 버튼을 누른다. 부족하면 어떤 물품도 소비하지 않는다. 창을 닫아도 준비 상태는 바뀌지 않는다.
4. 전달한 **다음 날부터 매일 12~17시**에 기존 노점으로 간다. 당일 장터는 열리지 않고, 시간을 놓쳐도 다음 낮에 다시 참여할 수 있다. 기한과 추가 물품 소비는 없다.
5. 타블렌·코르빈·이세르가 실제 노점으로 걸어온다. 수첩에서 노점 위치를 찾을 수 있으며 도착 전에는 기다리는 안내가 나온다. 모두 도착하면 노점 주변에서 E로 참여한다.
6. 세 주민의 장터 대화를 끝까지 읽으면 **밀 3개·40 G·평판 1**을 한 번 받는다. 중단하면 정산 없이 다시 참여할 수 있다. 수첩에 장터 날짜와 마무리가 남는다.

행사는 별도 거래 화면이나 반복 장터, 새로운 건물·손님 해금이 아니다. 마친 뒤에는 기존 노점 거래와 주민 안부, 이동 일정을 다시 이용한다. 준비 중 타블렌 근처의 E는 행사 안내·물품 준비를 우선한다.

수량·시간·거리는 `default_village_market.tres`/`VillageMarketSettings`의 초기 조정값이다. 조정 검토는 Claude에게 인수인계한다. 준비 물품의 판매대 진열 상태나 개별 거래를 시뮬레이션하지 않으며, 행사의 작은 정산은 완료 답례로만 처리한다.

## 구현과 저장

- 새 NPC와 이미지를 만들지 않고 기존 노점과 주민 세 명을 사용한다. `main.tscn` 수정 없이 `VillageLifeDirector`가 새 `VillageMarketDirector`를 자식으로 생성한다.
- 새 진행 로직 `VillageMarketFlow`, 준비 UI `VillageMarketPanel`을 기존 상호작용·주민 일정·수첩에 연결한다. 장터 진행 중에는 시간·플레이어 이동과 다른 상호작용을 멈추고 원래 상태로 복원한다.
- `village_market:first_market:accepted/prepared/done`을 기존 `PlayerProgress.story_beat_days`에 저장한다. 저장 형식 변경은 없다. 새 게임에서는 초기화된다.
- 전달 버튼은 창을 연 뒤 재고가 바뀌어도 클릭 시 다시 전체 물품을 검사한다. 전달과 완료는 각각 한 번만 처리한다. 평판은 기존 `resident_request:reputation:event/first_market` 경로로 집계한다.
- 사용자가 지도에서 노점이나 주민 거처를 제거한 경우 복구·복제하지 않는다. 존재하고 보이는 노점과 실제 도착한 주민이 필요하다. 지도 복사본 조회는 기존 `VillageSettlement` 규칙을 따른다.
- 기존 주민 부탁 완료 개수와 새 손님 방문 기준은 바뀌지 않는다. 3D 브랜치 자동 병합과 사용자 실행 폴더 브랜치 변경은 하지 않았다.

## 제미나이 대사 보강

새 종류 없이 기존 `service_text` 7개를 `requests_text.csv`에 등록하고, `content_voices.csv`에 상황·말투를 보충했다. 정식 인물 이름·말투 기준 파일은 수정하지 않았다. API는 호출하지 않았다.

| ID | 실제 사용처 |
|---|---|
| `first_market_intro` | 타블렌의 제안 대화와 제목 |
| `first_market_preparation` | 준비 화면의 소개·설명 |
| `first_market_wait` | 준비 이후 타블렌의 날짜 안내 |
| `first_market_open` | 타블렌이 여는 장터 장면 |
| `first_market_doyun` | 코르빈의 장터 장면 |
| `first_market_sora` | 이세르의 장터 장면 |
| `first_market_end` | 타블렌의 마무리·수첩 기록 |

`default_village_market.tres`의 `moments`가 도구에 선행 사건·물품 전달·날짜·완독 조건과 화자를 전달한다. 물품 수량·정산·평판 수치는 대사에 쓰지 않는다. 대사는 기존 노점과 이웃들의 생활 감각을 보강하고 새 고객·건물·반복 판매를 약속하지 않는다. 날짜 안내는 재방문해도 맞는 말이어야 한다.

이 콘텐츠를 받은 폴더에서 새 장면만 초안 작성:

```bat
dev\gemini\run_request_text.bat draft service_text --ids first_market_intro,first_market_preparation,first_market_wait,first_market_open,first_market_doyun,first_market_sora,first_market_end
```

초안은 검사와 검토 후 별도로 반영한다.
