# 프롤로그 연출 (2026-10-06)

사용자 요청: 프롤로그가 밋밋하니 게임 안 애니메이션으로 조정. 선택: **카메라·빛·소리 연출 + 유리문 밖이 도시에서 숲으로 바뀜**, 구현은 Claude. 새 그림 파일은 쓰지 않는다(3D 입방체와 색만 사용).

## 흐름

| 단계 | 시간 | 화면·소리 |
|---|---|---|
| 도입 | 약 6.4초 | 검은 화면 → 2.2초에 걸쳐 밝아짐. 가게 바깥이 **현대 도시 거리**(콘크리트 인도, 아스팔트 도로와 중앙선, 가로등, 건물, 오가는 차)로 보이고 도로 소리가 일상처럼 깔린다. 숲의 풀·나무·꽃은 숨겨 둔다. |
| 독백 1 `prologue_last_shift` | 대사 | 도시 거리 위에서 평소와 다른 적막을 알아챈다. |
| 전환 | 약 6.4초 | 도로 소리가 **뚝 끊기고** 형광등이 4~5번 깜빡 → 카메라가 유리문 쪽으로 2.6초 동안 다가가며(확대 1.7배) 하얗게 번쩍 → 번쩍하는 사이에 도시를 지우고 숲을 되돌림 → 숲 바람 소리와 함께 밝아짐 |
| 독백 2 `prologue_unfamiliar_window` | 대사 | 유리에 비친 건 간판이 아니라 풀과 나무다. |
| 마무리 | 1.8초 | 독백 2가 끝나면 카메라가 제자리로 돌아오고 바람 소리가 서서히 사라진다. 독백 3·4는 기존처럼 진행. |

연출 중 **E 또는 Esc**를 누르면 지금 단계를 건너뛴다(오른쪽 아래에 안내가 뜬다). 게임 시간은 프롤로그 동안 이미 멈춰 있고 플레이어 입력도 막혀 있다.

## 코드 (모두 새 파일, 기존 큰 파일은 건드리지 않음)

- `script/world/shop/tutorial/opening_cutscene.gd` — 단계 진행·화면 덮개(검정·깜빡임·하양)·카메라·건너뛰기. 시간과 카메라 값은 파일 위쪽 상수(`FADE_IN`, `CITY_HOLD`, `PUSH_ZOOM`, `PUSH_OFFSET` …)에서 조정.
- `script/world/shop/tutorial/opening_city_backdrop.gd` — 도시 거리 입방체와 차 이동, 숲 숨김·복구, 지면 색 바꿈. 배치 수치는 상수(`SIDEWALK_*`, `ROAD_WIDTH`, `BUILDING_*`, 색).
- `script/world/shop/tutorial/opening_road_noise.gd` — 파일 없이 만든 도로 소음과 숲 바람(`AudioStreamGenerator`).
- `script/world/shop/tutorial/tutorial_director.gd` — 프롤로그 독백 1·2 앞에서 연출을 부르는 몇 줄만 추가(`_begin_prologue`, `_end_talk`).

## 알아 둘 점

- **헤드리스(자동 검사)와 `--no-cutscene` 실행에서는 연출이 꺼진다.** 그래서 기존 검사의 흐름은 그대로이고, 연출은 화면이 있는 실행에서만 보인다.
- **소리는 이 클라우드 환경에서 들어 보지 못했다**(오디오 장치 없음, 대체 드라이버). 코드는 오류 없이 돌지만 크기·느낌은 사용자 PC에서 확인이 필요하다. 시끄러우면 `opening_road_noise.gd`의 `VOLUME_DB`를 낮춘다.
- 도시 장식은 임시 입방체다. 건물·차·가로등을 더 그럴듯하게 만들려면 이미지 담당이 3D 소품을 제안하면 된다.
- 연속 캡처로 확인하는 도구: `dev/spike3d/prologue_shot.tscn` (`godot --path . res://dev/spike3d/prologue_shot.tscn -- <저장 폴더>`, 화면이 있어야 한다. 단계별 장면과 상태를 출력한다).
- 이미 프롤로그를 본 저장 파일에서는 연출이 다시 나오지 않는다(기존 프롤로그 완료 기록을 그대로 쓴다).

## 독백 단축과 걷는 연출 (사용자 피드백 반영, 2026-10-06)

사용자 피드백: 독백이 너무 길고, 주인공이 제자리에서 말만 한다. → 4개 독백을 **17줄 → 9줄**(3·3·2·2)로 줄이고, 대사 사이에 주인공이 가게 안을 걷게 했다. 걷는 동안 대사창은 숨고, 걷고 나면 다음 줄이 나온다.

| 독백 | 줄 수 | 움직임(읽은 줄 번호 → 동작) |
|---|---|---|
| 1 `prologue_last_shift` | 3 | 0 → 유리문 쪽으로 / 1 → **도로 소리가 뚝 끊긴다**(1초 정적) 뒤 "…그런데 왜 이렇게 조용하지?" |
| 2 `prologue_unfamiliar_window` | 3 | 0 → 계산대로 / 1 → 진열대로 |
| 3 `prologue_food_dates` | 2 | 0 → 계산대로 |
| 4 `prologue_keep_the_light` | 2 | 0 → 가게 가운데로 |

- 코드: `OpeningCutscene.BEATS`(장면별 동작표)·`SPOTS`(가게 안 칸 좌표)·`WALK_SPEED`, 대사창의 `beat_handler`(다음 줄로 넘기기 직전에 부르는 함수, `story_dialogue_panel.gd`). 3D 인물은 2D 위치가 바뀌면 걷는 동작과 방향을 스스로 만들므로 위치만 옮긴다.
- 헤드리스(자동 검사)에서는 연출이 꺼져 걷기도 없다. 확인 도구: `dev/spike3d/prologue_walk_shot.tscn`(걷는 위치 로그와 걷는 중 화면 저장, 화면 필요).
- 인수인계 27번의 ①(도로 소리를 적막 대사 전에 끊기)은 위 1번 독백의 "소리 끊김"으로 적용했다. ②(자연광)·③(식품 날짜 독백을 첫 진열 직전으로 옮기기)는 남아 있다.

## 후속 권장안 (인수인계 27, 적용 전)

사용자 요청으로 소리·독백 순서, 전원 단절 이후 자연광, 식품 날짜 독백의 첫 진열 직전 연결을 [권장안](프롤로그_연출_권장안.md)과 [단계 데이터](프롤로그_연출_권장안.json)에 정리했다. 위 흐름 표는 현재 구현이고, 후속 권장안은 Claude 검토·조정 대기다.
