# 프롤로그 연출 (2026-10-06)

사용자 요청: 프롤로그가 밋밋하니 게임 안 애니메이션으로 조정. 선택: **카메라·빛·소리 연출 + 유리문 밖이 도시에서 숲으로 바뀜**, 구현은 Claude. 새 그림 파일은 쓰지 않는다(3D 입방체와 색만 사용).

## 흐름 (2026-10-06 개정: 손님 → 멍 때림 → 졸음 → 전이 → 부서진 가게)

사용자 피드백: 초반이 부실하다. 현대 편의점에서 손님이 계산하고 나가는 것을 보여 주고, 주인공이 바깥을 멍하니 보다 살짝 졸다가 차 소리가 사라진 것을 알아채는 흐름이 자연스럽겠다. 깨어나면 진열대가 다 박살 나 하나만 남아 있다.

| 단계 | 시간 | 화면·소리 |
|---|---|---|
| 도입 | 약 13초 | 검은 화면 → 2초에 걸쳐 밝아지면 **현대 편의점 안**(유리문 음료 냉장고 벽, 청록 간판 진열대 줄, 알록달록한 상품)과 도시 거리, 도로 소리. 주인공은 계산대 안쪽. **연출용 손님**이 문으로 들어와 진열대를 둘러보고 계산대에서 계산("삑")한 뒤 나간다. E/Esc 로 건너뛴다. |
| 독백 1 `prologue_last_shift` | 3줄 | ① "손님이 나가고 나면…" 읽은 뒤 주인공이 유리문 쪽으로 걸어간다 → ② "차가 오가는 소리가 한결같아서 눈꺼풀이 무겁다." 읽은 뒤 **졸음**: 눈꺼풀이 두 번 감겼다 뜨였다 하며 카메라가 고개 숙이듯 내려가고 도로 소리가 멀어지다 **뚝 끊긴다** → 검은 화면에서 ③ "…잠깐 졸았나? 왜 이렇게 조용하지?" |
| 깨어남 | 약 3초 | 검은 화면에서 **쿵 하는 소리** → 하얗게 번쩍(이때 도시가 사라지고 숲으로 바뀌며 가게 안 진열대가 **전부 부서진 잔해**로 바뀐다. 시작 배치의 진열대 하나만 멀쩡) → 화면이 한 번 크게 흔들리며 숲 바람 소리와 함께 밝아진다. |
| 독백 2 `prologue_unfamiliar_window` | 3줄 | "눈을 뜨니 도로가 있던 자리에 풀잎이 흔들린다." → (가게 안을 걸어 봄) "진열대는 전부 부서졌다. 건진 건 계산대와 진열대 하나뿐이다." → "계산대 전원은 눌러도 꺼진 채다. 가게가 통째로 여기 온 건가?" 끝나면 바람 소리가 서서히 줄어든다. |
| 독백 3 `prologue_food_dates` | 2줄 | "창고의 빵과 물은 무사하다. 봉지의 날짜도 그대로다." → (계산대로) 기한 임박 식품 처리 다짐. |
| 독백 4 `prologue_keep_the_light` | 2줄 | "어디인지도 모르는 곳에 혼자 나설 엄두는 안 난다." → (가게 가운데로) "우선 안부터 정리하자. 바깥은 그다음이다." 끝나면 **청소 튜토리얼**(아래 문서)로 이어진다. 잔해는 플레이어가 [E]로 직접 치운다. |

독백 줄 수는 17 → 3·3·2·2 = 10줄. 게임 시간은 프롤로그 동안 멈춰 있고 플레이어 입력도 막혀 있다. 검은 화면 위에서도 대사가 보이도록 연출 덮개를 대사창(30)보다 아래(20)에 둔다.

**이야기 연결:** 건진 것은 계산대와 진열대 하나(보관함)뿐이고, 가게 안에는 문만 서 있다. 이어지는 흐름은 [초반 청소와 건축](초반_청소와_건축.md). 창고의 빵과 물은 무사하다(시작 재고 그대로이며 무료 지급은 없다). 전이 원인은 보여 주지 않는다.

## 코드 (모두 새 파일, 기존 큰 파일은 건드리지 않음)

- `script/world/shop/tutorial/opening_cutscene.gd` — 단계 진행·화면 덮개(검정·깜빡임·하양)·카메라·건너뛰기. 시간과 카메라 값은 파일 위쪽 상수(`FADE_IN`, `CITY_HOLD`, `PUSH_ZOOM`, `PUSH_OFFSET` …)에서 조정.
- `script/world/shop/tutorial/opening_city_backdrop.gd` — 도시 거리 입방체와 차 이동, 숲 숨김·복구, 지면 색 바꿈. 배치 수치는 상수(`SIDEWALK_*`, `ROAD_WIDTH`, `BUILDING_*`, 색).
- `script/world/shop/tutorial/opening_store_dressing.gd` · `opening_store_models.gd` · `opening_store_layout.gd` · `opening_store_paths.gd` · `opening_layout_editor.gd` — 가게 안 장식(연출용, 저장·충돌·건축과 무관). 집기 모델(음료 냉장고·진열대·아이스크림 쇼케이스·계산대·상품 걸이·취식 탁자·커피 기계 장)은 메시 하나씩(정렬 부담 없음, 상자를 잘게 쌓으면 정렬이 150~260ms가 되어 끊긴다). **배치는 `data/shop/opening_store_layout.json`**(없으면 기본 배치)에서 읽고, **개발자 모드(F10)** 에서 직접 배치·저장한다([사용법](#개발자-모드-f10)). 청소 더미·손님 동선·점원 자리·둘러볼 자리는 **배치에서 자동으로** 정해진다(`OpeningCleanup`, `OpeningStorePaths`: 집기를 피하는 길찾기).
- `script/world/shop/tutorial/opening_road_noise.gd` — 파일 없이 만든 도로 소음·숲 바람·쿵(`crash`)·계산대 삑(`beep`)(`AudioStreamGenerator`). `set_level`로 졸 때 소리를 멀어지게 한다.
- `script/world/view3d/store_view_3d.gd` — 연출용 인물(`cutscene_actor` 그룹, `look_key` 메타)을 그리는 두 줄만 추가. 손님 외형은 `OpeningCutscene.VISITOR_*`·`backpacker`.
- `script/world/shop/tutorial/tutorial_director.gd` — 프롤로그 독백 1·2 앞에서 연출을 부르는 몇 줄만 추가(`_begin_prologue`, `_end_talk`).

## 알아 둘 점

- **헤드리스(자동 검사)와 `--no-cutscene` 실행에서는 연출이 꺼진다.** 그래서 기존 검사의 흐름은 그대로이고, 연출은 화면이 있는 실행에서만 보인다.
- **소리는 이 클라우드 환경에서 들어 보지 못했다**(오디오 장치 없음, 대체 드라이버). 코드는 오류 없이 돌지만 크기·느낌은 사용자 PC에서 확인이 필요하다. 시끄러우면 `opening_road_noise.gd`의 `VOLUME_DB`를 낮춘다.
- 도시 장식은 임시 입방체다. 건물·차·가로등을 더 그럴듯하게 만들려면 이미지 담당이 3D 소품을 제안하면 된다.
- 연속 캡처로 확인하는 도구: `dev/spike3d/prologue_walk_shot.tscn` (`godot --path . res://dev/spike3d/prologue_walk_shot.tscn -- <저장 폴더>`, 화면이 있어야 한다. 도입부터 잔해 정리까지 줄마다 화면을 저장하고 로그를 낸다. 화면 없는 환경은 4fps 안팎이라 시간이 길게 나온다). 옛 `prologue_shot.tscn`은 이전 흐름용이다.
- 이미 프롤로그를 본 저장 파일에서는 연출이 다시 나오지 않는다(기존 프롤로그 완료 기록을 그대로 쓴다).

## 독백 단축과 걷는 연출 (2026-10-06, 위 흐름에 반영됨)

사용자 피드백: 독백이 너무 길고 주인공이 제자리에서 말만 한다. → 독백을 줄이고 대사 사이에 주인공이 걷게 했다(위 표의 "→ (…로 걸어감)"). 걷는 동안 대사창은 숨고, 걷고 나면 다음 줄이 나온다.

- 코드: `OpeningCutscene.BEATS`(장면별 동작표: 읽은 줄 번호 → 걷는 곳 또는 `doze`)·`SPOTS`(가게 안 칸 좌표)·`ROUTES`·`WALK_SPEED`, 대사창의 `beat_handler`(다음 줄로 넘기기 직전에 부르는 함수, `story_dialogue_panel.gd`). 3D 인물은 2D 위치가 바뀌면 걷는 동작과 방향을 스스로 만들므로 위치만 옮긴다.
- 헤드리스(자동 검사)에서는 연출이 꺼져 걷기·손님·졸음이 없다.
- 인수인계 27번의 ①(도로 소리를 적막 대사 전에 끊기)은 졸음 장면에서 적용됐다. ②(자연광)·③(식품 날짜 독백을 첫 진열 직전으로 옮기기)는 남아 있다.

## 후속 권장안 (인수인계 27, 적용 전)

사용자 요청으로 소리·독백 순서, 전원 단절 이후 자연광, 식품 날짜 독백의 첫 진열 직전 연결을 [권장안](프롤로그_연출_권장안.md)과 [단계 데이터](프롤로그_연출_권장안.json)에 정리했다. 위 흐름 표는 현재 구현이고, 후속 권장안은 Claude 검토·조정 대기다.


## 개발자 모드 (F10)

프롤로그 가게 안 집기를 직접 배치하는 편집기다. **화면이 있는 실행(에디터에서 실행)** 에서만 동작한다(자동 검사에서는 꺼져 있다).

1. 게임을 실행하고 새 게임 장면에서 **F10**을 누른다(프롤로그 연출 중이면 E/Esc로 건너뛴 뒤). 현대 편의점 집기가 보이고 카메라가 가게 전체로 물러난다.
2. 마우스로 집기를 **누르면 고르고, 끌면 옮긴다**. 고른 집기는 바닥에 청록색 판이 깔린다. 마우스가 가리키는 칸은 노란 판으로 보인다.
3. 키: **R** 돌리기 · **, .** 길이 줄이기/늘리기 · **Tab** 종류 바꾸기(고른 집기가 있으면 그 집기를, 없으면 새로 놓을 종류를) · **N** 마우스 칸에 새로 놓기 · **C** 고른 집기를 마우스 칸에 복사 · **Delete** 지우기 · **Z** 되돌리기 · **마우스 휠** 확대/축소.
4. **P**를 누르면 저장한다: `data/shop/opening_store_layout.json`(프로젝트)과 사용자 폴더에 같이 쓴다. 이 파일을 저장소에 올리면 게임이 그 배치를 쓴다. **F10 또는 Esc**로 나가며, 저장하지 않은 배치는 버려진다.
5. 칸 좌표: 문 (0,4), 매장 (0..9, 0..7). 방향 0은 앞면(상품·손님 쪽)이 화면 앞(+y), 1은 +x, 2는 -y, 3은 -x. 종류: 음료 냉장고·진열대·아이스크림 쇼케이스·계산대·상품 걸이·취식 탁자·커피 기계 장.

배치를 올려 주시면 그대로 반영된다. 청소 더미(6곳, 철광석 4개)·손님이 걷는 길·계산대 앞뒤 자리는 따로 고칠 필요가 없고, 계산대가 없으면 점원·손님은 매장 가운데에 선다. 걸을 곳이 막히면(집기가 문 앞을 막는 등) 길이 우회하거나 곧장 가므로, 문 앞(0,4)~(1,4)은 비워 두는 것이 좋다.


## 계산대·시식대 연출 (갱신)
- 시작 자리: 계산대 단말기(POS) 바로 뒤. 손님이 계산하는 자리는 그 맞은편이다(`OpeningStorePaths.counter_cells`).
- 첫 독백 뒤 주인공은 취식 탁자(시식대)의 의자까지 걸어가 앉아 창밖을 보다 존다(`OpeningCutscene._sit_down`, 앉는 자세 `BlockyFigure.sitting`). 탁자는 개발자 모드(F10)의 "취식 탁자"로 놓는다. 없으면 문 안쪽에 서서 본다.
- 깨어나면(전이) 일어선다. 1인칭 시점은 3D 깊이 정렬이 등각 카메라 기준이라 아직 하지 않았다.
- 1인칭 창밖 장면(`OpeningWindowPov`, 시간은 `POV_*` 상수): 주인공이 시식대에 앉으면 화면이 검게 사라졌다가, 앉은 눈높이의 원근 카메라로 창밖 거리(지나가는 차·건물·가로등)가 밝아진다. 이 위에 독백 한 줄이 나온 뒤 눈꺼풀이 여러 번 깜빡이고 고개가 숙여지며 잠든다. 가게 안 등각 3D와는 별개의 작은 3D 세계(SubViewport)라 깊이 정렬에 영향이 없고, 작게 그려 키워 픽셀 느낌을 낸다. 깨어나면 등각 화면으로 돌아온다.

## 대사와 서술 구분 (2026-10-07)
한 줄에 말과 서술을 섞지 않는다. 줄 맨 앞에 `*` 가 붙으면 **서술**(독백·행동 묘사)이다: 이름 칸 없이 괄호로 감싼 흐린 글씨(행동 묘사처럼)로 나온다. 붙지 않은 줄은 점장이 소리 내어 하는 **말**이다(`StoryDialoguePanel.NARRATION_MARK`).
예(깨어남): 방금 무슨 소리였지. 지진이라도 난 건가? / *창밖에 도로는 없고 울창한 숲만 펼쳐져 있다. / …이게 진짜 말이 돼? / *뺨을 꼬집어 봤다. / 아야! / 꿈이 아니잖아? → 다음 장면 첫 줄 "그럼 여긴 도대체 어디야…?"
글을 쓰는 쪽(제미나이)에도 같은 규칙을 알려야 한다: "서술은 *로 시작, 말은 그냥".
- 프롤로그 동안(도입~마지막 독백)은 시계·돈 표시(HUD)와 메뉴 단추를 숨기고, 청소가 시작될 때 나타난다(`OpeningCutscene._set_hud`). 자동 검사(헤드리스)에선 연출이 꺼져 있어 그대로 보인다.
- **건너뛰기:** E 는 쓰지 않는다. Esc 를 누르면 첫 장면(손님 → 졸기)을 도입 연출·독백·졸음 어느 때든 통째로 건너뛰고 곧바로 쿵 → 깨어남(이세계) 장면으로 간다(`TutorialDirector._skip_first_scene`, `OpeningCutscene.abort`). 안내 "Esc 건너뛰기"는 첫 장면 동안만 오른쪽 아래에 보인다.
