# 프롤로그 연출 (2026-10-06)

사용자 요청: 프롤로그가 밋밋하니 게임 안 애니메이션으로 조정. 선택: **카메라·빛·소리 연출 + 유리문 밖이 도시에서 숲으로 바뀜**, 구현은 Claude. 새 그림 파일은 쓰지 않는다(3D 입방체와 색만 사용).

## 흐름 (2026-10-06 개정: 손님 → 멍 때림 → 졸음 → 전이 → 부서진 가게)

사용자 피드백: 초반이 부실하다. 현대 편의점에서 손님이 계산하고 나가는 것을 보여 주고, 주인공이 바깥을 멍하니 보다 살짝 졸다가 차 소리가 사라진 것을 알아채는 흐름이 자연스럽겠다. 깨어나면 진열대가 다 박살 나 하나만 남아 있다.

| 단계 | 시간 | 화면·소리 |
|---|---|---|
| 도입 | 약 13초 | 검은 화면 → 2초에 걸쳐 밝아지면 **현대 편의점 안**(유리문 음료 냉장고 벽, 청록 간판 진열대 줄, 알록달록한 상품)과 도시 거리, 도로 소리. 주인공은 계산대 안쪽. **연출용 손님**이 문으로 들어와 진열대를 둘러보고 계산대에서 계산("삑")한 뒤 나간다. E/Esc 로 건너뛴다. |
| 독백 1 `prologue_last_shift` | 3줄 | ① "손님이 나가고 나면…" 읽은 뒤 주인공이 유리문 쪽으로 걸어간다 → ② "차가 오가는 소리가 한결같아서 눈꺼풀이 무겁다." 읽은 뒤 **졸음**: 눈꺼풀이 두 번 감겼다 뜨였다 하며 카메라가 고개 숙이듯 내려가고 도로 소리가 멀어지다 **뚝 끊긴다** → 검은 화면에서 ③ "…잠깐 졸았나? 왜 이렇게 조용하지?" |
| 깨어남 | 약 3초 | 검은 화면에서 **쿵 하는 소리** → 하얗게 번쩍(이때 도시가 사라지고 숲으로 바뀌며 가게 안 진열대가 **전부 부서진 잔해**로 바뀐다. 시작 배치의 진열대 하나만 멀쩡) → 화면이 한 번 크게 흔들리며 숲 바람 소리와 함께 밝아진다. |
| 독백 2 `prologue_unfamiliar_window` | 3줄 | "눈을 뜨니 도로가 있던 자리에 풀잎이 흔들린다." → (남은 진열대로 걸어감) "진열대는 전부 부서졌다. 멀쩡히 남은 건 저 하나뿐이다." → (계산대로) "계산대 전원은 눌러도 꺼진 채다. 가게가 통째로 여기 온 건가?" 끝나면 바람 소리가 서서히 줄어든다. |
| 독백 3 `prologue_food_dates` | 2줄 | "창고의 빵과 물은 무사하다. 봉지의 날짜도 그대로다." → (계산대로) 기한 임박 식품 처리 다짐. |
| 독백 4 `prologue_keep_the_light` | 2줄 | "어디인지도 모르는 곳에 혼자 나설 엄두는 안 난다." → (가게 가운데로) "우선 안부터 정리하자. 바깥은 그다음이다." 끝나면 **잔해를 몇 개씩 치운다**(정리 시작). |

독백 줄 수는 17 → 3·3·2·2 = 10줄. 게임 시간은 프롤로그 동안 멈춰 있고 플레이어 입력도 막혀 있다. 검은 화면 위에서도 대사가 보이도록 연출 덮개를 대사창(30)보다 아래(20)에 둔다.

**이야기 연결:** 부서진 진열대 중 하나만 남는 것은 시작 배치(문·계산대·진열대 1개, `default_tutorial.tres`의 `opening_layout`)와 같다. 창고의 빵과 물은 무사하다(시작 재고 그대로이며 무료 지급은 없다). 전이 원인은 보여 주지 않는다.

## 코드 (모두 새 파일, 기존 큰 파일은 건드리지 않음)

- `script/world/shop/tutorial/opening_cutscene.gd` — 단계 진행·화면 덮개(검정·깜빡임·하양)·카메라·건너뛰기. 시간과 카메라 값은 파일 위쪽 상수(`FADE_IN`, `CITY_HOLD`, `PUSH_ZOOM`, `PUSH_OFFSET` …)에서 조정.
- `script/world/shop/tutorial/opening_city_backdrop.gd` — 도시 거리 입방체와 차 이동, 숲 숨김·복구, 지면 색 바꿈. 배치 수치는 상수(`SIDEWALK_*`, `ROAD_WIDTH`, `BUILDING_*`, 색).
- `script/world/shop/tutorial/opening_store_dressing.gd` · `opening_store_models.gd` — 가게 안 장식. **실제 편의점 내부 사진을 참고**한 연출용 모델(저장·충돌·건축과 무관): 벽을 따라 유리문 음료 냉장고 5대(청록 윗띠, 층마다 알록달록한 음료), 한쪽 끝에 아이스크림 냉동 쇼케이스, 가운데 줄 진열대(흰 몸통·청록 윗간판·노란 가격표 띠·층마다 상품 상자), 입구 쪽 상품 걸이. 배치는 `PROPS` 표(모델·칸·두께·회전). 모델은 `FurnitureAssets.Frame`으로 상자를 모아 **메시 하나**로 만든다(상품 상자가 수백 개여도 깊이 정렬 항목은 하나, 정렬 시간 약 16ms). **상자를 항목 여러 개로 쌓으면 정렬이 한 프레임 150~260ms가 되어 끊긴다**(폐기한 방식). `smash()`는 같은 자리에 잔해(판자·쏟아진 상품·꺾인 기둥·유리 조각)를 깔고 `clear_debris_step()`이 치운다.
- `script/world/shop/tutorial/opening_road_noise.gd` — 파일 없이 만든 도로 소음·숲 바람·쿵(`crash`)·계산대 삑(`beep`)(`AudioStreamGenerator`). `set_level`로 졸 때 소리를 멀어지게 한다.
- `script/world/view3d/store_view_3d.gd` — 연출용 인물(`cutscene_actor` 그룹, `look_key` 메타)을 그리는 두 줄만 추가. 손님 외형은 `OpeningCutscene.VISITOR_*`·`backpacker`.
- `script/world/shop/tutorial/tutorial_director.gd` — 프롤로그 독백 1·2 앞에서 연출을 부르는 몇 줄만 추가(`_begin_prologue`, `_end_talk`).

## 알아 둘 점

- **헤드리스(자동 검사)와 `--no-cutscene` 실행에서는 연출이 꺼진다.** 그래서 기존 검사의 흐름은 그대로이고, 연출은 화면이 있는 실행에서만 보인다.
- **소리는 이 클라우드 환경에서 들어 보지 못했다**(오디오 장치 없음, 대체 드라이버). 코드는 오류 없이 돌지만 크기·느낌은 사용자 PC에서 확인이 필요하다. 시끄러우면 `opening_road_noise.gd`의 `VOLUME_DB`를 낮춘다.
- 도시 장식은 임시 입방체다. 건물·차·가로등을 더 그럴듯하게 만들려면 이미지 담당이 3D 소품을 제안하면 된다.
- 연속 캡처로 확인하는 도구: `dev/spike3d/prologue_walk_shot.tscn` (`godot --path . res://dev/spike3d/prologue_walk_shot.tscn -- <저장 폴더>`, 화면이 있어야 한다. 도입부터 잔해 정리까지 줄마다 화면을 저장하고 로그를 낸다. 화면 없는 환경은 4fps 안팎이라 시간이 길게 나온다). 옛 `prologue_shot.tscn`은 이전 흐름용이다.
- 이미 프롤로그를 본 저장 파일에서는 연출이 다시 나오지 않는다(기존 프롤로그 완료 기록을 그대로 쓴다).

## 독백 단축과 걷는 연출 (2026-10-06, 위 흐름에 반영됨)

사용자 피드백: 독백이 너무 길고 주인공이 제자리에서 말만 한다. → 독백을 줄이고 대사 사이에 주인공이 걷게 했다(위 표의 "→ (…로 걸어감)"). 걷는 동안 대사창은 숨고, 걷고 나면 다음 줄이 나온다.

- 코드: `OpeningCutscene.BEATS`(장면별 동작표: 읽은 줄 번호 → 걷는 곳 또는 `doze`)·`SPOTS`(가게 안 칸 좌표)·`ROUTES`·`WALK_SPEED`, 대사창의 `beat_handler`(다음 줄로 넘기기 직전에 부르는 함수, `story_dialogue_panel.gd`). 3D 인물은 2D 위치가 바뀌면 걷는 동작과 방향을 스스로 만들므로 위치만 옮긴다.
- 헤드리스(자동 검사)에서는 연출이 꺼져 걷기·손님·졸음이 없다.
- 인수인계 27번의 ①(도로 소리를 적막 대사 전에 끊기)은 졸음 장면에서 적용됐다. ②(자연광)·③(식품 날짜 독백을 첫 진열 직전으로 옮기기)는 남아 있다.
