# 프롤로그 연출 권장안

2026-10-06 · ChatGPT → Claude · 인수인계 27번

사용자 요청으로 앞선 프롤로그 논의의 권장 사항을 데이터로 정리했다. 현재 구현 기준은 `main` @ `99eb136`이다. 이 문서와 같은 이름의 `.json`에 단계·장면 ID·실행 조건·화면·소리·빛·확인 항목을 기록했다. **권장안이며 구현 완료 보고가 아니다. JSON은 게임 실행 설정으로 연결하지 않았다.**

## 1. 먼저 맞출 부분

현재 `play_intro()`는 도로 소리를 켜고 첫 독백을 연다. `prologue_last_shift`의 마지막 문장은 이미 적막을 알아챈 상태지만, 소리는 다음 독백 앞의 `play_transition()`에서 끊긴다. **첫 독백이 시작되기 전에 도로 소리를 끊어 말과 연출을 맞춘다.**

## 2. 권장 순서

**호흡 제안값:** 밝아진 뒤 도시를 보여 주는 시간 3~5초, 정적 0.8~1.2초, 문 접근 1.5~2.6초, 빛 전환 0.2~0.4초. 모두 조정 가능한 제안값이다. 현재 화면과 비교해 Claude가 적용값·이유를 기록하고 실제 PC에서 확인한다. 독백은 사용자 읽기 속도로 진행한다.

진열대를 정리하는 플레이어 동작은 선택 보강이다. 아직 없는 동작을 완료된 기능으로 쓰지 않으며, 기존 차 이동과 카메라만으로도 도입을 구성할 수 있다.

## 3. 전원과 식품 이야기 연결

- 전환 뒤에는 **창밖의 자연광**으로 가게를 보이게 한다. 전기 조명이 다시 켜져 전원 단절 설정과 충돌하지 않도록 한다.
- 계산대는 꺼진 상태를 유지하고, 이후 기술자의 마석 개조는 기존처럼 계산대 회로용으로 설명한다. 모든 가게 기기의 전원 복구를 약속하지 않는다.
- 식품 날짜 독백은 숲 발견 직후에서 **첫 진열 직전**으로 옮긴다. 혼란→상황 확인→정리 결심→남은 식품 관리 순서가 목적이다.
- 현재 `OpeningPrologueFlow.current()`는 미완료 `moments`를 순서대로 실행하고 튜토리얼 시작 기록이 있으면 프롤로그를 중지한다. **배열 순서만 바꾸면 날짜 독백이 stock 직전으로 이동하지 않는다.** 최초 stock 진입에서의 실행·완독·복귀를 별도로 검토한다.
- `prologue_food_dates`와 기존 완료 키는 유지한다. 이전 프롤로그에서 날짜 독백을 이미 읽은 저장은 반복하지 않는다. 중간 저장에서도 다른 독백·물품 지급·목표 완료가 중복되지 않아야 한다.
