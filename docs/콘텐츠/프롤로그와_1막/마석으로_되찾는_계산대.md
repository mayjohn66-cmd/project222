# 마석으로 되찾는 계산대

2026-10-05 · 사용자 확정: 처음 계산대는 고장/전원 끊김 상태. 현지의 마석을 알게 된 뒤 기술자에게 발전기 접합과 개조를 맡기며 적응하는 사이드 스토리. main 구현.

## 실제 흐름

1. 새 게임의 기존 도입부에서 버튼을 눌러도 계산대가 켜지지 않는 것을 확인한다. 가게와 함께 내부 배선/콘센트/집기는 남아 있지만 외부 전력 공급과 계산대 회로가 끊겼다. 전이 원인은 밝히지 않는다.
2. 가격표와 장부로 첫 손님 델빈의 실제 현지 화폐 결제를 받는다. 빈 계산대 E는 **계산대 옆 장부 · 전원 꺼짐**, 결제 버튼은 **손으로 계산**으로 표시한다. 상품 조회/마감 정리/진열/실제 매출/직원 계산 기능은 계속 사용할 수 있다.
3. 첫 거래·원정·원재료 판매의 핵심 안내와 타블렌 정착 뒤 주민 E로 **꺼진 계산대에 다시 불이**를 듣는다. 타블렌은 마석을 동력으로 쓰는 현지 문화를 알고, 현대 계산대 운영은 모른다. 전체 완독해야 기술자 방문으로 이어진다. 기존 제품 이야기는 그 뒤 계속한다.
4. 노점 근처의 연결된 외부 바닥에 **순회 기술자**가 온다. 인물 고유 이름은 아직 정하지 않은 역할명이다. 임시 외형은 기존 채굴꾼 계열을 재사용한다. 기존 주민과 겹치지 않게 별도 빈 칸에 서며 [E] 계산대 개조를 표시한다.
5. 기술자 점검 대화를 완독한다. 다시 E로 실제 재료/비용 창을 열고 **재료와 개조비를 건네고 맡기기**를 눌러야 계약한다. 상담이나 창 닫기만으로 재료/돈을 가져가지 않는다.
6. 작업을 맡긴 뒤 게임 날짜가 하루 지나면 기술자에게 다시 말을 건다. 발전기/조절 장치를 기존 배선과 계산대에 연결한 설명을 최종 완독해야 복구된다. 날짜만 지나거나 일부 대화만 읽어서는 복구하지 않는다.
7. 계산대 창에 **마석 발전기 연결**을 표시하고 전원을 되찾는다. 기술자와 다시 만나 기억을 들을 수 있다. 수첩에서 단계/재료/비용/완료일 안내를 다시 확인한다. 기다리는 동안에도 수기 영업·원정·주민 콘텐츠를 진행할 수 있다.

## 초기 계약 조건

- 일반 창고 철광석2·석탄2 + 현지 화폐120G. 광산의 기존 재료를 사용한다. 진열대/원정 가방의 재료는 창고로 옮긴 뒤 맡긴다.
- 마석은 개조비 안에서 기술자가 조달한다. 기존 룬석이 유적 전리품이라 초반 사이드 이야기의 필수 드롭으로 요구하지 않는다. 무료 마석 아이템/새 드롭을 만들지 않았다.
- 작업 기간은 **맡긴 날 + 게임 날짜1일**. 현실 시간이나 창 재열기로 완료하지 않는다. 폐점 준비 중 날짜가 정지한 상황에서 기다리는 것만으로 진행되지 않는다.
- 재료·비용은 모두 준비되어 있을 때 한 번만 소비한다. 맡긴 뒤에는 추가 소비/운영비/충전 숙제/현금·평판·아이템 보상이 없다. 계산/가격/직원 속도나 냉장함 기능을 별도 변경하지 않았다. 이번 연결은 계산대 회로용이며 모든 가게 기기의 전원을 복구했다고 대사에 약속하지 않는다.
- 수치/부품/기간/위치는 `default_power_repair.tres`에 있다. 새 설비를 제작·판매·철거하는 가구 아이템을 추가하거나 기존 집기를 일괄 변환하지 않았다. 발전기 자체의 새 3D 부착물 그림은 없고 완료 대화/계산대 상태 표시로 연결을 표현한다.

## 저장과 이전 플레이

새 게임 집기 부트스트랩에서만 `shop_power:broken`을 기록한다. 소개/점검/계약 날짜/복구는 기존 `PlayerProgress.story_beat_days`에 저장한다. 새 저장 버전·별도 타이머를 추가하지 않았다.

기존 저장에 새 broken 기록이 없다면 현재 계산대를 정상으로 유지한다. 진행 중인 첫 거래나 오래된 가게를 강제로 고장내지 않는다. **이 도입부를 확인하려면 새 게임을 시작한다.** 이후 계약 중 저장은 재료를 다시 내지 않고 같은 완료 날짜로 이어진다. 다른 새 게임을 시작하면 기존 진행 초기화와 함께 수리 기록도 지워진다.

## 글 보강

기존 `service_text` 종류로 6장면: power_stone_intro, power_inspection, power_work_started, power_work_waiting, power_restored, power_memory. 개조를 완료하는 주체는 현지 기술자이며 플레이어는 현지인에게 도움을 부탁하고 장사를 이어 간다. 기술자는 현대 기기 운영법/전이 원인/냉장 설비 전체 복구를 설명하지 않는다. 조작과 수치는 UI에 남긴다.

Gemini SOURCE_FILES와 별도 content_voices에 등록했다. 정식 이름/말투 파일과 이미지는 바꾸지 않고 API를 호출하지 않았다.

```bat
dev\gemini\run_request_text.bat draft service_text --ids power_stone_intro,power_inspection,power_work_started,power_work_waiting,power_restored,power_memory
```
