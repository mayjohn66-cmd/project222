# 초반 청소와 건축 (2026-10-06)

사용자 요청: 가게가 전이되면서 전부 박살 나고, 플레이어가 내부를 청소하면서 얻은 자재로 진열대를 하나 제작하고, 고장 난 계산대와 진열대를 설치하면서 **건축 기능을 알게** 하자.

## 새 흐름 (2026-10-07 개정: 제작 없이 건축부터)

사용자 결정: 둘러보다 "남은 거라도 건져 보자"며 정리하다 빵·물·합판·계산대·진열대를 건지고, "그나마 멀쩡한 게 이거뿐인가" 한 뒤 **제작이 아니라 건축부터** 한다. 제작은 나중에 **기술자 NPC**를 만나 배우고 **간이 제작대**를 만들면서 시작한다(아직 미구현, 아래 후속).

| 순서 | 단계 id | 목표 | 완료 조건 |
|---|---|---|---|
| 1 | `cleanup` 부서진 가게 정리 | 바닥의 잔해 더미 6곳 앞에서 [E]. 빵 4·물 8·합판 4, 계산대 1, 간이 진열대 2를 건진다(`OpeningCleanup.LOOT_TOTAL`, 어울리는 더미에 나뉨: 계산대는 계산대 자리, 식품은 냉장함·냉동함 자리) | 6곳을 모두 치움 |
| 2 | `setup` 가게 다시 세우기 | Esc 메뉴 → 건축으로 건진 계산대와 간이 진열대 둘을 설치. 계산대는 "망가졌지만 이거라도 올려 둘까" | 문 + 계산대 + 진열대 2개 이상 설치 |
| 3~ | `stock` 이후 | 빵과 물을 진열하며 "이 세계에서도 음식은 상할 텐데…" 하고 날짜를 신경 쓴다 → 첫 손님 → 교환 → 원정 … | |

- **시작 상태:** 가게 안에는 **문만** 있고 보관함도 비어 있다(`salvaged_furniture` 전부 0). 새 게임 시작 때 함께 온 빵·물도 인벤토리에서 빼, 청소로 건져야 손에 들어온다(`OpeningJourneyFlow.initialize`).
- **합판:** 새 아이템 `plywood`(합판, 재료). 이번엔 건진 양만 받고 쓰는 곳은 없다. 간이 제작대의 재료로 쓸 예정(후속). 아이콘 그림은 아직 없다(다른 임시 재료와 같은 경고).
- **유통기한:** 처음엔 남은 기한 표시와 만료 분리만 있고 **마감 할인은 꺼져 있다**. 타블렌과 교환한 뒤 "날짜 가까운 건 싸게 내놔" 조언을 들으면 켜진다(`OpeningJourneyFlow.trade` 가 `FoodShelfLife` 의 `markdown` 을 켬). 계산대 마감 정리에서 끌 수도 있다.
- **건축 학습:** 메뉴의 건축 모드로 놓는 것이 이 단계의 학습이다. 계산대는 설치해도 전원이 없어 켜지지 않는다(기존 설정).
- **불러오기:** 청소 진행은 이야기 기록(`tutorial_event:cleanup:<번호>`)에 남는다. 이미 `setup` 이후 단계를 시작한 옛 저장은 `cleanup`을 건너뛴다(`skip_if_later_started`). 독백을 건너뛰고 불러와도 남은 잔해가 화면에 다시 깔린다(`OpeningCutscene.prepare_cleanup`).
- **후속(미구현):** 기술자 NPC를 만나 제작을 배우고 간이 제작대를 만든다. 합판을 쓰는 레시피, 제작 UI 해금 시점, 기술자 이름·말투는 사용자 결정 대기(❓).

## 코드

- `script/world/shop/tutorial/opening_cleanup.gd`(새) — 더미 6곳(`PILES`: 서는 자리·치우는 연출 집기 번호·얻는 자재), `clean`, `nearest`, `all_done`.
- `tutorial_director.gd` — [E]로 치우기(`_try_clean`), 가장 가까운 더미 위 "▼ [E] 잔해 치우기" 표시, 치운 뒤 얻은 자재 알림. 상속 클래스(`ResidentRequestDirector`)가 같은 처리를 또 돌리지 않도록 `_is_primary()`로 막는다.
- `tutorial_flow.gd` — 목표 `cleanup` 추가, `fixtures`는 문 + 계산대 + 진열대 2개 이상.
- `opening_journey_flow.gd` — 새 게임 시작 때 보관 가구와 함께 온 식품을 비우고(청소로 건진다), 마감 할인을 끈다. 타블렌 교환 때 다시 켠다.
- `opening_store_dressing.gd` — 집기별 잔해 묶음(`debris_by_prop`), `clear_props`, `smash(skip_props)`.
- 글: `data/shop/requests/requests_text.csv`의 `cleanup`·`setup`·`stock`(tutorial_step), `barter` 완료 줄, `default_tutorial.tres`의 단계 설명.

## 검사
