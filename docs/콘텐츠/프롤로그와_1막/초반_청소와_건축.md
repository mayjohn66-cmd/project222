# 초반 청소와 건축 (2026-10-06)

사용자 요청: 가게가 전이되면서 전부 박살 나고, 플레이어가 내부를 청소하면서 얻은 자재로 진열대를 하나 제작하고, 고장 난 계산대와 진열대를 설치하면서 **건축 기능을 알게** 하자.

## 새 흐름 (튜토리얼 단계)

| 순서 | 단계 id | 목표 | 완료 조건 |
|---|---|---|---|
| 1 | `cleanup` 부서진 가게 정리 | 바닥의 잔해 더미 6곳 앞에서 [E]. 쓸 만한 철광석을 얻는다(없는 더미도 있다) | 6곳을 모두 치움 |
| 2 | `craft_shelf` 간이 진열대 만들기 | Esc 메뉴 → 설계도에서 **간이 진열대**(철광석 2) 제작 | 설계도로 간이 진열대를 제작함(제작 기록 `furniture_craft:shelf_1x1`) |
| 3 | `setup` 가게 다시 세우기 | Esc 메뉴 → 건축으로 건진 계산대·진열대와 새 간이 진열대를 설치 | 문 + 계산대 + 진열대(아무 종류) 설치 |
| 4~ | `stock` 이후 | 기존과 같음(진열 → 첫 손님 → 교환 → 원정 …) | |

- **시작 상태:** 가게 안에는 **문만** 설치돼 있다. 보관함에는 건진 **계산대 1개와 진열대(1×1) 1개**뿐이다(2×1·3×1 진열대는 부서져 없음, `default_tutorial.tres`의 `salvaged_furniture`). 창고 선반·음료 제조기 등 다른 시작 가구는 그대로다.
- **자재 양:** 6곳을 모두 치우면 철광석 4개(4곳에서 1개씩, `OpeningCleanup.PILES`의 `loot`). 간이 진열대 제작(철광석 2)을 두 번 할 수 있다. **예정:** 청소에서 빵·물·철광석을 얻어 진열대를 만들고 전시·진열하는 튜토리얼로 바꿀 계획(사용자 방향 대기). 무료 완성품·식품·돈은 없다.
- **건축 학습:** 메뉴의 건축 모드로 놓는 것이 이 단계의 학습이다. 계산대는 설치해도 전원이 없어 켜지지 않는다(기존 설정).
- **불러오기:** 청소 진행은 이야기 기록(`tutorial_event:cleanup:<번호>`)에 남는다. 이미 `setup` 이후 단계를 시작한 옛 저장은 `cleanup`·`craft_shelf`를 건너뛴다(`skip_if_later_started`). 독백을 건너뛰고 불러와도 남은 잔해가 화면에 다시 깔린다(`OpeningCutscene.prepare_cleanup`).

## 코드

- `script/world/shop/tutorial/opening_cleanup.gd`(새) — 더미 6곳(`PILES`: 서는 자리·치우는 연출 집기 번호·얻는 자재), `clean`, `nearest`, `all_done`.
- `tutorial_director.gd` — [E]로 치우기(`_try_clean`), 가장 가까운 더미 위 "▼ [E] 잔해 치우기" 표시, 치운 뒤 얻은 자재 알림. 상속 클래스(`ResidentRequestDirector`)가 같은 처리를 또 돌리지 않도록 `_is_primary()`로 막는다.
- `tutorial_flow.gd` — 목표 `cleanup`·`craft_shelf` 추가, `fixtures`는 문 + 계산대 + 진열대 그룹 아무 것.
- `opening_journey_flow.gd` — 새 게임 시작 때 건진 가구만 남긴다(`salvaged_furniture`).
- `opening_store_dressing.gd` — 집기별 잔해 묶음(`debris_by_prop`), `clear_props`, `smash(skip_props)`.
- 글: `data/shop/requests/requests_text.csv`의 `cleanup`·`craft_shelf`·`setup`(tutorial_step), `default_tutorial.tres`의 단계 설명.
