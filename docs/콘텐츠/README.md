# 콘텐츠 지도 (플레이어가 만나는 순서)

2026-10-08 정리. 콘텐츠 기록 46개가 막별·날짜별로 흩어져 있어서, **플레이어가 게임에서 만나는 순서**로 다시 줄을 세웠다. 파일은 옮기지 않았고 링크만 모았다(`docs/README.md` 4장은 이 문서를 가리킨다).

- **현행** = 지금 구현 기준으로 읽는 문서. **구 기록** = 구현 전 설계나 옛 규칙이라 일부가 바뀌었으니, 안에 적힌 "현재 사양" 링크를 따라가야 한다. **검증** = 확인 결과 기록.
- 같은 주제는 한 묶음으로 모았다. 처음 보는 사람은 각 묶음의 **현행**부터 읽는다.
- 새 콘텐츠 문서를 만들면 이 표의 알맞은 묶음에 한 줄을 추가한다(빠뜨리면 `python tools/docs_check.py`가 알려 준다).
