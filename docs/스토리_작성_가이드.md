# 스토리 스크립트 작성 가이드 (제미나이용, 초안 v0.1)

작성일: 2026-10-01 · 대상: 스토리 스크립트를 쓰는 AI(제미나이)와 그것을 게임에 넣는 사람·AI
태그: ✅확정 / 🟡제안 / ❓미정

## 1. 역할과 흐름 ✅
- **제미나이 = 스토리 스크립트(대사·장면 구성) 담당.** 코드·수치·이미지는 건드리지 않는다.
- 흐름: ① 제미나이가 **초안 CSV**를 쓴다 → ② `python tools/validate_story.py . <초안 파일>`로 형식 검사 → ③ Claude가 선물·조건 **밸런스를 확인** → ④ 사용자가 내용을 보고 승인 → ⑤ `data/story/story_beats.csv`에 합친다.
- 초안 위치: `docs/drafts/story/` (예: `story_beats_gemini_001.csv`). **`data/`에 직접 쓰지 않는다.**
- 브랜치: `feature/story-script` (기능 브랜치, `AI_협업_규칙.md` 2장).

## 2. 출력 형식 (게임이 읽는 그대로) ✅
파일: `data/story/story_beats.csv`, 열은 정확히 이 순서입니다.

```
beat_id,npc_id,conditions,gifts,repeat_days,lines
```

| 열 | 형식 | 설명 |
|---|---|---|
| `beat_id` | 소문자·숫자·밑줄 | 장면 이름. 중복 금지 (`welcome_oven`) |
| `npc_id` | `data/story/story_npcs.csv`의 `npc_id` | 현재는 `neighbor`(이웃 주민)만 있음. 새 NPC는 사용자 승인 후 추가 |
| `conditions` | `;`로 이은 조건, **모두 맞아야** 나옴 | 아래 3장 목록만 사용 |
| `gifts` | `종류:아이디:수량`을 `;`로 이음. 종류 = `item` / `furniture` / `money` | 없으면 빈 칸 |
| `repeat_days` | 숫자 | 0 = 한 번만, N = N일마다 반복 가능 |
| `lines` | 대사 한 칸을 `\|`로 이음 | 한 칸 = 대화창 한 번 |

예:
```
welcome_oven,neighbor,day>=2;expedition_done;furniture_missing:magic_oven,furniture:magic_oven:1,0,개업 축하해요!|마을 사람들이 조금씩 모아서 만들었어요.|잘 써 줘요.
```

## 3. 쓸 수 있는 조건 ✅ (`story_conditions.gd`와 같은 목록)
- `day>=N` — 게임에서 N일 이상 지남
- `expedition_done` — 원정을 한 번 이상 다녀옴
- `money<N` — 소지금이 N 미만
- `item_below:아이템아이디:N` — 그 아이템이 N개 미만
- `furniture_missing:가구아이디` — 그 가구가 인벤토리에도 배치된 것에도 없음
- `product_stock_empty` — 팔 수 있는 상품이 모두 0개

**이 목록에 없는 조건은 게임에서 항상 거짓**이라 장면이 영원히 안 나옵니다. 새 조건이 필요하면 쓰지 말고 `docs/AI_소통.md`에 요청합니다(코드는 ChatGPT).

## 4. 아이디는 실제 파일에서 가져온다 ✅
- 아이템: `data/core/items.csv`의 `id`. 가구: `data/shop/catalogs/furniture_items.csv`의 `id`. **없는 아이디를 만들어 쓰지 않는다**(검사기가 오류로 잡음).

## 5. 글쓰기 규칙 🟡
- 한 칸 **40자 이내**, 장면당 **6칸 이하**(대화창 크기에 맞춘 값, ❓ 실제 화면 확인 필요).
- 말투: 편의점이 있는 작은 마을의 이웃. 따뜻하고 짧게. 게임 수치(골드, 확률, 숫자 능력치)를 대사에 직접 쓰지 않는다.
- 원정 규칙의 결정을 어기지 않는다: 포션은 원정에서 쓰지 않고, 공격력·방어력 숫자는 공개하지 않으며, 원정은 요일 제한이 없다.
- 선물은 **도움이 필요한 상황(조건)에 맞는 것만**, 수량은 적게. 돈 선물은 밸런스 영향이 커서 Claude 확인 후에만 넣는다. 선물 목록은 `docs/원정_v2_규칙서_초안.md` 6.6을 참고(시작 자금은 임시값).
- 미정(❓) 설정(세계관 이름, 지역 이름, 최종 스토리)은 임의로 정하지 말고 초안 맨 위 주석 대신 `docs/AI_소통.md`에 질문으로 남긴다.

## 6. 제미나이 API 사용 (사용자 PC에서) ✅ 보안 규칙
- **API 키를 저장소에 올리지 않는다.** 채팅·문서·커밋·코드·스크린샷에도 붙이지 않는다(Pixel Lab 토큰이 이미 한 번 노출됨).
- 키는 사용자 PC의 **환경 변수**(예: `GEMINI_API_KEY`)나 저장소 밖 파일에만 둔다. `.gitignore`에 `.env`, `*.key`, `gemini_*.json`을 막아 두었다.
- 클라우드 작업(Claude 환경)에서는 사용자 키를 쓰지 않는다. 제미나이 호출은 **사용자 PC 로컬**에서만 한다.
- 실행 방식(Gemini CLI, AI Studio 웹, 스크립트)은 ❓ 사용자가 정하면 `tools/`에 실행 스크립트를 추가한다. 어느 방식이든 결과는 2장 형식의 CSV 초안으로 `docs/drafts/story/`에 저장한다.

## 7. 제미나이에게 줄 프롬프트 틀 🟡
```
너는 편의점 경영 + 판타지 원정 게임의 스토리 작가다. 아래 규칙에 맞는 장면 CSV 행만 출력한다(설명·머리말 없음).
- 열: beat_id,npc_id,conditions,gifts,repeat_days,lines  (쉼표 구분, 대사 안에 쉼표가 있으면 칸 전체를 큰따옴표로 감쌈)
- npc_id는 neighbor만 사용. 조건은 day>=N, expedition_done, money<N, item_below:아이디:N, furniture_missing:아이디, product_stock_empty 만 사용.
- 선물은 item/furniture/money 중 하나, 아이디는 내가 준 목록에 있는 것만 사용.
- lines는 | 로 나누고 한 칸 40자 이내, 6칸 이하. 따뜻하고 짧은 이웃 말투.
- 게임 수치(골드·확률·공격력)를 대사에 쓰지 않는다.
장면 주제: <여기에 주제>
쓸 수 있는 아이템 아이디: <items.csv의 id 목록>
쓸 수 있는 가구 아이디: <furniture_items.csv의 id 목록>
```
