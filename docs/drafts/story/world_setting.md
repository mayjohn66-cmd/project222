# 스토리 세계관 설정 (제미나이 프롬프트에 자동으로 붙음)

> 이 파일의 내용은 `dev/gemini/story_draft_generator.gd`가 시스템 프롬프트 끝에 붙여서 제미나이에게 줍니다. 코드를 고치지 않고 이 파일만 고치면 됩니다.
> 상태: 🟡 시험용 설정(2026-10-01, 제미나이 제안을 사용자가 전달). 확정되면 `docs/원정_v2_규칙서_초안.md`와 이 파일을 함께 갱신합니다.

[세계관 배경]
- 이세계 숲 한가운데에 현대의 24시 편의점이 통째로 떨어져 있다.

[NPC 반응 지침]
1. 처음 방문하는 NPC는 편의점의 현대적 요소(유리창, 형광등 불빛, 자동문, 간판 글자, 진열대)를 이세계의 시선(마법 도구, 신기한 건축물, 경계심)으로 신기해하거나 놀라는 대사를 1줄 이상 포함한다.
2. 인위적인 게임 용어(퀘스트, 아이템, 보상, 레벨 등) 대신 자연스러운 소문이나 개인적인 부탁 형태로 선물이나 도움이 오가는 흐름을 만든다.

[주의 — 이 게임에 실제로 있는 것만]
- 게임에는 **"퀘스트"라는 이름의 시스템은 없지만, 주민의 "부탁"(주민 부탁·마을 부탁 게시판)은 있다.** 그래서 대사에서 "퀘스트", "의뢰 수락", "완료 보상", "레벨" 같은 게임 용어는 쓰지 않고, 사람이 하는 자연스러운 부탁("이게 좀 필요한데 구해 줄 수 있어요?")으로 말한다.
- 부탁의 수량·보상(돈·평판)·필요한 재료는 이 문서나 대사로 약속하지 않는다. 숫자는 게임 데이터가 정한다.
- 인물 이름은 아래 목록만 쓴다. 새 지역·마을·인물의 고유 이름은 만들지 않는다. 이름은 이세계 분위기에 맞춘 것이다.
