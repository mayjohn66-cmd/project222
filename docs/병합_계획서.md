## 3. 권장 병합 순서

1. **`village-life` → main** (충돌 2개, 위 표대로 해결)
2. **`story-script` → main** (village-life에 이미 들어간 82개는 건너뛰고 고유 커밋 1개만 반영, `AI_소통.md` 충돌 1개)
3. **`iso-3d-store` → main** (충돌 3개)

이유:
- `story-script`는 사실상 `village-life`의 부분집합이라 `village-life`를 먼저 합치면 자동으로 정리됩니다.
- 3D는 가장 크고 `main.tscn`을 건드리므로 마지막에 합쳐 앞선 변경 위에서 해결합니다.
- 3D는 `F10` 스위치(기본 꺼짐)라서 합쳐도 기존 게임 화면에는 영향이 없습니다.
