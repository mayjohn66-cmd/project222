# 프롤로그 장면 시나리오 요청 (제미나이용)

작성: 2026-10-07 · 대상: 새 게임 프롤로그 4장면의 대사와 행동 지문을 제미나이에게 다시 쓰게 하는 요청

**무엇을 하나:** 지금 프롤로그 독백은 설명투라 정적이다. 제미나이가 *대사 + 행동 + 감정*이 함께 있는 장면 시나리오를 쓰고, Claude가 그것을 CSV(`data/shop/requests/requests_text.csv`)와 연출 코드(`opening_cutscene.gd`)로 옮긴다. 기존 장면 id 4개는 바꾸지 않는다.

## 2. 요청문

```
너의 역할: 편의점 경영 + 판타지 원정 게임의 장면 시나리오 작가다. 소설이 아니라 "게임 장면 대본"을 쓴다.
게임 화면에서 그대로 연기할 수 있도록 대사마다 주인공의 행동·감정·연출 신호를 붙인다.

[상황]
주인공은 현대 24시 편의점의 점장이다(대화창 화자 이름 "점장", 플레이어 닉네임이 들어갈 수 있으나 대사에는 쓰지 않는다).
첫 장면: 손님이 계산하고 나간 뒤 주인공이 시식대 의자에 앉아 유리문 밖(차가 지나가는 도로)을 멍하니 보다 졸아서 잠든다.
이어서 쿵 소리와 함께 하얗게 번쩍인 뒤 깨어난다. 가게는 통째로 낯선 숲 한가운데로 옮겨 와 있고, 진열대는 전부 부서졌으며 계산대와 진열대 하나만 남았다.
계산대 전원은 켜지지 않는다. 창고의 빵과 물은 멀쩡하다. 이세계로 온 원인은 끝까지 밝히지 않는다(신·마법사·소환·저주 설정 금지).
현지인은 아직 만나지 않았다. 새 인물·새 물건·새 지급은 만들지 않는다.

[지금 문제]
현재 독백은 주인공이 너무 침착하다. 놀라고 당황하고 부정하고 허탈해하다가 "일단 내가 아는 일부터 하자"로 마음을 다잡는 흐름이 느껴지게 다시 쓴다.
하지만 과장된 코미디나 비명 연속은 피한다. 스타듀밸리 같은 잔잔한 생활극의 톤 안에서 사람다운 흔들림을 보여 준다.

[장면 4개 - id는 바꾸지 않는다]
1) prologue_last_shift      손님이 나간 뒤 시식대에서 창밖을 보다 존다. 마지막 줄은 검은 화면에서 잠깐 졸다 깬 사람이 하는 말.
2) prologue_unfamiliar_window  쿵 소리 → 깨어남 → 창밖과 가게를 확인 → 계산대 전원이 안 켜짐을 알아챈다.
3) prologue_food_dates      창고의 빵과 물 확인. 유통기한부터 걱정하는 점장의 직업 습관.
4) prologue_keep_the_light  혼자 바깥으로 나가긴 두렵다. 익숙한 가게 안부터 정리하기로 한다. 이 뒤에 청소 튜토리얼이 이어진다.

[분량 제한]
- 장면 하나당 대사 2~4줄, 전체 12줄 이내. (기존은 3·3·2·2줄)
- 한 줄은 45자 이내. 대사창 한 번에 한 줄이 나온다.

[말투]
- 서술체 독백은 "~다"체로 써도 되지만, 마음속 목소리(혼잣말)는 반말 구어체를 섞는다("~네", "~잖아", "…뭐야").
- 게임 용어(퀘스트·보상·레벨·UI 등)와 현대 기계 용어 설명은 쓰지 않는다. "편의점"이라는 단어는 써도 된다.
- 같은 문구를 두 장면 이상에서 반복하지 않는다. 숫자로 개수를 말하지 않는다("두 개", "3개" 금지, "하나뿐"은 가능).
- 쉼표(,)는 쓰지 않는다. 문장 안 쉼은 "…"이나 마침표로 대신한다.

[행동 지문에 쓸 수 있는 것]
게임이 지금 보여 줄 수 있는 연출은 아래뿐이다. 이 목록에서 골라 쓴다.
- 걷기 / 뛰기 + 목적지: 문, 진열대 앞, 계산대 앞, 가게 가운데, 시식대
- 앉기 / 일어서기
- 멈칫(잠깐 멈춤, 약 1초)
- 화면 흔들림 / 하얗게 번쩍 / 검은 화면 / 눈 깜빡임(졸림)
- 소리: 도로 소리, 바람 소리, 쿵, 계산기 삑, 조용함(무음)
- 카메라: 평소 시점 / 앉은 눈높이 1인칭(창밖을 볼 때만)
목록에 없는 동작이 꼭 필요하면 줄 끝에 "(신규 요청: 동작 이름과 이유)"로 적는다. 구현 여부는 내가 판단한다.

[출력 형식 - 이 표 그대로, 표 앞뒤에 다른 설명 없이]
| 장면 id | 줄 | 대사 | 행동(대사를 읽은 직후) | 감정 한 단어 | 소리·카메라 |
|---|---|---|---|---|---|

장면마다 줄 번호는 1부터. 행동이 없으면 "-".
표 아래에 "고민한 점" 3줄 이내만 덧붙여도 된다.
```

## 3. 받은 뒤의 흐름

1. 받은 표를 **사용자가 훑어 톤을 고른다**(마음에 안 들면 같은 요청문에 "더 담담하게/더 웃기게" 한 줄만 더해 다시 받는다).
2. Claude가 표를 CSV 4행과 연출 코드로 옮긴다. 글 점검기(`check_request_text`, 반복 어구·숫자 표현)에 걸리는 곳은 최소한으로만 고친다.
3. 신규 요청 동작은 Claude가 구현 가능 여부와 비용을 알린다.
4. 확인은 `dev/spike3d/prologue_walk_shot.tscn`(화면 필요)과 PC에서 새 게임 시작으로 한다.

## 4. 이미 있는 제미나이 흐름과의 관계

- 제미나이는 이미 스토리 글 담당이다(`docs/AI_협업_규칙.md`, `docs/스토리/작성_가이드.md`). 이 요청은 그 흐름을 새로 만드는 것이 아니라 **프롤로그 4장면에 한해 "행동 지문 포함 대본" 형식을 시험**하는 것이다.
- 결과를 `data/`에 넣기 전 초안은 `docs/drafts/story/`에 둔다.
- 대본 형식이 쓸 만하면 다른 장면(첫 거래, 첫 원정)에도 같은 틀을 쓴다.
