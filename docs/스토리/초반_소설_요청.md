# 초반 전체 소설 집필 요청 (제미나이용)

## 2. 요청문

```
너의 역할: 편의점 경영 + 판타지 원정 게임의 소설가다. 이번 일은 게임 대사가 아니라 "초반 이야기를 소설로" 쓰는 것이다.
이 소설은 게임에 그대로 실리지 않는다. 주인공의 감정이 어떻게 흔들리고 가라앉는지, 인물들이 어떤 말투로 어떤 행동을 하는지 기준을 잡는 자료다.

[범위: 아래 8개 장면을 이 순서로, 장면마다 제목 표시]
1. 마지막 손님: 야간 편의점. 손님 한 명이 계산하고 나간다. 점장은 시식대에 앉아 유리문 밖 도로를 멍하니 본다. 졸음이 온다.
2. 깨어남: 쿵 소리. 눈을 뜨니 가게가 통째로 낯선 숲에 있다. 도로도 차도 없다. 진열대는 전부 박살났다.
3. 건져 보기: 놀람과 부정. 그래도 "남은 거라도 건져 보자"며 잔해를 치우다 빵·물·합판·계산대·진열대 둘을 건진다. 그나마 멀쩡한 게 이거뿐인가 싶은 허탈함. 계산대 전원은 나가 있다.
4. 다시 세우기: 만들 줄 모르니 일단 건축부터. 망가졌지만 이거라도 올려 둘까 하며 계산대와 진열대를 놓는다. 이 세계에서도 음식은 상할 텐데 날짜를 신경 써야 하나 하는 걱정.
5. 첫 손님 델빈: 유리문 밖을 기웃대던 현지 청년이 와서 빵 하나를 동전으로 산다. 서로 모르는 물건과 돈. 
6. 행상인 타블렌: 낯선 빵과 물이 탐난다며 검과 가죽 갑옷과 교환하자고 한다. 날짜 가까운 음식은 싸게 내놓으면 이득이라는 조언을 흘린다.
7. 숲길로: 손에 쥔 검과 갑옷. 무서움과 호기심 사이에서 첫 원정을 결심한다.
8. 돌아온 밤: 원정에서 건진 재료(소설 안에서 물건 이름은 풀·열매 정도로만)를 가게에 두고 하루를 마무리한다. 아직 만들 줄은 모르지만, 언젠가 기술자를 만나 배우게 될 거라는 막연한 예감 한 줄.

[이야기 규칙]
- 편의점이 이세계에 온 이유는 끝까지 밝히지 않는다. 신·마법사·소환·저주·사고 설정 금지. "닮아 보인다" 정도의 질문으로만 남긴다.
- 위협·악역 없음. 스타듀밸리 같은 잔잔한 생활극. 던전·몬스터는 재료 구하러 가는 배경일 뿐이다.
- 새 인물은 만들지 않는다. 등장은 점장(주인공), 델빈, 타블렌, 이름 없는 마지막 손님뿐이다. 기술자는 이름 없이 "언젠가 만날 누군가"로만 언급한다.
- 숫자로 수량을 늘어놓지 않는다(빵 몇 개, 물 몇 개 같은 나열 금지).
- 게임 용어(퀘스트·레벨·UI·튜토리얼 등)와 현대 기계 설명을 쓰지 않는다.

[감정선: 가장 중요]
- 지금 게임의 주인공은 너무 침착하다. 놀람 → 부정 → 허탈 → 어쩔 수 없이 손을 움직임 → 작은 안도 → 낯선 사람과의 어색함 → 용기, 순으로 감정이 눈에 띄게 흔들리고 가라앉아야 한다.
- 과장된 코미디·비명 연속은 피한다. 말줄임·혼잣말·몸의 반응(손이 떨림, 뺨을 꼬집음)으로 보여 준다.
- 장면 안에서 주인공이 하는 행동을 구체적으로 쓴다(앉는다, 일어선다, 뛰어간다, 멈칫한다, 뒷걸음질 친다, 주저앉는다, 문을 연다, 물건을 든다). 나중에 화면 동작으로 옮길 근거가 된다.

[분량·시점]
- 전체 5000~7000자. 장면당 600~900자.
- 3인칭 한정 시점(점장의 마음에 가깝게). "~다"체.
- 대사는 말투 규칙을 따른다: 델빈은 또렷한 친근한 반말, 타블렌은 입담 좋은 친근한 반말, 점장의 혼잣말은 구어체 반말.

[끝에 덧붙일 것]
소설 아래에 표를 하나 붙인다. 소설에서 게임 화면으로 옮길 만한 핵심 순간만 골라 쓴다.
| 장면 번호 | 핵심 순간(한 문장) | 점장의 행동 | 감정 한 단어 | 대사로 옮길 만한 문장(원문 그대로 인용) |
|---|---|---|---|---|
```

## 3. 받은 뒤의 흐름

1. 사용자가 소설을 읽고 **톤과 감정선이 맞는지**만 먼저 본다(사건 순서는 이미 정해진 흐름이라 바꾸지 않는다).
2. 마음에 들면 Claude가 아래 표를 기준으로 4장면 대본을 새로 뽑아 요청서(`프롤로그_시나리오_요청.md`)의 출력 형식으로 정리한다(필요하면 제미나이에게 같은 형식으로 다시 쓰게 한다).
3. 인용한 문장이 글 점검기(쉼표·숫자 표현·반복 어구)에 걸리면 Claude가 최소한만 고친다.
4. 소설 원문은 `docs/drafts/story/`에 둔다(게임 데이터 `data/`에 넣지 않는다).

## 4. 이 요청이 하지 않는 것

- 기술자 NPC의 이름·성격·등장 시점은 정하지 않는다(사용자 결정 대기, `초반_청소와_건축.md`의 후속).
- 2막 이후(제작, 개인 부탁, 마을)는 다루지 않는다. 초반 흐름이 자리 잡은 뒤 같은 방식으로 이어 쓴다.

## 5. 후속 요청: 3·4장면 다시 쓰기 (2026-10-07)

첫 소설(`docs/drafts/story/초반_소설_gemini_001.md`)은 구조는 좋았지만 3·4장면의 감정이 요약으로 지나갔다. 이 두 장면만 다시 쓰게 한다.

붙여 넣을 것: 위 2장 요청문 중 "[이야기 규칙]"과 "[감정선]" 블록, 첫 소설의 2·3·4장면 원문(대화에서 받은 것), 아래 요청문. 세계관·말투 자료는 같은 대화에 이미 있으면 다시 붙이지 않는다.

```
앞서 쓴 소설의 3장면(건져 보기)과 4장면(다시 세우기)만 다시 쓴다. 나머지 장면은 건드리지 않는다.

[무엇이 문제였나]
두 장면 모두 감정이 "~했다"로 요약되어 지나갔다. 점장이 거의 혼잣말을 하지 않고 몸의 반응도 적다. 독자가 점장과 같이 흔들리지 않는다.

[고치는 방법]
- 장면마다 점장의 혼잣말(소리 내어 하는 말)을 최소 세 번 넣는다. 한 번에 한 문장, 25자 이내, 구어체 반말. 예: "…이게 말이 돼?", "하나라도 건지자.", "아직 따뜻하잖아."
- 몸의 반응을 장면마다 최소 두 번 쓴다. 손 떨림, 숨이 막힘, 삼킨 침, 무릎에서 힘이 풀림, 이마의 땀, 코끝이 시큰함 등. "당황했다" 같은 감정 이름을 직접 쓰지 말고 몸과 행동으로 보여 준다.
- 3장면은 놀람이 가라앉으며 억지로 손을 움직이게 되는 과정이다. 처음엔 멍하고 → 현실을 부정하고(뺨 꼬집기) → 허탈하게 웃고 → "그래도 뭐라도" 하며 잔해를 뒤진다. 건진 것을 하나씩 발견할 때마다 작은 반응(빵을 안고 안도, 계산대 전원이 안 켜질 때 가라앉음)을 넣는다. 계산대와 진열대 둘이 남은 것을 알았을 때 "그나마 멀쩡한 게 이거뿐인가"라는 허탈한 혼잣말이 나와야 한다.
- 4장면은 만들 줄 모르니 건축부터 하는 장면이다(제작 설정을 쓰지 않는다). 망가진 계산대를 올려 두며 "망가졌지만 이거라도 올려 둘까" 하는 마음, 빵 포장의 날짜를 보고 "이 세계에서도 음식은 상할 텐데" 하는 불안, 그리고 손을 움직이면서 조금씩 안정되는 호흡을 보여 준다.
- 한 장면 안에서 감정이 한 방향으로만 흐르지 않게 한다. 흔들림과 가라앉음이 번갈아 와야 한다.

[지킬 것]
- 이세계에 온 원인은 밝히지 않는다. 새 인물·새 물건을 만들지 않는다. 수량을 숫자로 나열하지 않는다.
- 장면당 800~1100자. 3인칭 한정 시점 "~다"체. 대사는 구어체 반말.
- 과장된 코미디·비명 연속은 피한다.

[출력]
1) 다시 쓴 3장면, 4장면 소설 본문.
2) 표: | 장면 번호 | 순간(한 문장) | 점장의 행동 | 몸의 반응 | 혼잣말 원문(25자 이내 그대로 인용) |
혼잣말은 장면마다 최소 세 개를 표에 넣는다. 이 문장들을 게임 대사 후보로 쓴다.
```

받은 뒤: 혼잣말 원문을 후보로 삼아 Claude가 `cleanup`·`setup` 단계 대사와 깨어남 장면 줄에 넣을 만한 것을 고르고, 글 점검에 맞춰 다듬어 반영한다.
