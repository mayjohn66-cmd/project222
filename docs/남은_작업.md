## 1. 사용자만 할 수 있는 일 (이 클라우드 환경에서는 확인 불가)

| 일 | 이유 |
|---|---|
| **PC에서 `GODOT_EXE=… dev/run_all_checks.sh` 실행** | 클라우드에서는 검사 56개가 모두 통과하지만 실제 PC 결과는 아직 모른다. |
| **게임 실행 후 화면 확인** | 책 UI(곡선 넘김·포스트잇), 대화창 줄바꿈, "화덕" 이름, F7 날씨 전환, 계절 채집 표시, **프롤로그 연출**(시간·카메라·화면)을 실제 GPU에서 본 적이 없다. |
| **프롤로그 소리 들어 보기** | 파일 없이 코드로 만든 도로 소음·숲 바람이다. 클라우드에는 오디오가 없어 들어 보지 못했다. 크기는 `opening_road_noise.gd`의 `VOLUME_DB`. |
| Pixel Lab 첫 시험(`moss_cottage`) 결과 보고 | 인수인계 1번 대기 중 |

2. **쉼터 첫 모임 시간대 15~18시 → 14~19시** — 인수인계 25. `VillageRestSettings` 값 2개.
3. **이미지·에셋** (`python tools/validate_assets.py .`)
   - 아이콘 파일 없음 86개(`art/items/pixel_v1/`에 36장뿐)
   - 규격 FAIL 14개(가구 12개와 `treasure_map`, `wild_berry`: 색 상한 초과, 반투명 픽셀)
   - 버전 폴더 7개 정리
   - 이 2D 그림이 3D 전환 뒤에도 쓰이는지부터 확인
4. (선택) **프롤로그 도시 소품** — 지금 도시 거리는 임시 입방체다. 건물·차·가로등을 3D 소품으로 만들면 더 그럴듯해진다(`프롤로그_연출.md`).
