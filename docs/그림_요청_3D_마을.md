# 그림 요청 — 3D 마을 건물·소품 (자동 생성)

> 이 문서는 `tools/build_art_request_doc.py` 가 만든다. 직접 고치지 말고 `data/shop/catalogs/village_3d.csv`·`village_3d_assets.csv` 를 고친 뒤 다시 생성한다.
> 각 자산 폴더(`docs/drafts/art_requests/<id>/`)에 **면 질감 틀 PNG(정확한 크기, 임시 그림)**, 3D 미리보기(`preview.png`), 요약 시트(`sheet.png`, 2D 원본 그림 포함)가 있다. 2D 원본은 각 자산의 `art/…` 경로에 있다.

## 0. 한눈에

- 자산 24종(건물 8, 소품 16), 면 질감 틀 총 153장(자산별 중복 포함).
- 면 이름이 같은 것(예: `crate`, `barrel`, `wood`)은 **한 번만 그려서 여러 자산이 같이 써도 된다**(아래 5장 공용 면 목록).
- 지금 질감은 모두 코드로 칠한 임시 그림이라, 같은 크기·같은 배치로 새로 그리면 그대로 교체된다.

## 1. 공통 규칙 (그림 담당 전달)

1. **크기는 틀 PNG 와 같게**: 틀 크기가 곧 최종 크기다. 확대·축소하지 않는다(도트 한 칸 = 낮은 해상도 한 픽셀, 게임이 3배로 키운다).
2. **그림에 외곽선·그림자·빛을 넣지 않는다**: 윤곽선은 게임이 후처리로 그리고, 밝고 어두움·그림자는 게임의 빛이 만든다(낮/밤이 바뀜). 그림은 "빛이 없을 때의 색"을 평평하게 칠한다. 벽돌 줄눈·나무결·창틀 같은 **안쪽 선**은 그려도 된다.
3. **알파(투명)는 쓰지 않는다**: 모든 면은 불투명.
4. **색**: 한 장 8~12색, 같은 자산의 면끼리 팔레트를 공유(예: 빵집의 벽·기단·창틀 색).
5. **반복(이음매) 면**: 표에서 "반복"인 면은 위아래·좌우가 이어져야 한다(가장자리를 맞춘다).
6. **법선 맵**(`_n` 접미): 지붕 기와는 필수 규격이 있다(기와 한 장 한 장의 불룩함). Pixel Lab 이 법선 맵을 못 내면 **높이 맵(회색조, 밝을수록 높음)** 을 같은 크기로 주면 `tools/height_to_normal.py` 로 변환한다. 다른 면은 선택.
7. **파일 이름·위치**: `art/world3d/<자산id>/<면이름>.png`(알베도), `<면이름>_n.png`(법선 맵). 면 이름은 아래 표의 이름 그대로. **넣는 법**: `python tools/ingest_world3d.py <자산id> <그림 파일 또는 폴더>` — 크기·불투명·색 수를 검사하고 위 위치에 넣어 준다(`--resize` 로 최근접 크기 맞춤).
8. 넣은 뒤: Godot 를 한 번 열어 `.import` 를 만들고 `python tools/fix_texture_import.py` 로 무손실 설정을 맞춘 다음 `python tools/validate_assets.py .` 로 검증. 게임(`dev/spike3d/game_3d_view.tscn`)에서는 **F8** 로 새 그림을 다시 읽는다. 그림이 없는 면은 임시 질감이 계속 쓰이므로 **면 하나씩 넣어도 된다**.

공통 영문 문구(프롬프트 끝에 붙임): `pixel art texture, flat unlit colors, no outline, no cast shadows, no baked lighting, limited palette 8-12 colors, crisp single pixels, nearest-neighbor, {w}x{h} pixels`

## 4. 요청 순서 제안

1. **이끼 오두막**(마을에 가장 많이 놓임) → 벽 앞·옆, 지붕 기와(+법선), 굴뚝 돌, 박공 벽, 지붕 두께 — 한 건물 완성본으로 "그림이 들어간 3D 마을" 느낌을 먼저 확인.
2. 다른 건물 7종(빵집·대장간·도구점 등): 벽 앞·옆과 지붕 색만 새로 그리면 되고, 굴뚝·기단·마당 등은 위에서 만든 것을 재사용.
3. 소품: 사과나무·꽃 덤불·가로등·울타리처럼 개수가 많은 것부터.

## 6. 알려진 한계

- 3D 모양(지붕 각도, 굴뚝, 창문 위치 등)은 임시이며 질감 그림과 함께 조정될 수 있다.
- 문은 카메라에 보이는 앞벽(왼쪽 아래를 보는 면)에 고정이다(2D 원본의 문 방향은 반영하지 않음).
- 창 위치·문 위치는 틀 PNG 의 배치를 따라야 3D 의 화분·계단 위치와 맞는다.
- 실제 PC(GPU) 확인 전. 면 크기는 이 환경의 기준 해상도(칸 36×18, 질감 18)로 계산했다.
