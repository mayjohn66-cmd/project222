# 도형 우선 오브젝트 설계 (초안 v0.1)

작성일: 2026-10-01 · 갱신: 조합 오브젝트 추가 · 브랜치: `feature/iso-objects` · 관련: `에셋_규격서_초안.md`, `이미지_제작_목록.md`

> **2026-10-05 정리**: 이 문서의 2D 도형 클래스(`IsoBox`·`IsoObject`·`IsoSortGroup`·`IsoGeometry`)와 그 미리보기·검사 장면은 매장 전체가 3D 로 바뀌면서 삭제했다(git 기록에 남아 있다). 앞뒤 정렬 계산기 `IsoSorter`(`script/world/shape/iso_sorter.gd`)는 3D 매장 정렬(`StoreView3D`)이 계속 쓰므로 남겼다. 아래 내용은 설계 기록으로만 읽는다.

태그: ✅확정 / 🟡제안 / ❓미정

## 1. 방침 (사용자 결정)
- ✅ 그림을 한 장씩 손으로 놓는 방식이 아니라, **도형(바닥 발자국 + 높이)을 코드로 먼저 만들고 그 도형에 그림을 씌운다.**
- ✅ 이렇게 하면 **충돌 영역·기준점·정렬이 같은 발자국에서 함께 결정**된다. 그림을 바꿔도 충돌은 변하지 않는다.
- ✅ 모든 오브젝트(문, 가구, 건물)를 이 방식으로 옮겨 가는 것이 목표다.

## 2. 구성 (구현됨: `script/world/shape/`)
| 이름 | 역할 |
|---|---|
| `IsoGeometry` | 마름모(96×48, 2:1) 계산. 바닥 발자국, 윗면·왼쪽 면·오른쪽 면, 타일 한 변에 서는 면(`edge_plane`: 문·창문) |
| `IsoBox` | 발자국 칸 수 + 높이만 정하면 면 3개와 충돌 영역(`CollisionPolygon2D`)을 자동 생성하는 `StaticBody2D`. 면마다 그림을 씌우고(없으면 단색), 벽돌·판자 같은 그림은 `repeat_side_textures`로 이어 붙임 |
| `IsoObject` | 여러 `IsoBox` 부품을 조합한 오브젝트(ㄱ자 가로등, 집). 회전·전체 크기·표시 여부를 부품에 전달하고, **완성된 그림 한 장**을 위에 씌울 수 있음(그림이 있으면 도형은 숨김 = 충돌·정렬 전용) |
| `door_visual.gd` | 문은 `IsoGeometry.edge_plane`으로 평행사변형을 만들고 정면 그림을 씌움(적용됨) |

- 좌표 규칙은 기존 `FurnitureFootprint`와 같다: 기준 칸 (0,0) 중심이 원점이고 발자국은 +x, +y로 뻗는다. 바닥 꼭짓점 순서는 [위, 오른쪽, 아래, 왼쪽].
- 충돌 영역은 `FurnitureFootprint.polygon`을 그대로 쓴다. 기존 가구 충돌과 값이 같다(검사로 확인).
- 검사: `dev/scenes/check_iso_box.tscn`(34개 항목, 충돌 = 발자국·면 좌표·문 면 회귀), 미리보기 `dev/scenes/iso_box_preview.tscn`.

## 3. 그림 규격 (제안 🟡)
- 면에 씌우는 그림은 **정면(평면) 그림**이다. 기울기는 코드가 만든다. 그림에 원근을 넣지 않는다.
- 벽·바닥 질감은 **이어 붙이는 타일 그림**(예: 32×32 판자, 벽돌)으로 만들고 `repeat_side_textures`를 켠다.
- 문·창문·간판 같은 패치는 한 장짜리 정면 그림이고 `edge_plane` 면에 씌운다.
- ✅ **곡선·장식은 도형으로 만들지 않는다(사용자 결정).** 곡선 가로등은 "기둥 상자 + 공중에 뜬 팔 상자"(ㄱ자)로 도형을 만들고, 그림만 곡선으로 그려 `IsoObject.art`로 위에 씌운다. 도형은 충돌(기둥만 막고 공중의 팔은 안 막음)과 정렬을 담당한다.
- ✅ **집도 같은 방식**: 몸통 상자 + 굴뚝 + 처마 같은 부품을 조합해 충돌 발자국을 만들고, 지붕·벽·장식이 있는 완성 그림을 위에 씌운다. 부품은 소수 칸(0.3칸 기둥 등), 바닥에서 뜬 높이(`elevation`), 막는지 여부(`blocking`)를 갖는다.
- 그림 위치는 `art_anchor`(그림 안에서 바닥 발자국의 아래 꼭짓점이 오는 픽셀)와 `art_scale`로 맞춘다. 맞추는 동안은 `show_shapes`, `show_outline`을 켠다.
- 부품은 자식 순서대로 그려지므로 뒤쪽(작은 x+y)부터 넣는다(그림이 있으면 영향 없음).

## 4. 이전 계획 🟡
1. (완료) 공통 부품 `IsoGeometry`/`IsoBox` + 문 적용.
2. 가구 시험 이전: 선반 하나를 `IsoBox`로 바꿔 기존 4방향 통그림(`shelf_visual.gd`의 `foot_pixel` 보정 숫자)과 비교한다. 충돌은 기존 `FurnitureCollision`과 같아야 한다.
3. 건물 시제품: 발자국 2×2의 상점 건물을 벽 면 + 지붕 + 문 패치로 구성한다. 지붕(경사)은 처음에 평지붕이나 한 방향 경사부터.
4. 통그림 집(`nearby_houses.gd`, `village_extra_houses.gd`)은 바닥 네 꼭짓점을 데이터로 두고 같은 발자국 통로로 배치한다(마법 숫자 제거).
5. 건축 메뉴(`build_objects.csv`)에 `shape` 열을 추가해 발자국·높이·그림 경로를 데이터로 정한다(❓ 열 이름과 형식은 구현할 때 확정).

## 5. 오픈 이슈 ❓
1. (해결) 기둥·곡선·나무 같은 비상자 오브젝트는 상자 조합(ㄱ자 등)으로 도형을 만들고 그림만 곡선으로 둔다.
2. 지붕 경사면과 박공(삼각형) 계산을 어디까지 코드로 할지.
3. 같은 가구의 회전 4방향 그림을 면 그림 하나로 줄일 수 있는지(면이 4방향에서 달라 보임).
4. 윗면 그림과 그림자(발자국 뒤쪽 어두운 면) 규칙.
5. Y 정렬 기준점(현재 노드 위치 = 기준 칸 중심)을 큰 건물에서 어떻게 잡을지.
