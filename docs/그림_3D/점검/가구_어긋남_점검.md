# 3D 가구 어긋남 점검 (2026-10-08)

**결론: 가구 3D 모델이 칸 영역에서 어긋나는 문제는 없다.** 어긋남처럼 보이는 원인은 모델 크기·위치가 아니라 다른 곳(깊이 정렬, 벽 부착물, 사람·길 위치 등)일 가능성이 크다. 아래 "못 본 것"을 다음 점검 대상으로 삼는다.

## 1. 무엇을 쟀나
- 도구: `dev/scenes/audit_furniture_3d.tscn` (`godot --headless --path . res://dev/scenes/audit_furniture_3d.tscn -- <저장 폴더>`).
- 방법: 건축 카탈로그의 모든 가구를 4방향으로 3D 모델로 만들어, 모델 정점이 차지하는 범위(AABB)를 게임 로직의 칸 영역(발자국, 두께 비율 포함)과 비교한다. 칸 크기는 게임과 같은 규칙(`get_rotated_size`)을 쓴다.
- 대상: 22종 × 4방향 = 88건(진열대·계산대·창고 선반·냉장함·냉동함·음료 제조기·화덕·화분·등불·진열장 등).
- 기준: 튀어나옴 > 0.05칸, 길이·폭 부족 < −0.15칸, 회전별 쏠림 차 > 0.04칸, 높이 차 > 0.12블록, 바닥에서 뜸 > 0.02.

## 2. 결과
| 항목 | 결과 |
|---|---|
| 칸 밖으로 튀어나옴 | **없음**(최대 0.02칸) |
| 회전해도 같아야 할 앞/뒤·좌/우 쏠림 | **없음**(0.00) |
| 모델 중심이 칸 중심과 다름 | **없음** |
| 이상 있는 가구 | 6종(아래). 모두 의도된 설계이거나 아주 작은 차이 |

| 가구 | 점검 표시 | 값 | 해석 |
|---|---|---|---|
| `night_lantern` 등불 | 부족 | 칸의 22%만 채움(폭 0.26) | 가는 기둥 모양이라 의도된 것으로 보임 |
| `plant_small` 작은 화분 | 부족 | 칸의 53% | 작은 소품 설계 |
| `drink_machine` 음료 제조기 | 부족 | 칸의 64%(사방 0.2칸 여백) | 칸 안에 여유를 둔 설계 |
| `magic_oven` 화덕 | 높이 불일치 | 실제 모델 1.62블록, 모델이 선언한 높이 1.4블록(0.22블록 차) | 선언 높이는 정렬·벽 투명 처리에 쓰일 수 있어 확인 필요 |
| `register`류(`wood_register`·`modern_register`) | 공중 | 바닥에서 0.05 단위 떠 있음(약 1px) | 다리 표현이면 의도, 아니면 무시 가능 |

## 3. 못 본 것(이 점검의 한계)
- 모델 **정점 범위만** 봤다. 화면에 어떻게 보이는지(질감·윤곽선·그림자)와 **깊이 정렬**(`IsoSorter`가 가구·사람의 앞뒤를 정하는 부분)은 보지 않았다.
- 벽에 거는 물건(문·포스터·지도·깃발)은 따로 만들어져 이번에 뺐다.
- 2D 로직 노드 ↔ 3D 위치 연동, 사람(직원·손님·플레이어)이 가구 옆에 서는 위치, 건축 미리보기 표시는 보지 않았다.
- 실제 장면에서 가구를 놓았을 때의 결과가 아니라 가구 하나씩 따로 만든 결과다.

## 4. 다음 점검 후보
1. **깊이 정렬**: 가구가 붙은 줄(진열대가 서로 등을 맞댄 곳, 계산대 옆 직원)에서 앞뒤가 뒤집히는 칸을 찾는다.
2. **벽 부착물**: 문·포스터가 벽 두께 안에 정확히 붙는지, 문 옮기기 뒤에도 맞는지.
3. **사람 위치**: 직원·손님이 서는 칸과 3D 가구 모서리가 겹치는지.
4. 화덕 선언 높이 불일치 확인과 수정(필요하면).
