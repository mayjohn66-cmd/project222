# 바닥 질감 규격 (2026-10-08 사용자 확정)

## 확정
- **그림 1장 = 2×2칸.** 64×64 픽셀 정사각형, 한 칸에 32픽셀. 이음새 없이 반복된다.
- 사용자가 모형 화면(`docs/그림_작업/받은그림/바닥/_밀도_비교.png`)을 보고 왼쪽(2×2칸 1장)을 골랐다. 1칸 1장은 무늬가 4배로 촘촘해져 지글거리므로 쓰지 않는다.
- 2D·3D 겸용. 위에서 본 정사각형 그림이고, 등각 2D에서는 마름모 칸에 입혀 그린다.

## 그림 (`art/world/ground/`)
| 파일 | 쓰는 곳 | 원본 후보 |
|---|---|---|
| `wood.png` | 매장 바닥(나무 마루) | `받은그림/바닥/wood_b.png` |
| `tile.png` | 창고·생산실 바닥(타일, 방마다 색조를 곱해 씀) | `tile_b.png` |
| `road.png` | 마을 벽돌길 | `road_b.png` |
| `paving.png` | 광장 포장석 | `paving_b.png` |
| `dirt.png` | 흙길 | `dirt_a.png` |
| `grass.png` | 잔디 | `grass_a2.png`(반복 꽃 점 제거) |

후보와 추천 이유는 `docs/그림_작업/받은그림/바닥/선택안.txt`. 종류별 선택은 Claude 추천안이며 사용자가 바꾸면 이 표와 파일만 교체한다.

## 게임 연결 (코드 담당에게 — 아직 안 함)
- **2D:** `script/world/shop/world_tile_art.gd`의 `draw_cell`이 이미 "그림 1장 = 2×2칸"으로 그린다. preload 경로만 `art/world/cozy_v3/` → `art/world/ground/`로 바꾸면 된다(현재 2D 바닥을 그리는 곳이 없으므로 2D 전환 때).
- **3D:** 지금은 `PlaceholderTextures.albedo(kind, texture_size)`가 코드로 만든 무늬를 쓰고(`store_view_3d.gd` `_make_surface_material`, `village_mirror.gd` `GROUND_TEXTURES`), 한 칸마다 한 번 반복된다. 연결하려면
  1. kind(`grass`·`brick`·`dirt`·`tile`·`wood`)에 맞는 그림을 `art/world/ground/`에서 읽고, 없으면 지금처럼 코드 무늬로 돌아간다.
  2. **반복 크기를 2칸에 1번으로**(`texel_per_unit` 등 셰이더 값). 1칸 1번이면 위의 촘촘한 화면이 된다.
  3. 필터는 최근접(NEAREST), 밉맵 없음.
  4. 계절 색조(`SeasonStyle`의 `grass_tint` 등)는 지금처럼 곱해서 쓴다. 그림이 이미 색을 가지므로 색조는 흰색에 가깝게 조정이 필요할 수 있다(미확인).
- `road`와 `paving`은 지금 둘 다 `brick` 무늬를 공유하므로 그림을 나눠 쓰려면 표를 분리해야 한다.

## 확인하지 못한 것
- 실제 게임 화면(3D 카메라 각도·확대)에서의 모습. 모형은 96×48 등각 칸에 64px 캐릭터를 세운 Python 합성이다.
- Godot 가져오기 설정(`.import`)은 아직 만들지 않았다. 편집기를 열면 생성된다.
