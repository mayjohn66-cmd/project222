# 이세르의 마을 이야기 (2026-10-03)

퀘스트·이벤트 추가 순서의 두 번째. **등불 아래의 길손 → 이세르의 마을 이야기 → 작은 노점의 첫 장터** 중 앞의 두 콘텐츠가 구현되었으며 장터는 다음 단계다.

## 플레이 흐름

1. 튜토리얼과 주민 세 명의 정착, 우물 곁 저녁 모임 실제 참여, 이세르의 **우물 곁 기록** 개인 부탁, 등불 아래 길손의 **재회**를 마친다.
2. 이세르에게 가까이 가서 E로 새 이야기를 끝까지 듣는다. 물품을 모아 전달하는 부탁이 아니라 이웃들의 기억을 듣고 함께 남기는 부탁이다.
3. 타블렌·코르빈과 각각 대화한다. 순서는 자유롭고 새 부탁을 받은 이후 대화를 끝까지 들어야 수첩에 기록된다. 이전의 안부나 중단한 대화는 대신 세지 않는다.
4. 이세르에게 돌아가 대화를 마치면 기억 선택 화면이 열린다. **길을 밝힌 불빛 / 함께 쉬던 저녁 / 머물 곳이 생긴 날** 중 하나를 선택한다. 창을 닫고 나중에 결정할 수 있다.
5. 선택한 기억의 마무리 대화를 끝까지 들으면 **숲 약초 2개·평판 1**을 한 번 받는다. 어떤 기억을 골라도 답례는 같고 돈·새 손님·시설 해금은 없다. 새 수치는 초기 조정값이다.
6. 마을 수첩에 선택한 제목·기억·날짜가 남는다. 이후 이세르에게 다시 이야기하면 같은 기억을 읽을 수 있으며 퀘스트 답례는 다시 지급하지 않는다.

재료 소비와 기한은 없다. 기존 주민의 하루 한 번 안부·친밀도·작은 선물은 계속 적용되며, 퀘스트 답례와는 별도다. 새 책 아이템이나 별도 읽기 화면을 만든 것이 아니라 기존 수첩과 대화를 사용한다.

## 연결과 저장

- 새 NPC를 복제하지 않는다. 기존 세 주민의 대화에 필요한 장면만 연결했다. `main.tscn`에 노드를 추가하지 않았다.
- 진행 로직은 `VillageStoryFlow`, 조정 값과 장면 ID는 `default_village_story.tres`/`VillageStorySettings`, 선택 화면은 `VillageStoryPanel`에 있다. `VillageLifeDirector`에는 대화 시작·완료·선택 신호의 연결만 넣었다.
- `village_story:sora_village_story:accepted/heard:<resident>/choice:<id>/done`을 기존 `PlayerProgress.story_beat_days`에 저장한다. 저장 버전 변경은 없다.
- 대화 도중 종료하면 그 단계는 완료하지 않는다. 선택 이후 마무리를 중단하면 선택은 저장되고 이세르에게 다시 이야기해 마칠 수 있다. 이미 선택한 기억은 바꾸지 않는다.
- 모달 화면 동안 기존 주민 대화의 시간·이동 중지와 다른 상호작용 차단을 재사용한다. 창을 닫으면 원래 상태를 복원한다.
- 수첩은 시작 전 이세르, 시작 후 아직 못 들은 주민, 모두 들은 뒤 다시 이세르를 목적지로 표시한다. 이동 일정에 따라 주민의 실제 위치를 따른다. 사용자가 지도를 편집해 NPC의 거처가 없으면 없는 인물을 새로 만들거나 지도를 복구하지 않는다.
- 기존 주민 부탁 2/4/6개의 새 손님 해금 개수는 바뀌지 않는다. 공동·개인 부탁의 기존 완료 기록도 유지한다.

## 제미나이 글 작업

기존 `service_text` 종류로 새 장면 8개를 등록했다. 임시 글은 `data/shop/requests/requests_text.csv`, 상황·말투 보충은 `docs/drafts/story/content_voices.csv`에 있다. 정식 인물 기준 파일 두 개는 수정하지 않았다.

| ID | 역할 |
|---|---|
| `sora_village_story` | 제목·수첩 소개·이세르의 시작 부탁·완료 요약 |
| `village_story_naru` | 타블렌의 정착 이후 이야기 |
| `village_story_doyun` | 코르빈의 집과 일상 이야기 |
| `village_story_reminder` | 아직 이야기를 못 들은 플레이어를 기다리는 이세르 |
| `village_story_choose` | 이세르에게 돌아와 기억을 선택하기 전 대화 |
| `village_story_lantern` | 불빛 선택 제목·설명·마무리 대사·수첩에 남는 기억 |
| `village_story_evening` | 저녁 모임 선택 제목·설명·마무리 대사·수첩 기억 |
| `village_story_home` | 정착 선택 제목·설명·마무리 대사·수첩 기억 |

- 글 도구가 인물·장면 순서·끝까지 듣는 조건을 프롬프트에 넣는다. 선택한 행의 `completion`은 수첩과 반복 대화에서 실제로 읽는 짧은 기억이므로 분기별 의미를 유지한다.
- 대사에 재료 수량·돈·평판 수치를 넣지 않는다. 새 책·고객·건물·자유 이름 입력 같은 기능을 약속하지 않는다.
- 이미 구현된 등불, 실제 저녁 모임, 정착 사건을 토대로 각자의 생활 감각과 편의점에 대한 반응을 보강한다. 미래 사건을 이미 일어난 것으로 쓰지 않는다.
- 사용자 PC의 이 콘텐츠가 포함된 폴더에서 다음 명령으로 새 장면만 초안을 만들 수 있다. API는 이번 작업에서 호출하지 않았다. 검사·검토 후 반영한다.

```bat
dev\gemini\run_request_text.bat draft service_text --ids sora_village_story,village_story_naru,village_story_doyun,village_story_reminder,village_story_choose,village_story_lantern,village_story_evening,village_story_home
```
