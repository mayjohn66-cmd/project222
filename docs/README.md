## 3. 폴더 구조

```
docs/
  README.md                 이 길잡이
  AI_협업_규칙.md            협업 규칙
  AI_인수인계.md             지금 대기·진행 중인 요청(옛 기록은 보관/)
  원정_규칙서.md             원정·재료·경제 규칙
  스토리/                    줄거리·인물·글 작성·4막 글 보기
  콘텐츠/                    사건별 구현 기록(막별 폴더 + 시스템 + 검토)
  그림_3D/                   3D 도트·에셋 규격·작업 기록
  그림_작업/                 Pixel Lab 요청서·시안 이미지
  drafts/                   초안 CSV와 스토리 초안(drafts/story)
  보관/                      끝난 기록(옛 인수인계·통합 검증·중간점검)
```

`art/world/*/GENERATION.md`(이미지 생성 기록)는 해당 이미지 폴더 옆에 둔다.
